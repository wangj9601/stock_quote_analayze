# 一阳穿三线策略日志说明

## 日志功能概述

一阳穿三线策略已集成完整的日志输出功能，支持同时输出到控制台和文件。

## 日志文件位置

日志文件统一保存在项目根目录 `logs/` 下，文件名格式为：
```
one_yang_three_lines_YYYYMMDD_HHMMSS.log
```

例如：`logs/one_yang_three_lines_20250130_143000.log`

> 需 `.env` 中设置 `LOG_TO_FILE=true` 才会写入文件。


## 日志级别

- **INFO**: 策略执行的主要信息，包括开始、结束、统计结果等
- **DEBUG**: 详细的调试信息，包括每只股票的分析过程
- **WARNING**: 警告信息，如数据不足、计算失败等
- **ERROR**: 错误信息，如异常处理失败等

## 使用方法

### 1. 直接运行策略
```python
from stock.one_yang_three_lines_strategy import OneYangThreeLinesStrategy
from sqlalchemy.orm import Session

# 创建数据库会话
db = Session()

# 执行策略（会自动记录日志）
results = OneYangThreeLinesStrategy.screening_one_yang_three_lines_strategy(
    db=db,
    limit=100  # 测试模式，只处理100只股票
)
```

### 2. 测试日志功能
```bash
cd backend_api
python test_one_yang_three_lines_logging.py
```

### 3. 查看日志文件
```bash
# 查看最新的日志文件
tail -f logs/one_yang_three_lines_*.log

# 查找特定股票的日志
grep "000001" logs/one_yang_three_lines_*.log

# 查看错误日志
grep "ERROR" logs/one_yang_three_lines_*.log
```

## 日志配置

日志配置在 `setup_strategy_logger()` 函数中：

- **日志格式**: `时间 - 模块名 - 级别 - 消息`
- **编码**: UTF-8
- **文件输出**: 按时间戳命名的日志文件
- **控制台输出**: 实时显示在控制台
- **日志级别**: INFO及以上级别

## 注意事项

1. **磁盘空间**: 长期运行会产生大量日志文件，建议定期清理
2. **性能影响**: DEBUG级别日志会影响性能，生产环境可调整为INFO级别
3. **敏感信息**: 日志中不包含密码等敏感信息
4. **文件权限**: 确保logs目录有写入权限

## 日志分析

### 常见日志模式

1. **数据不足**: `⚠️ 股票 000001 数据不足，跳过`
2. **不是长阳线**: `❌ 000001 平安银行: 不是长阳线，跳过`
3. **未穿越均线**: `❌ 000001 平安银行: 未穿越足够均线，跳过`
4. **成交量未放大**: `❌ 000001 平安银行: 成交量未放大，跳过`
5. **换手率异常**: `❌ 000001 平安银行: 换手率15.20%不在范围内，跳过`

### 性能监控

通过日志可以监控：
- 策略执行时间
- 股票处理速度
- 错误率统计
- 信号质量分布

## 故障排查

1. **策略无输出**: 检查参数是否过于严格
2. **错误率高**: 检查数据质量和网络连接
3. **性能慢**: 检查数据库查询和索引
4. **磁盘满**: 清理旧的日志文件
