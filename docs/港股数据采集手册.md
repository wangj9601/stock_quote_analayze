## 1. 港股个股历史数据 - 快速开始

### 1.1 5 分钟快速上手

#### 步骤 1：选择采集程序

```
是否已有实时行情数据？
    ├── 是 ──→ manual_hk_historical_collection.py（快速，适合日常同步）
    └── 否 ──→ direct_hk_historical_collection.py（直接从 API 获取，适合初始化）
```

#### 步骤 2：配置参数

**方案 A：manual_hk_historical_collection.py**（文件末尾配置区）

```python
START_DATE = '2024-01-01'
END_DATE = '2024-01-31'
COLLECTION_MODE = 'specified'
STOCK_CODES = ['00700', '09988', '01810']
```

**方案 B：direct_hk_historical_collection.py**

```python
START_DATE = '2024-01-01'
END_DATE = '2024-01-31'
COLLECTION_MODE = 'specified'
CALCULATE_INDICATORS = True
STOCK_CODES = ['00700', '09988', '01810']
```

#### 步骤 3：运行程序

```bash
# 方案 A
python manual_hk_historical_collection.py

# 或方案 B
python direct_hk_historical_collection.py
```

#### 步骤 4：确认并开始

程序显示配置信息，输入 `y` 确认开始采集。

### 1.2 常用场景示例

| 场景 | 推荐程序 | 配置要点 | 预计时间 |
|------|----------|----------|----------|
| 3 只股票最近 1 个月 | direct | COLLECTION_MODE='specified', STOCK_CODES=[...] | 约 15 秒 |
| 所有港股最近 1 周 | direct | COLLECTION_MODE='all' | 约 3.8 小时 |
| 今天自选股同步 | manual | COLLECTION_MODE='watchlist', 日期=今天 | 约 1 分钟 |
| 补充缺失历史数据 | direct | COLLECTION_MODE='specified', 指定日期与 STOCK_CODES | 视范围而定 |

**注意：** 全量采集时间较长，建议在空闲时段运行；manual 程序需先有当日实时数据。

### 1.3 查看采集结果

**日志文件：**

```bash
cat manual_hk_collection.log    # manual 程序
cat direct_hk_collection.log    # direct 程序
```

**数据库查询示例：**

```sql
-- 按日期统计条数
SELECT date, COUNT(*) AS stock_count
FROM historical_quotes_hk
WHERE date BETWEEN '2024-01-01' AND '2024-01-31'
GROUP BY date ORDER BY date;

-- 某只股票历史
SELECT * FROM historical_quotes_hk
WHERE code = '00700' AND date BETWEEN '2024-01-01' AND '2024-01-31'
ORDER BY date;

-- 技术指标（示例 MACD）
SELECT date, dif, dea, macd FROM macd_indicators
WHERE code = '00700' AND market_type = 'HK'
  AND date BETWEEN '2024-01-01' AND '2024-01-31'
ORDER BY date;
```

### 1.4 常见问题快速解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 提示「未找到港股实时行情表中的数据」 | 使用 manual 但无实时数据 | 先采集实时数据，或改用 direct |
| 采集速度很慢 | direct 受 API 限流（约 5 秒/股） | 正常现象；可分批采集或改用 manual（若有实时数据） |
| 股票代码无效 | 格式错误或不在库中 | 使用 5 位数字，如 `'00700'`，勿用 `'700'` |
| 没有计算技术指标 | manual：非自选股；direct：CALCULATE_INDICATORS=False | manual 将股票加入自选股；direct 设为 True |

### 1.5 检查清单（采集前）

- [ ] 已安装依赖（akshare、pandas、sqlalchemy 等）
- [ ] 数据库已初始化
- [ ] 日期格式 YYYY-MM-DD、股票代码 5 位数字
- [ ] 网络正常（direct）；已有实时数据（manual）

## 2. 程序选择与对比

### 2.1 程序概览

| 程序 | 数据来源 | 依赖实时数据 | 速度 | API 限流 | 适用场景 |
|------|----------|--------------|------|----------|----------|
| manual_hk_historical_collection.py | stock_realtime_quote_hk | 是 | 快 | 无 | 日常同步、归档当日 |
| direct_hk_historical_collection.py | AKShare API | 否 | 慢（约 5 秒/股） | 有 | 初始化、补历史、无实时服务时 |

### 2.2 功能对比表

| 功能特性 | manual | direct |
|----------|--------|--------|
| 数据来源 | stock_realtime_quote_hk | AKShare API |
| 历史日期 | 仅已有实时数据的日期 | 任意历史日期 |
| 指标计算 | 仅自选股 | 所有股票（可配置） |
| 网络依赖 | 低 | 高 |

### 2.3 程序选择决策树

```
是否已有实时行情数据？
  ├─ 是 ──→ 是否需要历史日期？
  │           ├─ 否（只采近期）──→ manual
  │           └─ 是 ──→ direct
  └─ 否 ──→ direct
```

### 2.4 数据流程简图

**manual：**  
`stock_realtime_quote_hk` → 读取与验证 → `historical_quotes_hk` → 自选股指标计算 → 各指标表

**direct：**  
AKShare API → 获取与清洗 → `historical_quotes_hk` → 指标计算（可配置） → 各指标表

### 2.5 性能参考

| 场景 | manual | direct |
|------|--------|--------|
| 单只股票 1 天 | <1 秒 | 约 5 秒 |
| 10 只 1 天 | <5 秒 | 约 50 秒 |
| 100 只 1 天 | <30 秒 | 约 8.3 分钟 |
| 全量约 2730 只 1 天 | <2 分钟 | 约 3.8 小时 |

### 2.6 注意事项

- **manual**：必须先有实时数据；只能同步已采集日期；适合配合定时任务。
- **direct**：受 API 限流；需稳定网络；可采任意历史日期；适合一次性大批量或补数。
- 两个程序不要同时运行，避免对同一表并发写入冲突。

## 3. 采集模式与配置

### 3.1 采集模式

| 模式 | 配置 | 说明 | 支持程序 |
|------|------|------|----------|
| 指定股票 (specified) | COLLECTION_MODE='specified', STOCK_CODES=[...] | 测试、少量或特定股票 | 两者 |
| 全量 (all) | COLLECTION_MODE='all' | 库中所有港股 | 两者 |
| 自选股 (watchlist) | COLLECTION_MODE='watchlist' | 自选股列表中的股票 | 仅 manual |

### 3.2 通用配置参数

| 参数 | 类型 | 说明 |
|------|------|------|
| START_DATE | str | 开始日期，如 '2024-01-01' |
| END_DATE | str | 结束日期，如 '2024-01-31' |
| COLLECTION_MODE | str | 'specified' / 'all' / 'watchlist' |
| STOCK_CODES | list | 指定股票时使用，如 ['00700','09988'] |

### 3.3 direct 独有参数

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| CALCULATE_INDICATORS | bool | 是否计算技术指标 | True |

### 3.4 自动计算的技术指标

两程序均可（在各自适用范围内）计算：MACD、KDJ、RSI、MA（5/10/20/30/60/120/200）、BOLL、MAVOL、PVFRS（均值频率共振）。

## 5. 运行、验证与故障排除

### 5.1 推荐工作流程

- **新项目初始化**：先用 direct 全量采集一段时间（如最近 1 年），再设定时任务用 manual 每日同步。
- **日常维护**：每日收盘后运行 manual，COLLECTION_MODE='watchlist'，日期为当天。
- **数据补充**：发现缺失时用 direct，COLLECTION_MODE='specified'，指定日期与股票代码。

### 5.2 故障排除

| 错误/现象 | 处理 |
|-----------|------|
| ModuleNotFoundError: No module named 'akshare' | `pip install akshare` |
| 未找到港股实时行情表中的数据 | 改用 direct 或先采实时数据 |
| 股票代码验证失败 | 确保 5 位数字且存在于 stock_basic_info_hk |
| 数据库连接失败 | 检查配置与 backend_core/database/db.py，确认服务运行 |

### 5.3 验收检查

- [ ] 数据已写入 historical_quotes_hk，条数符合预期
- [ ] 如需指标，已计算且无大量报错
- [ ] 日志无严重错误，必要时做数据抽查

## 6. 进阶使用与最佳实践

### 6.1 定时任务

**Linux/Mac (cron)：** 每天 18:00 运行 manual 同步当日自选股

```bash
0 18 * * * cd /path/to/project && python manual_hk_historical_collection.py
```

**Windows：** 使用任务计划程序，每日定时执行上述 Python 命令。

### 6.2 批量与分批

- 大批量时可将股票列表分多批运行，避免单次时间过长。
- 程序内置错误处理，失败股票会跳过并记入日志，可针对失败代码单独补采。

### 6.3 安全与备份

- 定期备份数据库与重要日志；勿将含密码的配置提交版本库。
- 程序对失败操作有回滚，不影响已有数据。

### 6.4 快速检查命令

```bash
python --version
pip list | grep akshare
pip list | grep pandas
# 数据库中：SELECT COUNT(*) FROM stock_basic_info_hk;
#          SELECT MAX(date) FROM historical_quotes_hk;
```

## 7. 港股指数数据采集系统

本节描述 **港股指数**（非个股）的采集、存储与 API，与前述个股历史采集相互独立。

### 7.1 系统概述

- **全量港股指数实时行情采集**：从 akshare 获取，写入数据库；前端从数据库读取，不直连 akshare。
- **港股指数基础信息**：指数代码、名称等单独表存储。
- **历史行情归档**：每日休市后将当日实时数据转存到历史表，用于分析与回测。

### 7.2 系统架构概览

```
数据采集层：AkShare API（stock_hk_index_spot_em / stock_hk_index_daily_sina）
    ↓
数据处理层：HKIndexRealtimeCollector（清洗、基础信息、实时行情）
    ↓
数据存储层：PostgreSQL
    ├─ hk_index_basic_info
    ├─ hk_index_realtime_quotes
    ├─ hk_index_historical_quotes
    └─ hk_index_collect_operation_logs
    ↓
数据归档层：HKIndexHistoricalCollector（每日 17:05 实时→历史）
    ↓
API 层：GET /api/market/hk-indices → 前端展示
```

### 7.3 数据库表（指数）

- **hk_index_basic_info**：指数基础信息（code PK, name, english_name 等）。
- **hk_index_realtime_quotes**：实时行情，按 (code, trade_date) 存储，同一日 UPSERT 更新。
- **hk_index_historical_quotes**：历史行情，长期保留。
- **hk_index_collect_operation_logs**：采集与归档操作日志（operation_type, status, error_message 等）。

### 7.4 核心组件与代码位置

| 组件 | 路径 | 功能 |
|------|------|------|
| 实时采集器 | backend_core/data_collectors/akshare/hk_index_realtime.py | collect_realtime_quotes()，写基础信息与实时表 |
| 历史归档器 | backend_core/data_collectors/akshare/hk_index_historical_collector.py | collect_daily_to_historical(trade_date)、collect_date_range(start,end) |

实时→历史字段映射：trade_date→date，price→close，其余 open/high/low/volume/amount/change/pct_chg 等对应；并写入 collected_source、collected_date。

### 7.5 定时任务

- **实时采集**：任务 ID `hk_index_realtime`，周一至周五 9–12、13–16 点，每小时的 5、35 分（每 30 分钟）。
- **历史归档**：任务 ID `hk_index_historical`，周一至周五 17:05，每日一次。

### 7.6 API：GET /api/market/hk-indices

- 从 `hk_index_realtime_quotes` 读取，优先当前日期，无则最新交易日。
- 返回示例含 code、name、current、change、change_percent、volume、timestamp 等。

### 7.7 手动调用示例

```python
# 实时采集
from backend_core.data_collectors.akshare.hk_index_realtime import HKIndexRealtimeCollector
HKIndexRealtimeCollector().collect_realtime_quotes()

# 历史归档：当天 / 指定日 / 日期范围
from backend_core.data_collectors.akshare.hk_index_historical_collector import HKIndexHistoricalCollector
c = HKIndexHistoricalCollector()
c.collect_daily_to_historical()                    # 当天
c.collect_daily_to_historical('2025-12-03')       # 指定日
c.collect_date_range('2025-11-01', '2025-11-30') # 范围
```

测试脚本：`test/test_hk_index_collection.py`（实时）、`test/test_hk_index_historical.py`（历史）。

### 7.8 监控与维护

- 查看操作日志：`SELECT * FROM hk_index_collect_operation_logs ORDER BY created_at DESC LIMIT 20;`
- 按 operation_type 统计成功/失败；检查实时表各指数最新 trade_date、历史表日期范围。
- 注意事项：确保表已创建（模型在 backend_api/models.py）；依赖 akshare 与网络；17:05 归档依赖当日实时已采完。
