# 主力入场判定 · 口径说明（一期）

## 数据源

| 表 / 接口 | 含义 |
|---|---|
| `stock_fund_flow_em_daily` | 个股主力/超大/大/中/小单净流入（元）；`source` 可为 `em` / `tushare` / `manual` |
| `stock_fund_flow_daily` | 同花顺流入/流出/**净额**（元）；**不等于**东财「主力净流入」 |
| `GET /api/stock_fund_flow/main_force_entry` | 判定结果 |
| `GET /api/stock_fund_flow/em/daily` | 分档序列 |
| `POST /api/stock_fund_flow/main_force/collect` | 单票补数：`source=auto\|em\|tushare` |
| `POST /api/stock_fund_flow/em/import` | 手动导入 CSV / JSON / Excel |
| `stock-analysis-bundle.main_force_entry` | 交易分析并行段 |

## 库内无数据时怎么补

1. **分析页「拉取数据」**（`source=auto`）：先 **Tushare `moneyflow`**（[文档 170](https://tushare.pro/document/2?doc_id=170)，金额万元→元，主力≈特大单+大单），失败再东财 `ak.stock_individual_fund_flow`。
2. **分析页「导入数据」**：粘贴或上传东财分档表，或 Tushare moneyflow 导出（含 `buy_elg_amount` 等列时自动识别）。
3. **日终流程**：`em_stock_fund_flow_daily` 之后可挂 `tushare_moneyflow_daily`（全市场单日一次调用）。
4. **回填脚本（AkShare 东财）**：`python test/backfill_em_stock_fund_flow_daily.py --codes 600519`
5. **回填脚本（Tushare）**：`python test/backfill_tushare_moneyflow_daily.py --codes 600519 --days 60`  
   - 默认 `--api l2` → `moneyflow`（约 2000 积分，`source=tushare_l2`）  
   - `--api dc` → `moneyflow_dc`（约 5000 积分，`source=tushare_dc`）  
   - 全市场推荐：`--all --start YYYY-MM-DD --end YYYY-MM-DD`（按交易日批量）
6. **不要**用同花顺 `net_amount` 冒充主力分档（口径不同）。

Tushare 需 `TUSHARE_TOKEN`；与东财分档阈值不完全相同，UI 会标 `series_source` / `source`。

## 「主力」含义

- **主力** = 东财按成交额分档推断的「主力净流入」（通常 ≈ 超大单 + 大单）
- **不是**机构账户、游资席位或北向持仓身份
- 勿与同花顺日表 `net_amount`、复盘文案中的「主力」混用，除非已单独切换数据源

## 判定要点

- 默认回看 **60** 个交易日
- 入场日：`main_net_inflow > 0` 且占当日成交额 ≥ 约 3%
- 入场窗口：连续 ≥2 入场日，或滚动 5 日净额为正且入场日 ≥3
- 价位近似：窗口内正净流入日的 VWAP 加权均价（`cost_center`）+ 高低价区间
- 旁证：同窗 Volume Profile 的 POC/VAH/VAL；同花顺净额方向；板块主力方向（有则返回）
