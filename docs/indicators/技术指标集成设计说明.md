# 技术指标集成设计说明（KDJ、MAVOL、RSI）

本文档整合 KDJ（随机指标）、MAVOL（成交量均线）、RSI（相对强弱指标）三个技术指标在股票行情分析系统中的集成设计与实现说明。

---

## 一、概述

| 指标 | 用途 | 存储/表 | 展示位置 |
|------|------|---------|----------|
| **KDJ** | 随机指标，K、D、J 值 | `kdj_indicators` | K 线图副图、历史数据表格 |
| **MAVOL** | 成交量均线（MAVOL20） | 由 K 线/成交量数据计算 | 副图成交量图表中的均线 |
| **RSI** | 相对强弱，超买超卖 | `rsi_indicators` | K 线图副图、历史数据表格 |

三者均支持 A 股与港股，在详情页 K 线图中通过副图指标切换（成交量、MACD、KDJ、RSI）统一展示；MAVOL 仅在“成交量”模式下显示。

---

## 二、KDJ 指标集成

### 2.1 目标

为 A 股和港股提供 KDJ 值（K、D、J），在前端 K 线图副图可视化，并纳入历史数据列表与导出。

### 2.2 数据库

**表名**：`kdj_indicators`

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | VARCHAR(20) | 股票代码（主键之一） |
| `date` | VARCHAR(20) | 交易日期（主键之一） |
| `market_type` | VARCHAR(10) | 市场类型 'CN'/'HK'（主键之一） |
| `k` | REAL | K 值 |
| `d` | REAL | D 值 |
| `j` | REAL | J 值 |
| `rsv` | REAL | RSV（未成熟随机值） |
| `created_at` | TIMESTAMP | 创建时间 |

- **主键**：`(code, date, market_type)`
- **冲突**：`ON CONFLICT DO UPDATE` 保证重跑时一致。

### 2.3 后端核心

- **计算工具**：`backend_core/utils/kdj_calculator.py`  
  - 标准 KDJ 算法（N=9, M1=3, M2=3），基于收盘价、最高价、最低价列表批量计算，处理数据不足与除零。
- **采集集成**：  
  - A 股：`backend_core/data_collectors/akshare/historical_collector.py`  
  - 港股：`backend_core/data_collectors/akshare/hk_historical.py`  
  - 采集时确保 `kdj_indicators` 表存在，获取价格后调用 `KDJCalculator` 并写入该表；增强 akshare 调用的错误处理（如 SSL/属性错误重试）。
- **回溯脚本**：`backend_core/data_collectors/akshare/kdj_backfill.py`  
  - 支持按市场（CN/HK/ALL）、日期范围、股票代码过滤，批量回补历史 KDJ。

### 2.4 后端 API

- **模型**：`backend_api/models.py` 中新增 `KDJIndicators`。
- **K 线接口**：`stock_manage.py`（A 股）、`hk_stock_manage.py`（港股）的 `get_kline_hist` / `get_hk_kline_hist` 在返回 K 线时查询 `kdj_indicators`，将 `k`、`d`、`j` 合并到每日数据。
- **历史列表**：`history_api.py` 的 `/api/stock/history`、`/api/stock/history/export` 对 `kdj_indicators` 做 LEFT JOIN，响应与导出中包含 K、D、J。

### 2.5 前端

- **详情页**（`frontend/js/stock.js`）：  
  - 副图在成交量、MACD、KDJ 间切换；`showKDJChart` / `hideKDJChart` 控制 KDJ 网格与系列。  
  - 三条折线：K（白）、D（黄）、J（红/紫）；Tooltip 中显示 K、D、J。
- **管理后台**（`admin/src/views/QuotesView.vue`）：A 股/港股历史数据表格增加 K、D、J 列（保留 2 位小数）。

### 2.6 实施顺序与后续

1. 建表 → 2. 实现并接入计算器 → 3. 运行回溯脚本 → 4. API 暴露 KDJ → 5. 前端图表与表格。  
- **后续**：可考虑盘中实时 KDJ、用户自定义 N/M1/M2（当前 9,3,3）。

## 三、MAVOL 指标集成

### 3.1 目标

在详情页副图**成交量**图中增加 **MAVOL20**（20 日成交量均线），用于观察量能趋势、识别放量/缩量；与成交量柱状图区分明显，仅在“成交量”副图下显示。

### 3.2 核心功能

- 副图成交量图中增加 MAVOL20 曲线。
- A 股（`stock.js`）与港股（`stock_hk.js`）一致。
- 副图切换为 MACD、KDJ、RSI 时自动隐藏 MAVOL20；仅选“成交量”时显示。
- Tooltip 中显示 MAVOL20 数值。

### 3.3 技术实现

- **图表**：在 ECharts 的 `series` 中增加 MAVOL20 系列。  
  - 类型：`line`；坐标：副图 `xAxisIndex: 1`, `yAxisIndex: 1`。  
  - 颜色：`#a855f7`，线宽 1.5，`smooth: true`。
- **数据**：`loadKlineData` 中从 K 线数据取 `mavol20`，`parseFloat` 并处理 null/undefined，按市场（A 股 series 索引 18、港股 13）写入 `option.series[i].data`。
- **显示逻辑**：  
  - 默认选中成交量并激活 MAVOL20。  
  - `updateLegendForIndicator` 在 `indicator === 'vol'` 时将 MAVOL20 加入图例。  
  - `showVolumeChart` 显示 MAVOL20；`showMACDChart` / `showKDJChart` / `showRSIChart` 将其设为不可见。
- **Tooltip**：当 `currentIndicator === 'vol'` 时，在 formatter 中展示“MAVOL20: XXX”。

### 3.4 文件与测试

- **变更**：`frontend/js/stock.js`（含 RSI 系列索引修正）、`frontend/js/stock_hk.js`（同步 MAVOL 逻辑）。
- **测试**：均线值与成交量趋势一致；切换成交量/MACD/RSI 时 MAVOL20 仅成交量模式出现；A 股/港股详情页样式与数据正常；无 `mavol20` 时页面不报错、不画脏线。

## 四、RSI 指标集成

### 4.1 目标

集成相对强弱指标 RSI，用于衡量价格强弱、识别超买超卖，实现从采集、计算、存储到前端展示的全链路。

### 4.2 数据库

**表名**：`rsi_indicators`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Integer | 主键 |
| `code` | String(20) | 股票代码 |
| `date` | Date | 交易日期 |
| `market_type` | String(10) | 'CN' / 'HK' |
| `rsi6` | Float | 6 日 RSI |
| `rsi12` | Float | 12 日 RSI |
| `rsi24` | Float | 24 日 RSI |
| `created_at` | DateTime | 创建时间 |

- **唯一约束**：`(code, date, market_type)`。

### 4.3 计算与数据流

- **计算引擎**：`backend_core/utils/rsi_calculator.py`  
  - 标准 RSI，默认周期 6、12、24；Wilder 平滑法 (SMMA)。  
  - 输入：收盘价序列；输出：含 RSI6/RSI12/RSI24 的 DataFrame 或字典。  
  - 公式要点：涨跌分离 → 平滑平均 gain/loss → RS = avg_gain/avg_loss → RSI = 100 - 100/(1+RS)。
- **数据流**：采集 K 线收盘价 → `RSICalculator` 计算 → 写入 `rsi_indicators` → K 线/历史接口关联查询 → 前端副图与表格展示。

### 4.4 后端实现

- **回补脚本**：`backend_core/data_collectors/akshare/rsi_backfill.py`，支持市场、日期范围、股票代码。
- **每日采集**：A 股 `historical_collector.py` 在 `collect_single_stock_data` 后调用 `_calculate_and_save_rsi`；港股 `hk_historical.py` 在采集日线后调用 `_calculate_and_save_rsi_hk`。
- **API**：  
  - A 股/港股 K 线接口在返回前关联 `rsi_indicators`，将 `rsi6`、`rsi12`、`rsi24` 合并到对应日期。  
  - `history_api.py` 的 `get_stock_history` 支持在历史数据表格中返回 RSI。

### 4.5 前端实现

- **K 线图**（`stock.js` / `stock_hk.js`）：  
  - 三条折线：RSI6（白）、RSI12（黄）、RSI24（紫）；更新 tooltip、legend。  
  - 副图下拉增加 RSI；`showRSIChart` / `hideRSIChart`；`updateSubIndicator` 调度。  
  - `loadKlineData` 解析 API 返回的 RSI 并填入 series。
- **管理后台**：`QuotesView.vue` 中 A 股/港股历史数据表格增加 RSI6、RSI12、RSI24 列。

### 4.6 测试与后续

- **测试**：与通达信/同花顺等对比 RSI 数值；切换股票与副图指标正常；大量数据下性能可接受。  
- **后续**：支持自定义 RSI 周期；支持 Excel/CSV 导出 RSI。

## 五、统一实施与测试要点

### 5.1 实施顺序（按指标）

1. **KDJ**：建表 → 计算器 + 采集/回溯 → API → 前端图表与表格。  
2. **MAVOL**：后端 K 线数据提供 `mavol20` → 前端副图成交量系列与切换逻辑。  
3. **RSI**：建表 → 计算器 + 采集/回补 → API → 前端副图与表格。

### 5.2 副图与切换

- 副图指标选项：成交量（含 MAVOL20）、MACD、KDJ、RSI。  
- 切换时仅当前选中指标可见，避免重叠；MAVOL 仅在成交量模式下显示。

### 5.3 通用测试

- 数据准确性：与主流软件或手工计算对比。  
- 多市场：A 股、港股详情页与历史表均正常。  
- 缺数/脏数据：无指标数据时不崩溃、不画异常线。  
- 导出：历史数据导出（Excel/CSV）包含 KDJ、RSI 等字段（若接口支持）。

以上为 KDJ、MAVOL、RSI 三个技术指标的集成设计说明，供开发与维护参考。
