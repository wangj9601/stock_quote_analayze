计算**无穷成本均线（CYC∞）的核心逻辑在于利用换手率**作为权重，对每一天的价格进行递归加权。这与普通均线最大的不同在于，它模拟了筹码在不同价格区间的流动和沉淀。

以下是具体的计算方法和代码实现：

### **1\. 数学公式**

无穷成本均线是一个递归算法，其公式如下：

$$P\_{\\infty, t} \= (1 \- HSL\_t) \\times P\_{\\infty, t-1} \+ HSL\_t \\times P\_t$$  
**参数说明：**

* $P\_{\\infty, t}$：当前交易日的无穷成本均线数值。  
* $P\_{\\infty, t-1}$：前一个交易日的无穷成本均线数值。  
* $P\_t$：当前交易日的收盘价（通常使用当日均价，即 $Amount / Volume$ 效果更佳）。  
* $HSL\_t$：当日换手率（注意：在计算时需将百分比转化为小数，例如 $2\\%$ 记为 $0.02$）。

### ---

**2\. 计算逻辑解析**

该公式的本质是\*\*“筹码替换”\*\*：

1. **旧筹码留存：** $(1 \- HSL\_t)$ 代表今天没有发生换手、继续持有的那部分筹码，它们维持原来的成本。  
2. **新筹码进入：** $HSL\_t$ 代表今天新成交的筹码，它们以今天的价格进入市场。  
3. **递归循环：** 每天不断地将新成交的成本“揉进”历史成本中，随着时间推移，早期的成本权重会越来越小。

### ---

**3\. Python 代码实现**

针对你可能正在使用的环境（如 Python、Pandas 或金融数据库），可以使用以下逻辑进行计算：

Python

import pandas as pd

def calculate\_cyc\_infinity(df):  
    """  
    计算无穷成本均线  
    df 需要包含: 'close' (收盘价) 或 'avg\_price' (均价), 'turnover\_rate' (换手率, 小数形式)  
    """  
    \# 确保换手率为小数  
    if df\['turnover\_rate'\].max() \> 1:  
        df\['turnover\_rate'\] \= df\['turnover\_rate'\] / 100  
          
    \# 初始化第一个数值为当日价格  
    cyc\_inf \= \[df\['close'\].iloc\[0\]\]  
      
    \# 循环递归计算  
    for i in range(1, len(df)):  
        hsl \= df\['turnover\_rate'\].iloc\[i\]  
        price \= df\['close'\].iloc\[i\]  
          
        \# 递归公式实现  
        current\_val \= (1 \- hsl) \* cyc\_inf\[-1\] \+ hsl \* price  
        cyc\_inf.append(current\_val)  
          
    return cyc\_inf

\# 示例：  
\# df\['CYC\_INF'\] \= calculate\_cyc\_infinity(df)

### ---

**4\. 注意事项**

* **数据起点：** 由于该算法是递归的，计算结果会受到数据起点的影响。通常需要足够长的历史数据（至少一两年的完整日线数据）来让数值趋于稳定，消除初始值带来的误差。  
* **均价 vs 收盘价：** 专业的指标计算通常使用当日的**成交均价**（即 当日成交额 / 当日成交量）而非收盘价，因为均价更能代表当日进场资金的真实成本。  
* **换手率限制：** 如果遇到极个别情况换手率超过 $100\\%$（如新股上市初期），该公式会导致权重计算异常，通常需要对换手率进行封顶处理（取 $1$ 或 $0.99$）。

这种计算方式能帮你更清晰地量化当前的筹码分布中线，建议在分析时将其作为长期的“价值中枢”来参考。
