# 板块龙头 / 中军业务规则

面向产品与业务的口径说明。实现以 `backend_core/board_roles/` 为准；开发入口见文末「相关实现」。

---

## 1. 目标与定位

在**单个行业板或概念板**内，按当日短线表现识别：

| 角色 | 语义 |
|------|------|
| **龙头** | 板内短线领涨核心（至多 1～2 只），须具备一定流通市值资格，避免小票虚高 |
| **中军** | 非龙头、市值居中偏上、同步跟涨的跟风中坚（约数只） |

**设计原则：**

- **偏短线领涨**：当日涨幅为主、成交额弱加权。
- **兼顾市值**：流通市值作资格门槛 + 弱加权，防止极小市值高涨幅被标成龙头。
- **按请求现算、不落库**：基于最新个股实时行情计算，不持久化历史角色序列。

### 与相近能力的区别

| 能力 | 口径 | 本功能是否使用 |
|------|------|----------------|
| **RPE Z（日线比价）** | 中期相对强弱 / 比价，非当日板内领涨 | **否**，不参与打分与判定 |
| **东财板级实时表**（如 `industry_board_realtime_quotes`） | 东财采集的板涨幅、领涨股等字段 | **否**，不作为同花顺角色输入；仅东财路径展示时可作参考 |
| **本功能板强度估计** | 成分股当日涨幅的**中位数** → `board_change_percent_est` | 仅作板强弱旁证，不参与个股角色门槛 |

## 2. 板块口径

### 2.1 默认来源：同花顺

行业 / 概念基础信息表：

- `industry_board_basic_info`
- `concept_board_basic_info`

通过字段 **`board_code_source`** 区分代码体系（见 `board_code_source.py`）：

| 取值 | 含义 |
|------|------|
| `tonghuashun` | 同花顺（**角色计算默认**） |
| `eastmoney` | 东方财富 |
| `huatai` / `manual` / `other` | 华泰 / 手动 / 其他 |

- 管理端新增、导入默认：`tonghuashun`
- 东财同步写入：`eastmoney`
- 存量空值展示回退：按遗留约定视为 `eastmoney`（`LEGACY_DEFAULT_BOARD_CODE_SOURCE`），**不等于**角色计算默认

**同一中文板块名**可能对应不同来源的不同板码，必须带 `board_code_source` 才能唯一定位基础信息行。

### 2.2 解析规则（`resolve_board_for_roles`）

1. 用请求中的 `board_code` + `board_code_source`（缺省为 **`tonghuashun`**）在 basic_info 中精确匹配。
2. 匹配成功 → 用该行的 `board_code` 取对应成分表成分，**不混用来源**。
3. 精确匹配失败且目标为同花顺时：可用请求传入的 `board_name`，或按板码查到的名称，**按同名映射到同花顺板码**。
4. 目标来源**不是**同花顺时：精确匹配失败则直接失败，**不做**同名映射到同花顺以外的静默替换。
5. **禁止**：指定同花顺失败时静默回退到东财成分（避免混口径）。解析失败时 API 侧表现为 404 / 空角色，而非悄悄换源。

### 2.3 成分池

解析得到规范 `board_code` 后：

- 行业：`industry_board_constituents`（或等价 ORM）
- 概念：`concept_board_constituents`

仅按该板码取成分；**不在成分查询阶段再按来源混码**。

## 3. 数据输入

对板内每只成分股组装字段后进入分类器：

| 字段 | 来源 | 说明 |
|------|------|------|
| `code` / `name` | 成分表 | 股票代码归一为 6 位 |
| `change_percent` | 最新交易日 `stock_realtime_quote` | 当日涨跌幅 |
| `amount` | 同上 | 成交额 |
| `circulating_market_value` | 同上 | 流通市值（通常为**元**） |
| `current_price` | 同上 | 可选；用于市值兜底 |

**最新交易日**：`stock_realtime_quote` 中 `change_percent IS NOT NULL` 的 `MAX(trade_date)`。

**市值兜底**：实时表无有效流通市值时，用 `stock_basic_info` 的流通股本 × 现价（`calc_mv_yi`）得到亿元，再 × `1e8` 转为元，与实时表单位对齐后参与分位。

缺涨幅或缺有效流通市值（≤0）的股票：**不进入有效打分样本**，不会被标为龙头/中军。

---

## 4. 有效样本与分位计算

1. **有效样本**：`change_percent` 有值，且 `circulating_market_value > 0`。
2. 在**全板成分行**上分别计算三项百分位（0–100），再仅对有效样本写综合分：
   - `chg_pctile`：涨幅分位
   - `amt_pctile`：成交额分位（缺失按 0）
   - `mv_pctile`：流通市值分位（缺失按 0）
3. **分位算法**：有效数值按升序；**并列取平均秩**；仅 1 个有效值时该点为 100；无效值保持无分位。

板强度估计（不参与门槛）：有效涨幅的**中位数** → `board_change_percent_est`。

---

## 5. 综合分公式与权重

对有效样本：

```text
board_role_score = 0.70 × chg_pctile + 0.20 × amt_pctile + 0.10 × mv_pctile
```

| 权重常量 | 默认值 | 含义 |
|----------|--------|------|
| `W_CHG` | **0.70** | 涨幅分位 |
| `W_AMT` | **0.20** | 成交额分位 |
| `W_MV` | **0.10** | 流通市值分位 |

分数保留两位小数。排序与并列判定均以该综合分为准。

---

## 6. 龙头判定规则

记有效样本数为 `N`。

### 6.1 资格门槛

须同时满足：

1. **市值门槛**：`mv_pctile ≥ 40`（`LEADER_MV_PCTILE_MIN`）
2. **领涨条件**（二选一即可）：
   - `chg_pctile ≥ 80`（`LEADER_CHG_PCTILE_MIN`），**或**
   - 按涨幅从高到低排名进入前 `max(3, ceil(N × 0.1))` 名

不满足市值门槛的极小市值高涨幅票**不能**成为龙头。

### 6.2 数量与并列

1. 合格候选按 `board_role_score` **降序**。
2. 取第 1 名为龙头。
3. 若存在第 2 名，且满足：
   - 第 1、2 名综合分差 **≤ 5**（`LEADER_SCORE_GAP`），且
   - 第 2 名同样通过龙头门槛，且
   - 总数不超过 **`LEADER_MAX = 2`**
   
   则再标一只第二龙头。

4. 龙头写入：
   - `board_role = "leader"`
   - `board_role_label = "龙头"`
   - `role_reason`：短线领涨说明（含涨幅/市值分位与综合分）

## 7. 中军判定规则

在**非龙头**的有效样本中筛选：

| 条件 | 默认 |
|------|------|
| 流通市值分位 | `50 ≤ mv_pctile ≤ 95` |
| 涨幅分位 | `chg_pctile ≥ 60` |
| 排序 | 综合分降序 |
| 数量上限 | 见下 |

**数量上限（`MID_MAX = 5`）：**

- 一般：最多 **5** 只。
- 小板：当 `N < 15` 时，上限缩为 `max(1, round(5 × N / 15))`，避免小板标注过多中军。

中军写入：`board_role = "mid"`，`board_role_label = "中军"`，以及对应 `role_reason`。

未入选龙头/中军的股票：`board_role` / `board_role_label` / `role_reason` 为 `null`（仍可有分位与综合分，若进入过有效样本）。

---

## 8. 输出字段与标签语义

### 8.1 行情 / 管理端成分行（`board_role` 体系）

| 字段 | 说明 |
|------|------|
| `board_role` | `leader` / `mid` / `null` |
| `board_role_label` | `龙头` / `中军` / `null` |
| `board_role_score` | 综合分 |
| `role_reason` | 人类可读判定说明 |
| `chg_pctile` / `amt_pctile` / `mv_pctile` | 分位明细 |
| `board_code_source` / `board_code_source_label` | 实际使用的板块来源 |
| `board_change_percent_est` | 成分涨幅中位数（板强度估计） |

### 8.2 选股 `role_tags`（与 `risk_tags` 分离）

由 `role_tag_from_row` 转换；**不写入** GMS/URT 的 `risk_tags`。

| `id` | `label` | `level` |
|------|---------|---------|
| `board_leader` | 龙头 | `info` |
| `board_mid` | 中军 | `info` |

`reason` 可带 `[板块名/来源标签]` 前缀。

**多板选股**：对所选多块板分别计算角色后，同一股票取 **综合分最高** 的那一个角色写入 `role_tags`（通常 0 或 1 条）。

## 9. 展示入口

| 入口 | 行为要点 |
|------|----------|
| **行情页**（`frontend/js/markets.js`） | 行业/概念成分、`top_stocks` 请求带 `board_code_source`；名称旁展示「龙头/中军」chip（tooltip 为 `role_reason`） |
| **选股 GMS / URT**（`frontend/js/screening.js` + screening API） | `scope` 为行业/概念且已选板时挂载 `role_tags`；前端优先透传同花顺来源；与风险标签分开展示 |
| **管理端「板块成分股维护」**（`BoardConstituentsView`） | 成分列表名称旁标签 + 行高亮；`GET /api/admin/board-constituents/list` 支持 `board_code_source`；当前页内龙头/中军排前 |

### 主要 API

- `GET /api/market/industry_board/{board_code}/stocks|top_stocks?board_code_source=&board_name=`
- `GET /api/market/concept_board/{board_code}/stocks|top_stocks?board_code_source=&board_name=`
- 管理端成分列表：`GET /api/admin/board-constituents/list`（同上来源参数）
- 选股：GMS/URT 在板块 scope 下参数 `board_code_source`（默认 `tonghuashun`）

解析失败 → 行情侧通常 404；管理端可不挂角色；选股侧对应板跳过挂载。

## 10. 边界与不做事项

本版明确**不做**：

1. **不落库**：不新增角色结果表 / 不持久化历史龙头序列。
2. **不新建**同花顺（或概念）板级实时涨幅采集表；板强度用成分涨幅中位数现算。
3. **不把**角色塞进 GMS/URT `risk_tags`。
4. **不静默**将同花顺空成分 / 解析失败回退为东财成分。
5. **不改** RPE Z 语义；角色计算不引用 RPE。
6. **不直接**用东财实时板表的「领涨股」字段当作本功能的龙头结论（来源与成分池不同）。

## 11. 可配置常量一览（当前代码默认值）

定义于 `backend_core/board_roles/classify.py`：

| 常量 | 默认值 | 用途 |
|------|--------|------|
| `W_CHG` | `0.70` | 涨幅分位权重 |
| `W_AMT` | `0.20` | 成交额分位权重 |
| `W_MV` | `0.10` | 流通市值分位权重 |
| `LEADER_MV_PCTILE_MIN` | `40.0` | 龙头最低市值分位 |
| `LEADER_CHG_PCTILE_MIN` | `80.0` | 龙头涨幅分位门槛（或进入涨幅 Top-K） |
| `LEADER_SCORE_GAP` | `5.0` | 第二龙头相对第一名的最大分差 |
| `LEADER_MAX` | `2` | 龙头数量上限 |
| `MID_MV_PCTILE_MIN` | `50.0` | 中军市值分位下限 |
| `MID_MV_PCTILE_MAX` | `95.0` | 中军市值分位上限 |
| `MID_CHG_PCTILE_MIN` | `60.0` | 中军最低涨幅分位 |
| `MID_MAX` | `5` | 中军数量上限（`N<15` 时按比例缩减） |

龙头涨幅 Top-K：`max(3, ceil(N × 0.1))`（写在判定逻辑中，非独立命名常量）。

板块来源相关（`backend_api/utils/board_code_source.py`）：

| 常量 | 默认值 |
|------|--------|
| `DEFAULT_BOARD_CODE_SOURCE` | `"tonghuashun"` |
| `SYNC_BOARD_CODE_SOURCE` | `"eastmoney"` |
| `LEGACY_DEFAULT_BOARD_CODE_SOURCE` | `"eastmoney"`（存量空值展示） |

v1 以上均为代码内默认；调整权重/门槛应改常量并同步本表与单测。
