## 1. 总览 / 模块边界

| 入口 | 职责 | 同源关系 |
|------|------|----------|
| **个股综合分析**（`stock_multi_strategy.js`） | 策略评估后并行拉「阻力支撑」+「形态」+「波段与趋势」；解读可注入 `confluence_zones` | levels / patterns / market-structure / PDF 同口径 |
| **技术工具 · 阻力支撑位**（`kde_levels_tool.js`） | 单股 KDE + VP + 经典位 + 共振带展示 | `GET /api/analysis/levels/{code\|query}` |
| **技术工具 · 形态识别**（`pattern_tool.js`） | 个股识别 / 扫描；NLG「形态专家解读」 | `GET/POST /api/analysis/patterns/*` |
| **波段与趋势**（`market_structure_tool.js`） | 日线 ZigZag · HH/HL · 趋势标签 · 破摆动事件 | `GET /api/analysis/market-structure/{code}` |
| **PDF 导出**（`stock_analysis_pdf.js`） | 策略 + 阻力支撑 + 形态 + 波段趋势摘要 | 共用解读与 `MarketStructureTool.formatPlainText` |

价格口径：`adjust=none|qfq`（默认 `none`；前端工具勾选前复权时常传 `qfq`）。与形态、levels 共用复权因子链路。

数据流（简化）：

```text
日线 OHLC(+volume)
  ├─ KDE 扩窗结构位 ──────────────┐
  ├─ Volume Profile ─────────────┤
  ├─ ZigZag Fib / Pivot / Cam / ATR-Pivot ─┤→ 候选点 → 共振带（DBSCAN）
  └─ 枢轴序列 → 形态检测 → 生命周期/NMS → 前端 FinalScore + NLG
```

### 1.1 典型场景与引擎行为

**四维闭环（产品口径）**：量化分析引擎在**形态识别**、**强弱共振带合成**、**多层级攻防分层**、**极端盘口自适应**四个维度上均已彻底闭环——主形态竞选与生命周期归档、共振带聚类与真空兜底、结构防守的贴身/近端/核心分层与测幅 ACHIEVED、以及上破阻力真空的参考降级与 VP 破位提示，均有可复现的规则路径。

**现行能力边界**：Fib / Pivot / Camarilla / ATR-Pivot / VP / 共振带及「参考/降级」档均为**参考用，不作策略硬门槛**；降级档须标注且不得伪装形态几何；巩固测幅以前端简化边界高度为准（后端入库仍为 P2）；专家解读为规则模板，非投资建议。

下列「场景分类」为产品侧归纳；**引擎处理**栏描述对外观感，「代码对应要点」仅写已落地路径/参数（未实现则如实标注）。细节见 §2.2（VP）、§3.2（生命周期）、§3.5–3.6（真空兜底 / 结构防守与软融合）。场景与四维的对应见下文「四维映射」。

| 场景分类 | 极端边界触发条件 | 引擎自动化处理机制 | 典型代表案例 | 代码对应要点（已落地） |
|----------|------------------|--------------------|--------------|------------------------|
| 形态突破确认 / 测幅 ACHIEVED | 股价有效突破主形态上沿/下沿；或现价已触及/越过简化测幅目标 | 计算测幅目标；上沿可翻支撑；**ACHIEVED** 后目标不再占结构阻力/支撑档，仅留背景一句 | 华亚智能 (003043)；富瀚微 (300613) | 巩固确认缓冲 `BREAKOUT_UP/DOWN_MULT`（1.005/0.995）；前端简化测幅 `H=upper−lower`，上破目标≈`upper+H`、下破≈`lower−H`（`_consolMeasuredMove`，后端测幅入库仍为 P2）；`close≥target`（下破对称 `≤`）→ ACHIEVED；已确认上破后上沿/颈线可标「突破后翻支撑」 |
| 筹码真空/破位 | 跌破价值区下沿 VAL（表意「跌破筹码高密区」） | 触发「无筹码承接」提示（降级展示） | 博杰股份 (002975) | **已落地（VP 文案层）**：`volume_profile.py` 在现价 `< VAL` 且下方无 `nearest_support` 时写 `support_note`＝`已跌破{N}日VAL，下方无{N}日筹码承接`；对称上破 VAH →「无筹码压制」。展示：`kde_levels_tool.js` / PDF `_fmtPriceOrNote`。**非**形态 NLG；`pattern_tool` 无「无筹码承接」专用分支。不扫描「全部高密桶」，条件即 VAL+无下方 VP 支撑 |
| 无主形态归档期 → 共振兜底 | 主形态归档且无新主形态（活跃池空或仅过期/失败 forming） | 主形态降级为「暂无主导形态」；结构防守无损提取底层高强度多维共振带 | 华光环能 (600475) | **真空共振兜底**：主形态「暂无主导形态」；短/中线提示跟踪共振带；结构防守用 `confluenceZones` **整侧**兜底并标注强度（`buildStructureLevelsReference` / §3.5–3.6）；无共振数据则只改占位语义、不编假价 |
| 防守/阻力多层提取、贴身临界、临界压制 | 现价与形态几何边界间存在强/弱夹层共振；或反转旁有近端巩固通道沿 | 重构为「近端缓冲/贴身临界 + 核心破位/形态阻力」；弱带写「日内/临界压制」且不占双档 | 东方雨虹 (002271) / 凯莱英 (002821) / 博实股份 (002698) / 甘源食品 (002991) | **软融合**：`pattern_lower`/`pattern_upper` 取 **primary 几何边界**；夹层 ≥**10**（贴身 CONTACT ≥**4**）→ **近端优先**；`0≤dist&lt;0.5%` →「贴身临界支撑/压制」；≥10 或贴身≥4 **不得**被战术 nearEps 静默丢弃。**P1**：primary 强制第一档后第二档近距优先；巩固通道沿 ≤约 **3%** 可保送；弱共振 ≥约 **4**（&lt;soft≥10）结构块追加「日内/临界压制/支撑」（例：14.21 通道沿 / 14.03@4.5） |
| 形态失效/诱空反抽归档 | 破位后价格大幅拉回，形态遭破坏 | 触发失效/归档，对外「已归档」 | 凯莱英 (002821) | 对外「已归档」=`status=archived`（非默认过滤的 `invalidated`）。头肩：**失败破位**（深破+回抽够远）或 **失败反抽**（回颈线另一侧且逼近右肩±2% **或** 反抽 ≥约 **2.0×ATR**）→ `lifecycle.py` 标 `archived`；反转另有测幅兑现/回吐兜底归档。巩固几何失效多为 `invalidated`（见 `INVALIDATE_*`），列表默认不返回 |
| 主形态竞选：conf 优先 + 几何强制 | 同 status 多形态并存；结构档需锚定主形态边界 | 竞选以 confidence 优先；结构防守以 primary 几何边界强制第一候选 | 博实股份 (002698) | 同 status：`Confidence desc` → 仅 `|Δconf|&lt;RANK_CONF_TIE_EPS`(0.05) 时时间衰减弱 tie-break → `formed_at` desc；**confirmed &gt; forming**（§3.5）。结构档：`primaryGeom` 强制第一席，勿用「全库已选支撑 max」顶替（§3.6） |
| 上破后阻力真空降级 | 已确认上破且形态内阻力档为空 | 单侧近端补 1 档：共振 → ATR-Pivot R1 → 最近 KDE；文案标「参考/降级」 | 富瀚微 (300613) | `buildStructureLevelsReference` 上破阻力真空降级：优先 `confluence.resistances`（标强度），再 ATR-Pivot R1 / 最近 KDE；勿伪装形态几何；已跌破 VAH/Fib 不写回上方；个股路径可传 `classicLevels` / `kdeLevels` |
| 同 conf 多空交织中线文案 | 同 status 且 conf 接近、多空 bias 冲突 | 中线提示宽幅箱体/震荡观察；**不**改写 primary | 甘源食品 (002991) | `|Δconf| &lt; RANK_CONF_TIE_EPS` 且 `_biasConflicts` → 中线「多空形态交织，宜按宽幅箱体/震荡观察…」；置信优先的 primary 选取不变 |

## 1.2 短期三态与结构买点

实现：`backend_core/analysis/pattern_tactical.py`  
挂接：`GET /api/analysis/patterns/{code}` 响应字段 `tactical`（尽量注入同请求 VP / 共振带 / RPE 快照；拿不到则 `grade=base`）。  
展示：`pattern_tool.js` 专家区徽章 + 买点列表；`stock_multi_strategy.js` / PDF 消费同一字段。与现有 shortTerm / mediumTerm NLG **并存**，主标签应对齐短线语义。

### 分层原则

| 层 | 作用 | 不做 |
|----|------|------|
| **主标签 `short_bias`** | 只由形态结构定：确认站上 → 看多；forming / 多空交织 / 高强度贴压 → 震荡；有效跌破核心防守 → 看空 | VP/RPE **不**作看多硬 AND |
| **`grade`** | `base` / `enhanced` / `strong`：破 VAH+无上方筹码、RPE Z≥`z_lead`(默认 2.0) 各计一档增强 | 不改写 short_bias |
| **买点 `buy_hints`** | 看多/震荡输出结构区间；看空 `[]` + `risk_note`；**楔形蓄势突破预警 + GMS>60** 时追加右侧 `breakout_follow`（站稳 `hold_level` + 量>1.5×MA20，与左侧回踩并存） | 不做空建议；不写入 URT/GMS 硬筛（GMS 仅升预警/右侧跟进） |
| **trade_advice** | 可选软旁证写入 `evidence`（`trade_advice_soft`） | 不硬绑形态买点 |

免责：`disclaimer`＝「规则模板，非投资建议」。

### 三态规则摘要

| short_bias | 主条件（满足即定标签） | bias_label | 买点 |
|------------|------------------------|------------|------|
| **看多** | primary 多头反转 `confirmed` 且 close>颈线（`BREAKOUT_UP_MULT`）；或巩固已确认上破；**或无活跃命中时的旁路**：空头形态因向上脱离而 `invalidated`，或归档多头反转且现价仍在颈线上方（趋势延伸） | 趋势确立 | 优先 `pullback_buy` 回踩颈线/翻支撑；旁路场景改近端支撑 `watch`（颈线远离不作锚）。无增强时可为 `watch`、降低 priority |
| **震荡** | `forming`；或多空交织；或近端强压；**或旁路**：归档空头仅贴颈/浅破（逼近压力）、旁路多空冲突接近、放量长阳否决旁路看空 | 蓄势夹击 / **逼近压力** / **箱体震荡**（双顶双底互斥） | `watch` → 下沿/近端支撑或观察颈线站稳；有 `box_low`/`box_high` 时优先箱体下沿作锚、上沿作 target；**形态下沿相对现价过远（≥25%）时远端下沿永不作 priority≤2 主锚（仅 p4 极限参考）**；`floor_far` 内优先序：贴身超强压（strength≥`BUY_PRESSURE_MIN_STRENGTH`=10，与 bias 的 50 解耦）→ `break_upper`；否则近端 A（≥10/≤6%）或 B（≥5/≤8%）→ `near_support_pref`（可附更远近端第二档 watch；**各档 invalidation 绑定本档支撑带下沿**，经 `_clamp_invalidation` 约低 1%，不与更远档/Fib 共用失效）；再否则观察上破。**`break_upper` 主目标优先取「形态上沿之上的下一档有效阻力」（strength≥5），`max(合格上沿, 下一档)`；上沿相对突破入场 upside 过薄或 RR 倒挂时不得单独用上沿作唯一 target**。强压下不新开/不追。`invalidation` 须低于买入下沿 |
| **看空** | 跌破下沿/核心颈线；或确认空头反转且 close 在颈线下；**或旁路**：多头向下失效 / 归档空头**相对颈线深破**（默认≥3%；陈旧≥8%） | 结构破位 | `buy_hints=[]`；`risk_note` 破位价与反抽压制 |
| **insufficient** | 有效命中 0 且**无**旁路证据（不再把 `invalidated_count>0` 映射成震荡） | 信息不足 | 无进攻买点 |

旁路收紧（`_inactive_bypass`，600722 类）：贴颈（≤1.5%）或浅破不作「结构破位看空」；归档空头与归档多头并存时近端压力优先震荡；日涨幅≥4% 且量比≥1.8（或涨幅≥5.5%）否决旁路看空。

### 增强证据（写入 `evidence[]`）

| code | 含义 |
|------|------|
| `pattern_confirmed_neck` / `pattern_consol_break_up` | 结构看多主条件 |
| `pattern_breakdown` | 破位/看空主条件 |
| `pattern_forming` / `bias_mix` / `resonance_pressure` | 震荡主条件 |
| `inactive_bypass` | 无活跃命中时的归档/失效旁路（看多 / 看空 / 逼近压力震荡） |
| `momentum_veto_bear` | 放量长阳否决旁路看空（写入 change_pct / volume_ratio） |
| `vp_break_vah` | last_close>vah 且上方无近端筹码（`nearest_resistance is None` / `resistance_note`） |
| `rpe_lead` | `z_score ≥ z_lead` |
| `trade_advice_soft` | 四策略旁证（可选） |
| `near_support_pref` | 形态下沿过远（`floor_far`）时优先近端共振支撑作主买点锚（A/B 档）；贴超强压时降为次级左侧 watch |
| `wedge_breakout_alert` / `wedge_breakout_follow` | 下降楔形微幅上破 + GMS>60 → 蓄势预警；并注入右侧 `breakout_follow`（`wedge_hold_level` / 量能条件 / `alert_target`·`alert_invalidation`） |
| `ultra_squeeze` | 近端双侧强度>20 且带宽&lt;2.5% → 盘口态「极窄箱体变盘临界」；回踩 `entry_zone` **硬收窄到支撑带下沿附近**（禁止贴现价追涨）；贴压 `break_upper` 仅观察「变盘前不追」 |
| `no_active_hits` | 有效 0 + invalidated_count |

### 与 trade_advice 边界

- 战术买点来自**形态结构**（± VP/RPE 强弱档），策略卡片 `trade_advice.action=buy` 仅作 evidence 旁证。
- Fib / Cam /「参考降级」档不作硬止损/硬买入；本模块亦不替换旧版指标 `TradingRecommendation`。

### 1.3 波段与趋势（第三块产品面，与四维并列）

实现：`backend_core/analysis/market_structure.py`  
API：`GET /api/analysis/market-structure/{code}`（`adjust=none|qfq`，复权与 levels/patterns 同口径）

| 项 | 口径 |
|----|------|
| 锚点 | 与 Fib 同参 ZigZag（`swing_zigzag`：分形 + 深度过滤；默认 `min_swing_bars≈8`） |

| 非目标（近端） | 订单块、FVG、周线主判、完整 SMC |

## 2. 支撑与阻力

### 2.1 KDE 结构位

实现：`backend_core/strategies/rpe/kde_levels.py`  
个股 API 封装：`backend_api/stock/stock_analysis.py` → `KeyLevels.calculate_key_levels`（默认各侧最多 **2** 档；技术工具请求可传 `max_levels`，前端默认 **8**）。

| 项 | 现行口径 |
|----|----------|
| 样本 | 收盘价 + 成交量；有效点（价>0 且量>0）&lt; 20 → 失败 |
| 密度 | 优先 `scipy.stats.gaussian_kde`（成交量权重）；无 scipy 则加权直方图 + 三点平滑 |
| 峰检测 | `find_peaks`（prominence≈5% max；直方图回退 3%）；失败再局部极大 |
| 划分 | 峰 &lt; 现价 → 支撑（近→远）；峰 ≥ 现价 → 阻力（近→远） |
| **结构锚窗（默认开）** | 与 Fib 同参 ZigZag（`OHLC_LOOKBACK` / `DEFAULT_FRACTAL` / `DEFAULT_MIN_SWING_BARS`）取最近确认波段较早端为锚；`lookback = clamp(窗末日−锚, 40…750)`；高波动（ATR/价&gt;4%）×0.85、低波动（&lt;1.5%）×1.15；失败回退日历 60。传 `kde_lookback` / `kde_from_date` 则强制日历窗 |
| 日历初始回看 | 强制日历时默认 **60** 日（与 VP 对齐；API 可覆盖）；可调的是**初始**回看 |
| 无支撑扩窗 | 自初始回看按 STEP 递推至 MAX：例 60 → 310 → 560 → 750（`KDE_LOOKBACK_STEP=250` / `MAX=750`） |
| 带宽 | `bw = clamp(base_factor × σ/μ, min_bw=0.01, max_bw=0.08)` |
| 扩窗衰减 | `effective_factor = base_factor × 0.85^expand_steps`，再受 `max_bw` 约束，避免「抹平→扩窗→更平滑」 |
| **时间衰减（默认自动）** | 有效样本 ≥120 时对成交量权重乘 `e^(-λ·age)`，半衰期约 **40** 根（`KDE_TIME_DECAY_HALFLIFE`） |
| **多窗峰（默认开）** | 另算固定 60/120/250 窗 VW-KDE（不扩窗）；峰以 `kde_60/120/250` 进共振，权重 0.55/0.65/0.75；**展示卡仍只用主路径 expand 结果** |

入口：`compute_kde_bundle`（主路径 expand + 锚元数据 + 多窗）；底层仍 `extract_kde_levels_expand_support`（RPE / URT / 个股关键价位同内核）。

### 3.2 状态机

| 状态 | 含义 | 列表 / 主形态 |
|------|------|----------------|
| `forming` | 构筑中 | 可见；可竞争（反转过期除外） |
| `confirmed` | 突破/破颈等已确认 | 可见；优先主形态 |
| `archived` | 测幅兑现 / 失败破位 / 超时 / 回吐等 | 可见；**不**竞争主形态 |
| `invalidated` | 假设失效 | 默认 API 过滤 |

**头肩破颈锁存**：右肩后**任一收盘**有效破**当日斜颈阈值** → `confirmed` + `confirm_date`/`confirm_neckline`；此后反抽/回落**不得**改回 `forming`。颈线由两峰线性插值/外推；头相对两肩深度 ≥3%，颈线两峰相对差 ≤22%（否则不产出，避免双底+虚高均价颈线）。斜颈外推至非正，或相对两颈点过低（`<min×HS_NECK_EXTRAP_LO_FRAC`，顶/底），或底相对过高（`>max×HS_NECK_EXTRAP_HI_FRAC`）→ `invalidated`，展示颈改参考值（禁止负/近零颈线；000533 / 002286 类外推失真）。

**头肩失败破位归档**（`forming`/`confirmed` 均可）：

- 顶：最低 &lt; 颈线×`0.95`，且现价 &gt; 颈线×`1.02`
- 底：对称（`HS_FAIL_DEPTH_MULT` / `HS_FAIL_RECOVER_MULT`）

**头肩远距反抽归档**（仅 `confirmed`）：现价相对确认颈线（优先 `confirm_neckline`）反向偏离 ≥`HS_CONFIRM_FAR_RECOVER_PCT`（默认 **8%**）→ 强制归档（顶：回到颈线上方过远；底对称）。优先于「失败反抽」文案路径。

**头肩失败反抽归档**（仅 `confirmed`；不回 `forming`）：破颈后现价回到颈线另一侧，且（逼近/超过右肩±`HS_FAIL_RS_NEAR_PCT`≈2% **或** 反抽/回撤幅度 ≥ 约 `HS_FAIL_PULLBACK_ATR_MULT`×ATR，默认 **2.0**）。仅「任意回到颈线上方」不触发。

**头肩 forming 超时**：右肩后 ≥`90` 根仍未收盘破颈 → `archived`（`HS_FORMING_TIMEOUT_BARS=0` 关闭）。

**双顶双底同窗交织降权**（`engine.annotate_double_extremes_mix`，lifecycle/NMS 之后）：同时存在活跃 `double_top` 与 `double_bottom` 且枢轴日期跨度重叠 → 两者 `confidence` cap 至 ≤**0.45**，reason/key_levels 标 `bias_mix`，并写入 `box_low`/`box_high`、`range_label=箱体震荡`、顶层 `range_box`；若双底颈≈双顶 H1（或对称）相对差&lt;0.5% 则 reason 注「同枢轴复用」。tactical 在 `bias_mix` 且双顶+双底并存时 `bias_label` 为「箱体震荡」，买点优先锚箱体下沿、目标取上沿。

**结构买点失效位**：`buy_hints.invalidation` 须严格低于 `entry_zone.low`（默认至少约低 1%，再与最小价差取严），避免失效位落在买入区间之上形成死锁。近端多档 `near_support_pref` 时，**每档失效绑定该档共振带/入场区下沿**，不得把更远一档的失效抬给近端主买点。

**测幅兑现归档**（反转类）：触及颈线±形态高度×`0.9`（`LIFECYCLE_TARGET_RATIO`），不依赖 45 根。另有反向已确认巩固突破降权、以及 ≥45 根 + 有利方向≥25% + 回吐≥50% 的兜底归档。

巩固形态确认/失效缓冲见下表（与 [形态识别工具.md](./形态识别工具.md) 一致）。

### 3.3 楔形斜率收敛校验

### 3.5 主形态选取：FinalScore、真空兜底

前端：`pattern_tool.js`（非 LLM）。

竞选主序（同 status）：

1. **Confidence desc**
2. 仅当 `|conf_a − conf_b| < RANK_CONF_TIE_EPS`（默认 **0.05**）时，才用时间衰减弱 tie-break：`conf × e^(-λ·Δt)`（`λ` 默认 `0.012`，`Δt` 为 `formed_at` 距 asof 日历日）
3. 再比 `formed_at` desc

状态层：**confirmed 优先于 forming**（不靠 `W_status×衰减` 间接压过）。兼容旧口径的综合分仍可写为：

\[
\mathrm{FinalScore} \approx \mathrm{confidence} \times W_{\mathrm{status}} \times e^{-\lambda \Delta t}
\]

（`_finalScore` 保留供调试；**排序不再单靠该分**让新形成的低 conf 压过旧高 conf。）

| 常量 | 默认 |
|------|------|
| `RANK_W_CONFIRMED` | 1.2（兼容分） |
| `RANK_W_FORMING` | 0.6（兼容分） |
| `RANK_TIME_DECAY_LAMBDA` | 0.012（仅 conf 接近时的弱 tie-break） |
| `RANK_CONF_TIE_EPS` | 0.05（`|Δconf| ≥` 该值则衰减压不过） |
| `PRIMARY_FORMING_MAX_AGE_DAYS` | 60（形成中反转超日龄不进主形态） |

挑选：优先已确认；否则仅「可活」候选。活跃池空或仅过期/失败 forming → **真空**：主形态写「暂无主导形态」，短/中线提示跟踪多维共振带；结构防守可注入 `confluenceZones`（无数据则只改占位语义、不编假价）。最近 `archived` 可写一句背景，不抢主形态。

同分/接近时：已确认巩固若晚于冲突反转可小幅 boost；再比 `formed_at`。

### 3.6 形态解读 NLG（结构防守与目标）

`buildStructureLevelsReference` / `buildExpertAnalysis`：

| 场景 | 行为 |
|------|------|
| 有活跃形态档 | 以**主形态几何边界**为第一候选（巩固 upper/lower；反转颈线按侧，阻力侧可取最近右肩/峰）；补第二档时**近距优先**（同分再语义）；巩固通道上/下沿距现价 ≤约 **3%**（`TRADE_LEVEL_NEAR_CHANNEL_PROMOTE_PCT`）可保送一席；勿被全库远端峰/头挤掉近端通道沿 |
| 巩固测幅 | 前端简化：`H=upper−lower`；上破目标≈`upper+H`，下破≈`lower−H`（文案标明按边界高度）；**ACHIEVED**：上破 `close≥target`（下破对称 `≤`）→ 标已超额达成，**不再**作为上方阻力/下方支撑档，仅保留背景一句 |
| 空档占位 | 已确认上破且无形态内阻力 →「形态边界已上破；上方暂无形态内阻力档…」（下破对称）；禁止再写「等待突破」；测幅已兑现时不再写「近端关注简化测幅目标」 |
| 真空共振兜底 | 无主形态（或两侧皆空且无巩固突破）→ 用 `confluenceZones` **整侧**兜底，标注强度 |
| 上破阻力真空降级 | 已确认上破且形态阻力档空 → 单侧近端补 1 档：优先 `confluence.resistances`（标强度），再 ATR-Pivot R1 / 最近 KDE；文案标「参考/降级」，勿伪装形态几何；已跌破 VAH/Fib 不写回上方 |
| 有主形态软融合 | **不**硬盖形态边界；`pattern_lower` / `pattern_upper` 取 **primary 几何边界**；夹层强度 ≥ **10**（**贴身 CONTACT 带 ≥4 即可**）候选中 **近端优先**→「近端缓冲防守」/「贴身临界」/「近端缓冲/第一压制」；形态档保留「核心破位防守 / 核心形态阻力」；≤2 档优先贴身/近端 |
| 贴身临界 | 阻力：`high > close`（或 `center≥close` 且 `high>close`）；支撑：`low < close`；且 `0 ≤ \|center−close\|/\|close\| <` 约 **0.5%**（`CONFLUENCE_SOFT_CONTACT_PCT`）→ 标「**贴身临界压制/支撑**」；贴身带强度缝（≥4&lt;10）走 soft/贴身路径并**豁免**战术 nearEps |
| 阻力软插 | 与支撑同构：有 primary 且已有形态阻力时即可尝试；**强度≥10 或贴身 CONTACT≥4** 不按 0.3% nearEps 丢弃；档位仍 ≤2 |
| 临界压制（战术） | 夹层弱共振强度 ≥约 **4** 且 **&lt; soft≥10**，或 VP VAH 叠层；非贴身可贴价约 **0.3%** 过滤（判距可用 `min(\|close−center\|,\|close−边界\|)`）；**不占**核心双档，结构块追加「日内/临界压制/支撑」一行 |
| 中线多空交织 | 同 status 且 `\|Δconf\| < RANK_CONF_TIE_EPS`（默认 **0.05**）且 `_biasConflicts` → 中线提示「多空形态交织，宜按宽幅箱体/震荡观察…」；**不**改 primary（置信优先不变） |

### 3.7 多形态关键位语义保留

近价合并容差约 **0.8%**。同价多来源展示名拼接，例如：

`双底:颈线 | 下降楔形:上沿`

不再用单一 prefer 名覆盖；`role` 仍取最高优先级（如「突破后转支撑」）。
