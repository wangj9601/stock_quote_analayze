# 江恩趋势预测 · 算法说明（V1）

个股分析（stock-ai）模块中的「江恩趋势预测」：基于与波段趋势同口径的 ZigZag 锚点，投影江恩角度线与时间窗口，并输出轻量 SVG 扇形几何（非完整蜡烛 K 线叠线）。

**免责声明**：几何参考，非投资建议。

## 与波段趋势的关系

| 项 | 说明 |
|----|------|
| 锚点来源 | 复用 `extract_zigzag_swing`（分形 + ZigZag 深度过滤 + `min_swing_bars`） |
| 波段方向 | 上涨波段 → 以**波段低点**为扇起点（上行扇）；下跌波段 → 以**波段高点**为起点（下行扇） |
| 差异 | 波段趋势侧重 HH/HL 结构标签；江恩侧重角度价位、时间窗与相对 1×1 的偏多/偏空解读 |

## 1×1 标定（scale）

- **含义**：每一根交易日对应的**价格单位**，用于把角度比换算成价格斜率。
- **默认**：自适应 — 优先用 Wilder ATR 的约 0.35 倍；不足时用近窗日均振幅；并设相对收盘价的下限。
- **覆盖**：API Query `scale` 可强制指定。
- **重要**：此处 1×1 **不是**屏幕上的 45° 视觉角，而是价格/时间坐标系中的比例。

斜率公式：

```
Δprice / bar = scale × (rise / run)
```

## 角度线

V1 固定五条：`1×1`、`2×1`、`1×2`、`4×1`、`1×4`。

- 上行扇：自锚点价格随交易日序号**向上**投影。
- 下行扇：自锚点价格随交易日序号**向下**投影。
- 输出基准日（asof）上的理论价，供表格展示。

## 趋势结论（相对 1×1）

比较现价（窗口末收盘）与 1×1 在 asof 的理论价：

- 带宽：`max(收盘×0.5%, ATR×0.5)` 内 → **贴近1×1**
- 上行扇：现价在 1×1 上 → 偏多；下 → 偏空
- 下行扇：现价在 1×1 下 → 偏空；上 → 偏多（空头角度削弱）

## 时间窗口

自锚点起计交易日：`+45 / +90 / +144 / +180 / +360`。

状态：

- `passed`：目标索引已落在历史窗口内
- `near`：距基准日约 ±5 根（已过）或未来 ≤10 根
- `upcoming`：仍在未来（无交易日历外推时目标日可为空，仅保留相对根数）

## 扇形几何（`fan_geometry`）

后端直接给出画图点列，前端不重算斜率：

- 锚点坐标、各射线 `start` / `end` / `asof_point`（`bar_offset`, `price`）
- 建议纵轴 `y_min` / `y_max`、现价、扇向
- 可选 `zigzag_overlay`（相对锚点的折线示意）

前端用轻量 SVG（对齐波段 ZigZag「示意非蜡烛」风格）绘制。

## API

`GET /api/analysis/gann-trend/{code}`

| Query | 说明 |
|-------|------|
| `asof` | 基准日 |
| `lookback` | 日线回看（默认 180） |
| `adjust` | `none` / `qfq` |
| `scale` | 可选覆盖 1×1 单位 |

权限：`channel.analyze.tab.stock_ai`
