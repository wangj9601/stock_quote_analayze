# 个股分析 · 综合交易策略规则说明

本文说明分析页「综合交易策略」区块中**每一项参数如何得出**，对应实现：

| 层级 | 路径 |
|------|------|
| API | `POST /api/analysis/stock-integrated-trade-plan` |
| 合成 | `backend_core/analysis/integrated_trade_plan.py` → `build_integrated_trade_plan` |
| 买卖建议 | `backend_core/analysis/trade_advice.py` → `build_trade_advice` |
| 前端展示 | `frontend/js/stock_trade_plan.js` |

> **定位**：规则模板合成的短线 / 中长线**参考**，整合四策略命中、结构位、形态战术、波段趋势与江恩几何结论，**不构成投资建议**。

---

## 1. 总体数据流

```
前端「分析」
  ├─ 四策略包 strategy_pack（URT / GMS / SBBR / RPE 命中摘要 + 原始行）
  ├─ 结构位 levels（支撑/阻力、Fib/Cam/Pivot、成交量分布、共振带）
  ├─ 形态战术 pattern.tactical（短线偏向等）
  ├─ 波段趋势 swing（日/周线市场结构）
  └─ 江恩 gann（偏向、临近时间窗）
        ↓
build_integrated_trade_plan(ctx)
  1) 按优先级选出「主策略」
  2) 用主策略行 + 结构参考位 → build_trade_advice（买卖区/止损/止盈/信心）
  3) 叠加形态 / 日周线 / 江恩 → 冲突列表、信心下调、中长线立场
  4) 组装短线块 + 中长线块 + 关键位 + 证据链
        ↓
StockTradePlan.render 展示徽章与表格
```

无前端快照时，服务端会现场重算策略包（`collect_strategy_raw_rows`），再合成。

## 2. 顶部徽章（总览）

### 2.1 短线立场 `stance_short` / `stance_short_label`

| 取值 | 界面文案 | 含义 |
|------|----------|------|
| `buy` | 买入/承接 | 主策略给出可执行买点（或左侧/右侧买点） |
| `watch` | 观察 | 无正式买点，或仅有结构观察区 |
| `avoid` | 回避 | 策略建议回避（较少） |
| `sell` | 减仓/离场 | 策略卖点主导（较少单独作短线立场） |

**来源**：`build_trade_advice(...).action`。  
四策略均未命中时强制为 `watch`，并生成「结构观察区」（非正式买点）。

### 2.2 中长线立场 `stance_medium` / `stance_medium_label`

由**周线趋势**与**江恩偏向**合并：

| 周线 `trend` | 映射 |
|--------------|------|
| `uptrend` | bull / 偏多 |
| `downtrend` | bear / 偏空 |
| `transition` | neutral / 转换观察 |
| `range` | neutral / 震荡 |
| `insufficient` 等 | neutral / 样本不足 |

| 江恩 `bias` | 映射 |
|-------------|------|
| `bull` | bull / 江恩偏多 |
| `bear` | bear / 江恩偏空 |
| `near` | neutral / 江恩临界 |
| `neutral` | neutral / 江恩中性 |

**合并规则** `_merge_medium_stance`：

- 仅有 bear、无 bull → `bear`
- 仅有 bull、无 bear → `bull`
- 否则（含对立）→ `neutral`

界面标签多为「周线标签 / 江恩标签」拼接，例如「偏空 / 江恩偏空」。

### 2.3 信心 `confidence`

| 取值 | 界面 |
|------|------|
| `high` | 高 |
| `medium` | 中 |
| `low` | 低 |

**初始**：来自 `build_trade_advice`（默认 `medium`）。

**策略侧常见下调为 low**（举例）：

- GMS：出现卖点且仍判买；或主行业板走弱（`board_weak`，买点可降为观察）
- URT：过热 hard 标；风险标签触发等
- 未知策略 / 异常路径

**共振对齐可上调**：止损或止盈与共振带同向贴近时，`medium` → `high`（软融合，不改主结构依据）。

**合成阶段再调整**：

| 条件 | 调整 |
|------|------|
| 形态短线「看空」且短线 action=`buy` | 记冲突，信心 → `low` |
| 形态短线「看多」且 action=`watch` 且信心为 low | 可抬至 `medium` |
| 短线 `buy` 且中长线 `bear` | 记冲突；若信心为 high → 降至 `medium` |

### 2.4 主策略 `primary_strategy` / `primary_strategy_name`

在四策略摘要中，按固定优先级取**第一个命中**者：

```
URT → GMS → SBBR → RPE
```

- 均未命中 → `none` / 「无命中」
- 名称取该策略摘要里的 `name`（如「GMS 均值引力动量」）

界面「主旋律」即此字段。截图示例主策略为 GMS，说明当日 URT 未命中、GMS 命中。

## 3. 关键位（支撑 / 现价 / 阻力）

字段：`key_levels.support` / `close` / `resistance`。

### 3.1 现价 `close`

从结构位快照按序解析（有则停）：

`current_price` → `realtime_price` → `last_close` → `close`  
→ 再尝试经典结构里的 `last_close` / `anchor_price`。

### 3.2 支撑 / 阻力

优先**共振支撑/阻力带中心**（`confluence_zones.nearest_*_zone.center`），否则退回：

- `nearest_support` / `nearest_resistance`

这些价位通常来自 KDE/箱体结构引擎；Fib、Camarilla、Pivot、成交量分布（VP）等进入「参考摘要」，一般**不直接改写**关键位数字（见 §5）。

无策略命中时，关键位仍用上述结构位填充，便于观察。

## 4. 短线策略表

对应 `short_term`：

| 表项 | 字段 | 含义 |
|------|------|------|
| 入场/承接（或「观察区」） | `entry_zone`（= advice.`buy_zone`） | 买点或结构观察区 |
| 止损参考（或「失效参考」） | `stop_zone` | 防守失效价 |
| 止盈参考（或「压力观察」） | `take_profit` | 目标/压力 |
| 要点列表 | `triggers` | 操作提示 |
| 段落摘要 | `summary` | 策略说明 + 参考位文案 |

当 `stance_short=watch` 且 `entry_zone.basis=structure_watch` 时，表头改为「观察区 / 失效参考 / 压力观察」，强调**非正式买点**。

### 4.1 无策略命中时的结构观察区

- **观察入场**：支撑 × `(1±1.5%)` 带宽，标签含「结构支撑观察区（非买点）」
- **失效参考**：支撑 × `0.98`（约下移 2%）
- **压力观察**：取结构阻力
- **摘要**：提示临近支撑时观察企稳、未触发策略买点前不宜追涨

### 4.2 主策略 = GMS

| 信号 | 行为 |
|------|------|
| 左侧买（`left_buy_signal` 或 `buy_type=左侧`） | action=`buy`；入场锚在结构支撑附近分批承接；可按「距第一支撑过近」改用第二档支撑 |
| 右侧买（`right_buy_signal` 或 `buy_type=右侧`） | action=`buy`；文案「右侧动量：突破后回踩不破支撑再跟」；入场常锚定现价附近 |
| 卖点 `sell_signal` | 写入卖出触发；若仍为买则信心 → low |
| 主行业板走弱 `board_weak` | 信心 → low；买点可降为 `watch` |

止损默认：结构支撑 × `(1 - 2%)`（`URT_STOP_BUFFER_PCT=0.02`，与 URT 缓冲同口径）。  
止盈默认：靠近结构压力减仓/止盈。

### 4.3 主策略 = URT

- 有 `buy_signal` → action=`buy`
- 入场：支撑 / MA20 与现价构成可执行带宽；过热或距支撑过远时强调**回踩再接**、不追高
- 距第一支撑过近（约 3% 内）时可改用**第二档支撑**作入场参考
- 止损：支撑下方约 2% 缓冲，且买入下沿须高于止损约 0.5%（不可执行窄带会加宽）
- 止盈：结构阻力或百分比目标（与 structure_exit 回测口径对齐）

### 4.4 主策略 = SBBR / RPE

同样走 `build_trade_advice` 分支：以策略买点 + KDE/箱体支撑阻力为主，形态战术可软合并；止损须低于买入下沿。细节见该文件中对应 `kind` 分支。

### 4.5 短线 `triggers` 组装（合成层）

在 advice 基础上追加，例如：

- `buy`：加入「买入区企稳后可分批建仓」及 buy_zone / take_profit 的 label
- `watch`：加入「等待策略买点或形态确认后再介入」；若为结构观察区再强调「非策略正式买点」

## 5. 技术参考位（摘要中的 Fib / Cam / Pivot / VP / 共振）

这些出现在 `summary` 拼接文案中（界面常跟在 GMS/URT 说明后），来自结构位快照的 `reference_levels`：

| 参考 | 典型字段 |
|------|----------|
| Fib | `nearest_fib_support` / `nearest_fib_resistance` |
| Camarilla | `nearest_cam_support` / `nearest_cam_resistance` |
| Pivot | `nearest_pivot_support` / `nearest_pivot_resistance` |
| Volume Profile | `poc`、`nearest_vp_support` 等 |
| 共振带 | `confluence_zones` 最近支撑/压力带中心 |

**规则要点**：

1. **主依据**仍是策略信号 + KDE/箱体结构支撑阻力。  
2. Fib/Pivot/Cam/VP：**软参考**，写入摘要提示，默认**不覆盖**主止损。  
3. **共振带软对齐**：与 KDE 同向贴近时，可把展示价对齐到带中心，并可能把信心 `medium`→`high`；对齐后仍强制「止损 < 买入下沿」。

截图中「Fib支撑 / Cam支撑 / Pivot / VP POC / 共振支撑·压力」即上述参考摘要，不是独立硬交易信号。

## 6. 中长线策略

对应 `medium_term`：

| 表项 | 字段 | 来源 |
|------|------|------|
| 趋势立场 | `bias_label` | 同 §2.2（周线 + 江恩） |
| 回撤观察 | `watch_zone` | 策略 horizon.medium_term.watch，否则 advice.deeper_watch；无则结构支撑观察 |
| 持仓计划 | `holding_plan` | 见下 |
| 离场触发 | `exit_triggers` | 见下 |
| 摘要 | `summary` | 持仓计划前若干句 |

### 6.1 持仓计划文案

按中长线立场模板：

- **偏多**：回踩关键均线或结构支撑不破可持有或分批加仓  
- **偏空**：反弹至压力附近宜减仓，不宜重仓抄底  
- **中性**：区间操作，突破/跌破结构再顺势  

若有 MA20，追加「MA20≈x 作趋势回撤观察」。  
可再附策略中期 watch 标签、形态战术 `mediumTerm` 文案（截断）。

### 6.2 离场触发 `exit_triggers`

合并来源：

1. `advice.sell_triggers` 的 label（策略卖点等）  
2. 周线偏空时：「周线趋势转弱或跌破最近 HL 结构」  
3. 江恩临近时间窗（最多 3 个）  
4. 跌破止损参考区  

截图「策略卖点触发… / 周线趋势转弱… / 跌破止损参考…」即此类规则。

## 7. 冲突提示 `conflicts`

合成时写入的典型冲突（界面红色/警告条，并影响信心）：

| 条件 | 提示方向 |
|------|----------|
| 形态短线看空 + 策略买点 | 形态偏空与买点并存，宜降仓或等待确认 |
| 日线偏多 + 周线偏空（或 swing 自带逆势注记） | 短线与中长线节奏不一致 |
| 日线偏空 + 周线偏多 | 宜等日线企稳再跟 |
| 短线买点 + 中长线偏空 | 宜小仓或快进快出 |

截图底部「短线有买点但中长线偏空，宜小仓或快进快出」即最后一类冲突文案。

| 止盈 -- | 当时无可用结构压力或未算出目标 |
| Fib/Cam/Pivot/VP/共振一行 | reference_levels 软参考摘要 |

## 9. 常量速查（买卖建议）

| 常量 | 约值 | 用途 |
|------|------|------|
| `ALIGN_TOL_PCT` | 1.5% | 价位与参考对齐容差 |
| `URT_STOP_BUFFER_PCT` | 2% | 止损相对支撑缓冲 |
| `URT_ENTRY_ABOVE_STOP_PCT` | 0.5% | 买入下沿须高于止损 |
| `URT_ENTRY_MIN_WIDTH_PCT` | 3% | 可执行入场带最小宽度 |
| `STRUCTURE_ENTRY_NEAR_SUPPORT_PCT` | 3% | 距第一支撑过近则改第二档 |
| 无命中观察带宽 | ±1.5% | 结构观察区 |
| 无命中失效 | 支撑 × 0.98 | 观察失效参考 |

## 10. 维护说明

- 改短线买卖数字逻辑 → 优先改 `trade_advice.py`  
- 改徽章、冲突、中长线文案、主策略优先级 → 改 `integrated_trade_plan.py`  
- 改展示文案/表头 → 改 `stock_trade_plan.js`  
- 单测：`test/test_integrated_trade_plan.py`、`test/test_gms_trade_price_plan.py`（及相关 trade_advice 用例）
