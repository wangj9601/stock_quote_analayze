# 板块中长线 / 短线入场闸门（v1 约定）

本文档固化 grill 共识：**板级三态闸门**，供策略过滤与展示；**不**产出板级买卖点。  
**实现状态（2026-11-12）：** 已落地于 `backend_core/board_gates/`（与 v2 同批）；默认 **shadow**（`board_gate.hard_filter_enabled=false` / 环境变量 `BOARD_GATE_HARD_FILTER`）。以代码与配置为准，差异回写本文。

---

## 1. 目标与定位

| 项 | 约定 |
|----|------|
| 产物 | 板块入场闸门：`可配` / `观望` / `回避` |
| 用途 | 作为 GMS / RPE / LDS 等策略前的过滤与降权依据 |
| 非目标 | 不给出「板块买卖点」；真正下单信号仍在板内个股策略 |
| 上线 | 先 **shadow**（只算态、对照展示），再打开硬过滤 |
| 持久化 | 按交易日、按板落库闸门快照（证据位、确认计数、asof） |

### 与现有能力关系

| 现有能力 | 关系 |
|----------|------|
| `board_env` / `sector_slope` 多窗 | **价**证据直接复用走强/走弱与阈值 |
| `board_fund_flow_daily` | **量**证据（日/近 5 / 近 20 合计） |
| 复盘主线 / `rotation` | 短线**情绪**（概念为主） |
| `board_trend_*` | 中长线结构标签（禁止「长弱短强」当中长线可配） |
| GMS `board_weak` 软减分 | v1 目标演进为：`回避` 硬过滤、`观望` 降权、`可配` 全量 |

## 2. 时间窗与标的范围

| 周期 | 交易日量级 | 斜率窗 | 标的 |
|------|------------|--------|------|
| 短线 | 约 1～10 日 | 5 / 10 | 行业 + 概念 |
| 中线 | 约 20～60 日 | 20 / 60 | 行业（观察池） |
| 长线 | 约 60～120 日+ | 60 / 120 | 行业（观察池） |

- **中长线闸门**：仅 `trade_observe_flag=true` 的**行业**板；概念**不**出中长线 `可配`。
- **短线闸门**：行业与概念均跑。
- 斜率阈值与 R² 下限对齐 `backend_core/board_metrics/sector_slope_store.py`：

| 窗口 | 走强斜率阈值 | R² 下限 |
|------|--------------|---------|
| 120 | 0.0008 | 0.25 |
| 60 | 0.001 | 0.30 |
| 20 | 0.0012 | 0.35 |
| 10 | 0.0015 | 0.40 |
| 5 | 0.002 | 0.50 |

## 3. 状态机与确认

- 输出离散三态，不做 0–100 连续评分卡（v1）。
- **短线**：连续 **2** 个交易日满足才升 `可配`；连续 **2** 日破坏才降 `回避`；中间为 `观望`。
- **中长线**：同上逻辑，确认天数 **3**。
- 既非可配也非回避 → `观望`。

### 缺数策略

| 情况 | 处理 |
|------|------|
| 无有效 `sector_slope`（或样本/R² 不足导致不可用） | 该周期最高 `观望` |
| 短线缺 `main_net_inflow` | **禁止**短线 `可配` |
| `slope_source=equal_weight_return` | 中长线 `可配` 须更严：近 20 日资金合计 **> 0**（不仅 ≥ 0） |

### 跨周期冲突

| 中长线 | 短线 | 动作 |
|--------|------|------|
| 可配 | 回避 | 允许持有/低仓跟踪；**禁止**新开/加仓 |
| 回避 | 可配 | 仅超短/快进快出；仓位上限更低或策略降权 |
| 其他组合 | — | 按各自状态：回避硬过滤、观望降权、可配全量 |

## 4. 短线闸门

证据三端：**价 / 量 / 情绪**；`可配` 至少 **2** 端成立（缺资金则不可可配）。

### 4.1 证据定义

| 端 | 条件 |
|----|------|
| **价** | `board_env_5` 或 `board_env_short(10)` 为走强，且对应窗斜率 ≥ 0 |
| **量** | 当日 `main_net_inflow > 0`，且近 5 日合计 ≥ 0 |
| **情绪（概念）** | 当日主线命中（涨幅 Top15 ∪ 资金 Top10），或近 10 日主线计数 ≥ 2 |
| **情绪（行业）** | 涨幅进入观察池前列，或板内涨停/领涨结构可用（实现时与复盘行业确认口径对齐） |

资金硬条件用**符号/合计**，**不**要求进入资金流 TopN；Top 榜仅作情绪/主线。

### 4.2 `可配` / `回避`

- **可配**：三端至少两端成立，且通过 2 日确认；有资金数据且量端规则可判定。
- **回避**（任一，经 2 日确认）：
  - 5 与 10 窗均为走弱（斜率 < 0）；或
  - 当日净流入 < 0 且近 5 日合计 < 0；或
  - 概念：`rotation.dropped` 且当日资金净流出。

---

## 5. 中长线闸门（仅观察池行业）

### 5.1 `可配`（经 3 日确认）

同时满足：

1. **价**：`board_env(60)` 走强；且 `board_env_120` 为走强，或至少非走弱（斜率 ≥ 0；假强 `strong_low_r2` 按中性/不可当走强）。
2. **量**：近 20 日 `main_net_inflow` 合计 ≥ 0（等权斜率来源时须 **> 0**）。
3. **结构**：`board_trend_*` 为「全面走强 / 中强短修 / 长强短弱」等可保留可配；若为「**长弱短强**」→ **禁止**中长线可配（只走短线逻辑）。

估值、板级 RS：**v1 不做硬条件**。

### 5.2 `回避`（任一，经 3 日确认）

- 60 与 120 窗均为走弱；或
- 60 走弱且近 20 日资金合计 < 0；或
- trend 为明确长弱结构（全面走弱，或长弱且短线未形成稳定修复）。

## 6. 策略接法（硬过滤目标态）

| 闸门 | 策略行为 |
|------|----------|
| `回避` | 不产出 / 不展示该板**新买入**信号 |
| `观望` | 保留信号，标记降权 |
| `可配` | 全量 |

Shadow 阶段：仍按旧逻辑出信号，但并列展示闸门态与「若硬开将如何」。
