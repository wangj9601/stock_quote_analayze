# 板块入场闸门 v2 规划

承接 [`板块中长线与短线入场闸门_v1约定.md`](./板块中长线与短线入场闸门_v1约定.md)。  
v1：价量情绪三态闸门（现有斜率/资金/主线即可）。  
v2：为**中长线可配**补「相对强度 + 资金阶段 + 估值/景气」层，并反哺短线量端质量。

**原则：** 不推翻 v1 三态与冲突表；v2 指标以**加硬条件 / 加降级**为主，默认仍先 shadow。

**实现状态（2026-11-12）：** v2.1/2.2/2.3 已与 v1 同批接入日批（`fund_stage` → `board_fund_flow_features`；板 RS → `board_rs_ratings`；估值 → `board_valuation_daily`）。板 RS 当前主口径为同花顺指数日 K；等权回退未接。估值 ROE 为可选聚合。

---

## 1. 目标

| 目标 | 说明 |
|------|------|
| 减少中长线假可配 | 斜率走强但相对大盘/同业并不强、或资金一日游、或估值极端时降级 |
| 资金「阶段」可读 | 用持续流入/流出天数，替代仅看 5/20 日合计符号 |
| 与个股 RS 对齐语言 | 板级也有 1–99 或池内分位，便于和 `rs_ratings` 一起解释 |
| 仍不产出板级买卖点 | 买卖点继续在个股策略 |

---

## 2. 三支柱与推荐分期

按「零/少新采集 → 可派生 → 需质量治理」排序落地。

```
v2.1 资金持续度状态机  →  v2.2 板级 RS  →  v2.3 估值/景气闸
     （已有资金流日表）      （板日 K / 成分 RS）   （成分 PE/PB/财务）
```

| 阶段 | 主题 | 新采集？ | 主要服务 |
|------|------|----------|----------|
| **v2.1** | 资金持续度 / 轮动阶段 | 否 | 短线量端加严；中长线可配加「非一日游」 |
| **v2.2** | 板级相对强度 | 否（算） | 中长线可配/回避主证据之一 |
| **v2.3** | 板级估值与景气代理 | 基本否（聚合成份） | 中长线可配封顶/降级；极端估值回避 |

概念板：v2 仍**不出中长线可配**；v2.1 短线可用；v2.2 概念仅在有稳定日 K 或成分 RS 中位数时给**展示用**板 RS，不进硬闸。

## 3. v2.1 — 资金持续度状态机

### 3.1 数据

- 源表：`board_fund_flow_daily`（`main_net_inflow` 等）
- 无新采集；日批在闸门计算时派生并写入闸门快照（或独立 `board_fund_flow_features`）

### 3.2 派生字段（建议）

| 字段 | 定义 |
|------|------|
| `inflow_streak` | 截至 asof，连续 `main_net_inflow > 0` 的交易日数；当日 ≤0 则为 0 |
| `outflow_streak` | 连续 `main_net_inflow < 0` 日数 |
| `pos_days_5` / `pos_days_20` | 近 5 / 20 日净流入为正的天数 |
| `net_sum_5` / `net_sum_20` | 与 v1 相同的合计（可复用） |
| `fund_stage` | 见下 |

### 3.3 `fund_stage`（板级轮动阶段，展示 + 闸门）

| 阶段 | 粗规则（可调） | 含义 |
|------|----------------|------|
| `accumulate` | `inflow_streak≥3` 且 20 日合计≥0，短窗斜率未全面走强 | 吸筹/回流 |
| `markup` | `inflow_streak≥2` 且 5 或 10 窗走强 | 主升/加仓友好 |
| `distribute` | `outflow_streak≥2` 且价仍强或平 | 分流风险 |
| `decline` | `outflow_streak≥3` 或 20 日合计<0 且中长窗走弱 | 衰退 |
| `churn` | 其他（正负交错） | 震荡，偏观望 |

### 3.4 接入闸门（相对 v1 的增量）

| 闸门 | v2.1 增量 |
|------|-----------|
| 短线 `可配`·量端 | 在 v1「当日>0 且近5合计≥0」之上，增加 **`inflow_streak≥2` 或 `pos_days_5≥3`**（二选一满足即可，避免过严） |
| 短线 `回避` | 增加：`outflow_streak≥3` 且 5/10 未走强 |
| 中长线 `可配` | 增加：禁止 `fund_stage∈{distribute, decline}`；且 **`pos_days_20≥8`**（约 40% 正向日）或 `inflow_streak≥3` |
| 中长线 `回避` | 增加：`fund_stage=decline` 且 60 窗非走强 |

Shadow 期只写字段与「若启用将降级」标记，不改硬过滤。

## 4. v2.2 — 板级相对强度（Board RS）

### 4.1 推荐算法（与个股 RS 同构）

对**行业板**官方/同花顺指数日收（`industry_board_historical_quotes`）：

```
ROC(n) = I_t / I_{t-n} - 1
RS_Raw = 0.4×ROC(63) + 0.2×ROC(126) + 0.2×ROC(189) + 0.2×ROC(252)
board_rs_rating = 截面百分位 → 1–99
```

- 截面宇宙：当日有有效 `RS_Raw` 的**行业板**（优先 `trade_observe_flag=true` 子集内再排一列 `board_rs_observe` 供闸门用）
- 指数不足时：回退成分股前复权**等权**收益链（与斜率 `equal_weight_return` 同源），并打 `rs_source` 标记；等权来源的中长线可配更严（与 v1 斜率政策一致）
- **不要**简单把成分 `rs_ratings` 平均当主口径（市值/停牌偏差大）；可另存 `member_rs_median` 作对照展示

落库建议：`board_rs_ratings`（`board_kind, board_code, trade_date, rs_raw, rs_rating, rs_source, universe`）。

工作流：挂在 `cn_board_historical` / 斜率刷新之后，与 `rs_rating_cn` 并列的日终节点。

### 4.2 接入闸门

| 闸门 | 条件（观察池分位 `board_rs_observe`，无则用全行业 `board_rs_rating`） |
|------|------|
| 中长线 `可配` | **`≥70`**（与个股「偏强」档对齐） |
| 中长线 `可配` 降级 | 50–69 → 最多 `观望`（除非 v1 价量极强且 `fund_stage=markup`，仍建议观望） |
| 中长线 `回避` | **`<30`** 且（60 走弱或 `fund_stage=decline`） |
| 短线 | **不**把板 RS 作硬条件（偏中期动量）；仅展示 |

### 4.3 与现有能力边界

| 能力 | 区别 |
|------|------|
| 个股 `rs_ratings` | 股票截面；板 RS 是板指数截面 |
| RPE `z_score` | 个股相对本板；板 RS 是板相对其他板 |
| `sector_slope` | 绝对趋势斜率；板 RS 是相对排名 |

中长线理想形态：**斜率走强 ∩ 板 RS 高分位 ∩ 资金非 distribute/decline**。

## 5. v2.3 — 估值 / 景气代理

### 5.1 数据（优先聚合，不新开外网主题库）

| 板指标 | 聚合法 | 源 |
|--------|--------|-----|
| `board_pe_median` | 成分股有效 `pe_dynamic` 中位数（剔负、剔极端分位） | 个股实时/日行情字段 |
| `board_pb_median` | 成分 `pb_ratio` 中位数 | 同上 |
| `board_roe_median` | 成分最新 `stock_fina_indicator.roe` 中位数 | 财务表 |
| （可选）盈利/营收增速 | 有字段再加；无则 v2.3 不做硬依赖 | 财务表 |

另算观察池内 **估值分位**：`pe_pct` / `pb_pct`（该板中位数在观察池横截面的百分位）。

质量规则：有效成分估值覆盖率 &lt; 50% → 估值层**不参与**硬闸，只标 `valuation_unknown`。

### 5.2 接入闸门（保守，防误杀成长板）

估值**不单独决定可配**，只做封顶与回避：

| 规则 | 动作 |
|------|------|
| `pe_pct` 或 `pb_pct` ≥ 90（池内极贵）且板 RS &lt; 80 | 中长线最高 `观望` |
| 极贵且 `fund_stage=distribute` | 中长线 `回避` |
| `pe_pct` ≤ 20 且 60 走强且板 RS≥70 | 允许作为可配的**加分叙事**（展示）；v2.3 仍不因便宜而放宽斜率/RS |
| `valuation_unknown` | 忽略本层，回退 v2.1+v2.2 |

景气：若后续有统一「盈利上修/增速」字段，再单开 `earn_stage`；v2.3 首版以估值分位 + ROE 中位数展示为主。

## 6. v2 合成逻辑（中长线）

在 v1 价量与确认天数之上：

```
中长线可配 =
  v1 价条件
  ∧ v1 量合计条件（及 equal_weight 更严）
  ∧ 非「长弱短强」
  ∧ v2.1 资金阶段允许
  ∧ v2.2 板 RS ≥ 70
  ∧ v2.3 估值未触发封顶/回避
```

任一 v2 层数据缺失：该层跳过并记 `degraded`，**不得**因缺失而自动当通过（与 v1 缺斜率→最高观望 一致的精神：关键层缺失则不能升可配）。

建议关键层优先级：`斜率(v1) > 板RS(v2.2) > 资金阶段(v2.1) > 估值(v2.3)`。  
即：无板 RS 时中长线最高观望；无资金阶段特征时同；无估值时可配（不阻塞）。

## 7. 落库 / 工作流 / 展示

| 项 | 建议 |
|----|------|
| 特征表 | `board_gate_daily` 扩展列，或分表 `board_fund_flow_features` / `board_rs_ratings` / `board_valuation_daily` |
| 调度 | 资金特征与闸门同批；板 RS 节点在板历史之后；估值聚合在成分与行情就绪后 |
| UI | 板块分析 / 复盘：三态旁展示 `fund_stage`、板 RS、估值分位、degraded 原因 |
| 策略 | 仍先 shadow；v2 硬条件与 v1 硬过滤同一开关或子开关 `board_gate_v2_enabled` |

---

## 8. 明确不进 v2 的范围

- 宏观利率、大宗商品、北向按板块持久标签
- 机构持仓/舆情主题库
- 概念板中长线可配
- 板级独立买卖点评分卡（0–100 连续分）——若要做标为 **v3 可选**

---

## 9. 依赖与验收

| 前置 | 说明 |
|------|------|
| v1 shadow 可用 | 日闸门快照、证据位、确认计数已跑通 |
| 板历史质量 | 行业同花顺日 K 覆盖率达标，否则板 RS 大面积 equal_weight |
| 成分映射 | `industry_board_constituents` 与估值字段更新频率可接受 |

| 验收（建议） | |
|--------------|--|
| v2.1 | 对照报表：启用持续度后，中长线可配数量下降，且「次日即转回避」比例下降 |
| v2.2 | 板 RS 与 60/120 走强一致性；高 RS 板后续 20～60 日相对弱势板的超额（粗回测） |
| v2.3 | 极贵封顶触发率可控；成长行业（如贵但 RS 高）不被系统性误杀 |

## 10. 待你拍板的默认（已写入本文的推荐）

若无异议，实现时按下列默认：

1. 板 RS 主口径 = 板指数 IBD 公式，观察池内再分位  
2. 中长线可配 RS 门槛 = 70；&lt;30 叠加弱势 → 回避  
3. 估值只封顶不开放；覆盖不足则跳过估值层  
4. 资金阶段进硬条件，但短线量端用「streak 或 pos_days」宽松或  

有分歧再单独开一轮 grill；否则 v1 编码完成后按 2.1→2.2→2.3 排期。
