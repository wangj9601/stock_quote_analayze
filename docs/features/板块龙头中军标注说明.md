# 板块龙头/中军标注说明

> **完整业务规则（产品/业务口径）请见：[板块龙头中军业务规则.md](./板块龙头中军业务规则.md)**  
> 下文为简要入口与实现索引；规则细节以业务规则文档与代码为准。

## 口径

- **偏短线领涨**：板内当日涨幅为主（成交额弱加权），涨停代理加分；不使用 RPE 日线比价 Z。
- **兼顾市值**：流通市值分位 + **绝对市值硬门槛**（龙头 ≥30 亿、中军 ≥80 亿），避免小票虚高「龙头」。
- **中军**：取消市值分位上限，超大市值跟涨亦可入选（仍须涨幅分位与绝对市值）。
- **过滤**：ST 名称剔除；`change_percent < 0` 不标角色；小样本护栏（`N<3` 不标，`N<8` 至多 1 龙头）。
- **板块来源暂定同花顺**：默认 `tonghuashun`；失败不静默回退东财。
- **不落库**：按最新 `stock_realtime_quote` 现算。
- **二期**：首封时间 / 板内最早封板加分（本轮仅涨停布尔代理）。

## 综合分（默认）

`score = min(100, 0.70 * 涨幅分位 + 0.20 * 成交额分位 + 0.10 * 流通市值分位 + 涨停加分12)`

龙头/中军门槛、Top-K、双龙头、数量上限等见 [板块龙头中军业务规则.md](./板块龙头中军业务规则.md) 第 5～7、11 节。
