# 板块龙头/中军标注说明

> **完整业务规则（产品/业务口径）请见：[板块龙头中军业务规则.md](./板块龙头中军业务规则.md)**  
> 下文为简要入口与实现索引；规则细节以业务规则文档与代码为准。

## 口径

- **偏短线领涨**：板内当日涨幅为主（成交额弱加权），不使用 RPE 日线比价 Z。
- **兼顾市值**：流通市值分位作资格门槛与弱加权，避免小票虚高「龙头」。
- **板块来源暂定同花顺**：`industry_board_basic_info` / `concept_board_basic_info` 的 `board_code_source`（`tonghuashun` / `eastmoney` / …）。默认 `tonghuashun`。
- **不混口径**：请求指定来源解析失败时不静默回退东财成分；可用同名映射到同花顺板码。
- **不落库**：按最新 `stock_realtime_quote` 现算。

## 与东财实时板表的关系

`industry_board_realtime_quotes` 为东财采集的板涨幅/领涨字段，**不能**直接当作同花顺板涨幅。同花顺角色只基于同花顺成分 + 个股实时行情；板强度估计为成分涨幅中位数（`board_change_percent_est`）。

## API

- `GET /api/market/industry_board/{board_code}/stocks|top_stocks?board_code_source=tonghuashun&board_name=`
- `GET /api/market/concept_board/{board_code}/stocks|top_stocks?board_code_source=tonghuashun&board_name=`

返回字段含：`board_role`（`leader`/`mid`）、`board_role_label`、`board_role_score`、`role_reason`、`board_code_source`。

## 展示入口

- **选股**：GMS/URT 在 `scope=industry_board|concept_board` 时挂 `role_tags`（与 `risk_tags` 分离），参数 `board_code_source` 默认同花顺。
- **管理端**：`板块成分股维护` 右侧成分列表在股票名称旁显示「龙头/中军」标签并高亮行；`GET /api/admin/board-constituents/list` 支持 `board_code_source`。
- **行情页**：成分 / top 列表展示龙头/中军 chip。

## 综合分（默认）

`score = 0.70 * 涨幅分位 + 0.20 * 成交额分位 + 0.10 * 流通市值分位`

龙头/中军门槛、数量上限、并列规则等见 [板块龙头中军业务规则.md](./板块龙头中军业务规则.md) 第 6～7、11 节。
