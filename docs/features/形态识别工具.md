# 形态识别工具

## 入口

分析页 → **技术工具** → **形态识别** →「使用工具」  
深链：`analysis.html?tab=technical-tools&tool=pattern`

## 能力

| 模式 | 说明 |
|------|------|
| 个股识别 | 输入代码/名称或自选，按日线识别所选形态族 |
| 扫描 | 全市场（限量）或行业/概念板块成分并集扫描 |

形态族：

- **双顶双底**：双底复用 DBLB 检测器；双顶为镜像规则
- **头肩顶底**：ZigZag 五枢轴几何 + 颈线突破确认
- **三角形**：上升 / 下降 / 对称（高低枢轴回归线收敛）
- **楔形旗形**：同向收敛楔形；旗形为「旗杆+短轴通道」简化规则

## API

- `GET /api/analysis/patterns/meta`
- `GET /api/analysis/patterns/{code}?types=&asof=&lookback=&adjust=`
- `POST /api/analysis/patterns/scan`  
  body：`scope`、`board_codes`、`types`、`asof`、`limit`（≤200）、`timeout_sec`、`adjust`

价格口径（与阻力支撑位 levels 一致）：

| 参数 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `adjust` | `none` / `qfq` | `none` | `qfq`=前复权现算 OHLC 后再跑检测器；A 股与港股（港股因子 `akshare_sina_hk_qfq`） |

因子持久化：`ensure_adj_factors` 优先读 `stock_adj_factor`；库无再拉外网并 UPSERT（A 股新浪/BaoStock；港股 `stock_hk_daily` qfq-factor，5 位码 + `source=akshare_sina_hk_qfq`）。同表多源靠 `(code, trade_date, source)` 隔离。

响应含 `price_adjust`；个股 `adjust=qfq` 时可选返回 `adj_meta`（因子源等）。前端「前复权」勾选默认开启，请求时传 `adjust=qfq`。

权限：`channel.analyze.tab.technical.btn.pattern` / `...pattern_scan`

## 返回字段

`pattern_family`、`pattern_type`、`status`（`forming` / `confirmed` / `invalidated`）、`confidence`、`key_levels`、`pivots`、`reason`（说明：枢轴/关键价位旁带日期，如 `左肩=44.97(2026-03-12)`；斜率标注单位 `元/K线索引(约交易日)`，自变量为枢轴的 K 线 index）、`formed_at`（形成/关键日：有突破确认日则用确认日，否则取枢轴最晚日）、`key_dates`（各枢轴 role+date）、可选 `confirm_date`

默认 API/`detect_all` **不返回** `invalidated`（失效）项；前端列表与专家解读亦忽略失效。

## 关键阈值（统一）

| 规则 | 条件 | 说明 |
|------|------|------|
| 巩固形态上破确认 | `last_close > upper × 1.005` | 楔/旗/三角 |
| 巩固形态下破确认 | `last_close < lower × 0.995` | 楔/旗/三角 |
| 底部形态失效 | 形成中且 `last_close < 头/低点 × 0.99` | 头肩底、双底 |
| 顶部形态失效 | 形成中且 `last_close > 头/高点 × 1.01` | 头肩顶、双顶 |
| 楔旗同界 NMS | 上下沿相对差均 ≤ 1%，且枢轴日期区间重叠 | 下降楔↔下降旗、上升楔↔上升旗；优先已确认，其次高置信 |

实现见 `backend_core/analysis/chart_patterns/rules.py` 与 `engine.nms_wedge_flag_overlaps`。

## 形态专家解读

个股识别有命中时，结果表下方展示「形态专家解读」（`#patternExpertAnalysis`）：

- **短期走势**：直接读取 `status`；已确认巩固（如上破下降楔）写明突破方向，**禁止**再写「方向尚未定，宜等待边界有效突破」
- **中线格局**：侧重高置信已确认；已确认偏多巩固与已确认偏空反转并存时写入冲突提示（以更高置信为主）
- **关键位置参考**：从 hits 的 `key_levels` / `pivots` 提炼可操作价位（颈线、双峰/双谷、头肩高低点、楔旗三角上下沿等），近价去重后按价格升序；标注来源形态；形成中或低置信标「观察中」；现价相对最近关键位一句带过
- **后续交易点位参考**：以 `last_close` 分界，下方支撑/上方阻力各取 1～2 档最有意义价位（优先颈线翻支撑、峰谷/头、通道上下沿），给出区间与 bullet；已确认且上沿/颈线落在现价下表述为「突破后翻支撑」；单侧无档则提示等待边界突破
- **风险提示**：非投资建议、日线规则局限

由前端规则引擎根据 `pattern_type`、`status`、`confidence`、`key_levels`、`formed_at`、`last_close` 拼装，不调用外部 LLM。多形态并存时优先已确认且置信度更高者；扫描模式仅提示前往个股识别获取完整解读。

## 限制

- 仅日线 OHLC，非分时；可选前复权（A 股 / 港股），与 levels 同因子链路（港股用 `stock_hk_daily` qfq-factor）
- 扫描有数量与超时上限，全市场会截断；扫描模式下单票因子失败则跳过该票
- 旗形为简化启发式，误报可能偏高；同界重叠由 NMS 压掉一条
- 首期结果以表格为主，不含图上画线
- 专家解读为规则模板文案，不构成投资建议
