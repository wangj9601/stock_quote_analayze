### 已识别形态清单（现行）

日线 OHLC；默认一次跑齐 **5 个形态族、13 种具体形态**（与 `GET /api/analysis/patterns/meta` 一致）。可用 `types` 按族筛选。

| 形态族 (`pattern_family`) | 具体形态 (`pattern_type`) | 中文 | 类型倾向 | 检测模块 |
|---------------------------|---------------------------|------|----------|----------|
| `double_extremes` | `double_bottom` | 双底 | 反转·偏多 | `double_extremes.py`（复用 DBLB） |
| | `double_top` | 双顶 | 反转·偏空 | 同上（镜像规则） |
| `head_shoulders` | `head_shoulders_bottom` | 头肩底 | 反转·偏多 | `head_shoulders.py` |
| | `head_shoulders_top` | 头肩顶 | 反转·偏空 | 同上 |
| `triangle` | `ascending_triangle` | 上升三角 | 巩固·偏多 | `triangles.py` |
| | `descending_triangle` | 下降三角 | 巩固·偏空 | 同上 |
| | `symmetrical_triangle` | 对称三角 | 巩固·中性 | 同上 |
| `wedge_flag` | `falling_wedge` | 下降楔形 | 巩固·偏多 | `wedges_flags.py` |
| | `rising_wedge` | 上升楔形 | 巩固·偏空 | 同上 |
| | `bull_flag` | 上升旗形 | 巩固·偏多 | 同上（旗杆+短轴通道启发式） |
| | `bear_flag` | 下降旗形 | 巩固·偏空 | 同上 |
| `cup_handle` | `cup_with_handle` | 带柄茶杯 | 巩固·偏多 | `cup_handle.py`（杯身+浅柄启发式） |

形态族要点：

- **双顶双底**：双底复用 DBLB 检测器；双顶为镜像规则；同窗双顶+双底可交织降权为「箱体震荡」
- **头肩顶底**：ZigZag 五枢轴几何 + **斜颈线**收盘破位确认（历史破颈锁存，反弹不得改回 `forming`）
- **三角形**：上升 / 下降 / 对称（高低枢轴回归线收敛）
- **楔形旗形**：同向收敛楔形；旗形为「旗杆+短轴通道」简化规则。楔形拟合与展示共用近端 3 高 3 低；另校验端点方向与斜率收敛（见 `WEDGE_*`），不满足则不产出楔形
- **带柄茶杯**：左沿→杯底→右沿→浅柄；确认看收盘上破柄/沿上沿；柄破杯底结构则失效

**未覆盖**（常见经典形态，现行引擎不产出独立 `pattern_type`）：三重顶底、圆弧顶底、独立矩形箱体、扩散三角、岛型反转等。算法细节与后处理见 [支撑阻力与形态识别_算法说明.md §3](./支撑阻力与形态识别_算法说明.md#3-形态识别)。

## API

- `GET /api/analysis/patterns/meta`
- `GET /api/analysis/patterns/{code}?types=&asof=&lookback=&adjust=`
- `POST /api/analysis/patterns/scan`  
  body：`scope`、`board_codes`、`types`、`asof`、`limit`（≤200）、`timeout_sec`、`adjust`

价格口径（与阻力支撑位 levels 一致）：

| 参数 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `adjust` | `none` / `qfq` | `none` | `qfq`=前复权现算 OHLC 后再跑检测器；A 股与港股（港股因子 `akshare_sina_hk_qfq`） |

因子持久化：`ensure_adj_factors` 优先读 `stock_adj_factor`；库无再拉外网并 UPSERT（A 股新浪/BaoStock；港股 `stock_hk_daily` qfq-factor，5 位码 + `source=akshare_sina_hk_qfq`）。同表多源靠 `(code, trade_date, source)` 隔离。

响应含 `price_adjust`；个股 `adjust=qfq` 时可选返回 `adj_meta`（因子源等）。前端「前复权」勾选默认开启，请求时传 `adjust=qfq`。

权限：`channel.analyze.tab.technical.btn.pattern` / `...pattern_scan`

## 返回字段

`pattern_family`、`pattern_type`、`status`（`forming` / `confirmed` / `invalidated` / `archived`）、`confidence`、`key_levels`、`pivots`、`reason`（说明：枢轴/关键价位旁带日期，如 `左肩=44.97(2026-03-12)`；斜率标注单位 `元/K线索引(约交易日)`，自变量为枢轴的 K 线 index）、`formed_at`（形成/确认日：有突破确认日则用确认日，否则取枢轴最晚日）、`key_dates`（各枢轴 role+date）、可选 `confirm_date`

默认 API/`detect_all` **不返回** `invalidated`（失效）项；前端列表与专家解读亦忽略失效。`archived`（已归档）列表可见，但不参与主形态竞争。个股/扫描响应另含 `invalidated_count`（过滤前失效条数），便于空列表时提示「有效命中 0（另有 N 条已失效）」。

## 关键阈值（统一）

| 规则 | 条件 | 说明 |
|------|------|------|
| 巩固形态上破确认 | `last_close > upper × 1.005` | 楔/旗/三角（预期上破者） |
| 巩固形态下破确认 | `last_close < lower × 0.995` | 楔/旗/三角（预期下破者） |
| 巩固形态反向脱离 | 预期上破却有效下破，或预期下破却有效上破 | 标为 `invalidated`（默认列表不展示）；避免「形成中」滞留 |
| 底部形态失效 | 双底：形成中且 `last_close < 低点 × 0.99`；头肩底：右肩完成后任一 `low`/`close` < 头 × 0.99（优先于颈线确认） | 头肩底、双底 |
| 顶部形态失效 | 双顶：形成中且 `last_close > 高点 × 1.01`；头肩顶：右肩完成后任一 `high`/`close` > 头 × 1.01（优先于颈线确认） | 头肩顶、双顶 |
| 头肩几何 | 头相对两肩深度 ≥`HS_HEAD_MIN_DEPTH_PCT`（默认 3%）；两肩高差 ≤8%；颈线两峰相对差 ≤`HS_NECK_ASYMMETRY_MAX`（默认 22%，抑制双底+虚高均价颈线） | 头肩顶/底 |
| 头肩斜颈线 | 两峰线性插值/外推为斜颈；破位按**当日斜颈阈值**收盘确认；外推至 ≤`HS_NECK_COLLAPSE_FLOOR`，或相对两颈点过低（`<min×HS_NECK_EXTRAP_LO_FRAC`，顶/底对称），或底相对过高（`>max×HS_NECK_EXTRAP_HI_FRAC`）→ **invalidated**（展示用右肩日斜颈/两峰均值，禁止负/近零颈线）；`neck_left`/`neck_right` 仍保留 | 顶/底对称 |
| 头肩破颈锁存 | 右肩后**任一收盘**破当日斜颈即 `confirmed` 并记 `confirm_date`/`confirm_neckline`；此后反弹/回落不得改回 `forming` | 顶/底对称；与双顶/双底历史破颈口径一致 |
| 头肩失败破位归档 | 顶：最低 `< 颈线 × 0.95` 且现价 `> 颈线 × 1.02`；底：最高 `> 颈线 ÷ 0.95` 且现价 `< 颈线 ÷ 1.02` | `forming`/`confirmed` 均可；标 `archived`（失败破位） |
| 头肩远距反抽归档 | confirmed：现价相对确认颈线反向偏离 ≥`HS_CONFIRM_FAR_RECOVER_PCT`（默认 8%）；顶 `last≥neck×1.08`，底对称 | 强制归档；优先于「失败反抽」文案 |
| 头肩失败反抽归档 | confirmed：破颈后现价回颈线另一侧，且（逼近/超过右肩±2% **或** 反抽幅度 ≥ 约 2.0×ATR） | 不回 `forming`；仅「任意回到颈线上方」不触发 |
| 头肩 forming 超时 | 右肩后 ≥90 根仍未收盘破颈 | 辅规则；标 `archived`（可关：`HS_FORMING_TIMEOUT_BARS=0`） |
| 双顶双底同窗交织 | 活跃（非 invalidated/archived）双顶与双底日期跨度重叠 | `confidence` cap 至 ≤0.45，reason/key_levels 标交织并写入 `box_low`/`box_high`、`range_label=箱体震荡`；tactical `bias_mix` 偏震荡且 `bias_label` 为「箱体震荡」 |
| 巩固形态同源 NMS | 上下沿相对差均 ≤ 1%，**或**高/低枢轴价序列同源；且枢轴日期区间重叠 | 下降楔↔下降旗、上升楔↔上升旗、**下降楔↔上升旗**、**上升楔↔下降旗**、下降三角↔下降楔、上升三角↔上升楔；选取：已确认 → 三角/楔斜率几何 → **楔优先于反向简化旗** → 高置信；保留项注明同源 |
| 反转形态生命周期 | ①测幅目标兑现（颈线±形态高度×0.9，不依赖 45 根）；②后续反向已确认巩固突破则旧反转降权；③兜底：自形成日起 ≥45 根 K，有利方向 ≥25%，且相对极值回吐 ≥50% | 标为 `archived`（已归档），不参与专家主形态竞争；列表仍可见 |

实现见 `backend_core/analysis/chart_patterns/rules.py`、`engine.nms_overlapping_patterns`、`lifecycle.apply_pattern_lifecycle`、`head_shoulders.py`。

默认参数（`rules.py`）：

| 常量 | 默认 | 含义 |
|------|------|------|
| `HS_HEAD_MIN_DEPTH_PCT` | `0.03` | 头相对两肩最小深度 |
| `HS_NECK_ASYMMETRY_MAX` | `0.22` | 颈线两峰最大相对差 |
| `HS_SHOULDER_TOL_PCT` | `0.08` | 两肩相对高差上限 |
| `HS_FAIL_DEPTH_MULT` | `0.95` | 失败破位深破阈值 |
| `HS_FAIL_RECOVER_MULT` | `1.02` | 失败破位回抽足够远 |
| `HS_FAIL_PULLBACK_ATR_MULT` | `2.0` | confirmed 失败反抽：反抽/回撤 ≥ 约 N×ATR |
| `HS_FAIL_RS_NEAR_PCT` | `0.02` | confirmed 失败反抽：逼近右肩相对容差 |
| `HS_CONFIRM_FAR_RECOVER_PCT` | `0.08` | confirmed 远距反抽强制归档（相对确认颈线） |
| `HS_NECK_COLLAPSE_FLOOR` / `EXTRAP_LO/HI` | `0.01` / `0.35` / `2.5` | 斜颈外推崩塌（过低顶底对称；底过高） |
| `HS_FORMING_TIMEOUT_BARS` | `90` | forming 未破颈超时（0=关闭） |
| `LIFECYCLE_TARGET_RATIO` | `0.9` | 测幅兑现比例 |
| `LIFECYCLE_MIN_BARS` / `MIN_EXCURSION` / `GIVEBACK` | `45` / `0.25` / `0.5` | 回吐归档兜底 |

共振带：支撑/压力按带中心相对现价划分后，**支撑带 high 裁到 ≤ 现价、压力带 low 裁到 ≥ 现价**（`confluence_zones._clip_zone_to_price_side`）。列表可按 `max_each`（默认 3）取 TopN；**近端密集簇兜底**（默认 `near_pct=2.5%`，且 `n_points≥3` 或 `sources≥2`）强制纳入并参与 `nearest_*` 选取，避免远端高强度带截断后近端消失。

## 形态专家解读

典型产品场景与四维映射（突破测幅 ACHIEVED、无主形态真空、多层攻防/贴身临界、失败反抽归档、筹码 VAL 无承接、上破阻力真空降级、同 conf 多空交织等）见 [支撑阻力与形态识别_算法说明.md §1.1](./支撑阻力与形态识别_算法说明.md#11-典型场景与引擎行为)（**详见总览四维闭环**）。

个股识别有命中时，结果表下方展示「形态专家解读」（`#patternExpertAnalysis`）：

- **主形态选取**：同 status 下 **Confidence desc** → 仅当 `|Δconf| < RANK_CONF_TIE_EPS`（默认 0.05）时才用 `e^(-λ·Δt)` 弱 tie-break（`λ` 默认 `0.012`）→ `formed_at` desc；**confirmed 优先于 forming**。兼容分 `FinalScore ≈ confidence × W_status × exp(-λ·Δt)` 仅供调试，排序不再单靠该分让新低 conf 压过旧高 conf。归档/失效不进排序。形成中反转超过约 60 日龄视为过期，**不**选作主形态。
- **真空兜底**：活跃池为空或仅过期/失败 forming 时，主形态写「暂无主导形态」，不把旧顶/旧底写成主导；短/中线可写「结构整理期，跟踪多维量化共振带」；结构防守块注入 `confluenceZones` 近端带（个股分析路径若有 `lastLevels.confluence_zones`）；形态工具单独调用无共振数据则只改占位语义、不编假价。
- **已兑现背景**：最近 `archived` 反向/测幅形态可写一句背景，不抢主形态。
- **短期走势**：直接读取 `status`；已确认巩固（如上破下降楔）写明突破方向，**禁止**再写「方向尚未定，宜等待边界有效突破」
- **短期三态 `tactical`**：结构买点 `invalidation` 须低于 `entry_zone.low`（约 1% 取严）；双顶双底互斥时专家区展示「箱体震荡 low–high」，中线优先箱体文案
- **中线格局**：侧重高置信已确认；压短边界/现价堆砌；已确认偏多巩固与已确认偏空反转并存时，**以后续巩固突破为主**（旧反转若测幅已兑现应由后端归档）；冲突提示写入解读；双顶双底 `bias_mix` 时优先「箱体震荡」而非仅「交织」
- **结构防守与目标**（合并原「关键位置参考」+「后续交易点位参考」）：以 `last_close` 分界分层展示——**防守/支撑** → **目标/近端形态阻力**。**主形态几何边界强制为第一候选**（巩固 upper/lower；反转颈线按侧），补第二档**近距优先**（同分再语义），巩固通道沿距现价 ≤约 3% 可保送；已确认上破后上沿作翻支撑；阻力空档时若已确认上破，**禁止**写「等待形态边界突破」，改为「形态边界已上破；上方暂无形态内阻力档…」；下破对称。巩固类前端简化测幅：`H=upper−lower`，上破目标≈`upper+H`、下破≈`lower−H`，文案标明「按边界高度」；**有活跃形态档用形态，真空（无主形态档）时用 `confluenceZones` 多维共振带整侧兜底**（标注强度；无共振数据则只改占位语义、不编假价）；有清晰主形态时**不**把汇合区硬盖形态边界，软融合的 `pattern_lower`/`pattern_upper` 取 **primary 几何边界**，夹层强度≥`CONFLUENCE_SOFT_BUFFER_MIN_STRENGTH`（默认 10）候选中**近端优先**（同分再强度）软插入「近端缓冲」或「贴身临界压制/支撑」（`high>close`/`low<close` 且 dist&lt;约 0.5%），形态边界保留为「核心破位防守 / 核心形态阻力」（档位仍 ≤2；**soft≥10 不被**战术 0.3% nearEps 静默丢弃）；夹层弱共振（默认强度≥`CONFLUENCE_TACTICAL_CAP_MIN_STRENGTH`≈4 且低于 soft）可追加「日内/临界压制/支撑」战术行、**不占**双档席位；同 status 且 `|Δconf|<0.05` 且 bias 冲突时中线可提示「多空形态交织…」（不改 primary）
- **空头反转文案分层**：`rel.side==='above'` 时按距颈线幅度分档（远离 / 逼近右肩），**禁止**大偏离仍写「附近」；逼近/超过右肩或大幅偏离时降偏空语气。多头「颈线下方」对称。
- **风险提示**：非投资建议、日线规则局限

由前端规则引擎根据 `pattern_type`、`status`、`confidence`、`key_levels`、`formed_at`、`last_close` 拼装，不调用外部 LLM。多形态并存时按上述竞选规则排序；扫描模式仅提示前往个股识别获取完整解读。个股分析 PDF（`stock_analysis_pdf.js`）与页面共用 `buildExpertAnalysis` / `formatExpertPlainText` 字段，含结构防守与目标；PDF/嵌入可传入 `confluenceZones`。

## 限制

- 仅日线 OHLC，非分时；可选前复权（A 股 / 港股），与 levels 同因子链路（港股用 `stock_hk_daily` qfq-factor）
- 扫描有数量与超时上限，全市场会截断；扫描模式下单票因子失败则跳过该票
- 旗形为简化启发式，误报可能偏高；同界重叠由 NMS 压掉一条
- 首期结果以表格为主，不含图上画线
- 专家解读为规则模板文案，不构成投资建议
- 头肩失败破位/超时阈值偏保守，可通过 `rules.py` 参数收紧或放宽；过松会误杀仍在构筑的形态
