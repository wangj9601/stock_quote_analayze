# 同域用户站与管理端登录说明

## 背景

用户站（如 `https://www.icemaplecity.com/`）与管理端（如 `https://www.icemaplecity.com/admin/`）为**同一站点（同一 Origin）**。浏览器按 **Origin** 划分 `localStorage`，不按路径划分，因此两端读写的是**同一块本地存储**。

## 令牌存储

| 端       | 主要 localStorage 键 |
|----------|----------------------|
| 用户站   | `access_token`、`userInfo` 等 |
| 管理端   | `admin_token`、`admin_user` 等 |

JWT 相互独立，键名不同，**不会**因互相覆盖而串号；问题在于历史上若对用户站执行 **`localStorage.clear()`** 或整页清空脚本，会**一并删除**管理端键，表现为管理端「突然掉线」或像 session 冲突。

## 当前行为（修复后）

1. **用户站 `login.html`**：仅在进入登录页时移除用户登录相关键（`access_token`、`userInfo`、`token`），**不**清空整块 `localStorage`，**不**清空 `sessionStorage` 与全站 Cookie。
2. **用户站退出**：仅移除用户站及旧版遗留键，**保留** `admin_token`、`admin_user`，以便同浏览器会话内管理端仍保持登录（若需同时退出管理端，请在管理端单独退出）。

## 可选架构

若希望两端存储完全隔离，可将管理端部署到独立子域（如 `admin.icemaplecity.com`），并相应调整 CORS、Cookie `Domain` 与 Nginx 配置。
