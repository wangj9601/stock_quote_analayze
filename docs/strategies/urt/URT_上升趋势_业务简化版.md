# URT 上升趋势策略（业务简化版）

这版给业务同学看：找什么票、何时算「正式买点」、推送里多出来的票是什么意思、买后怎么管。

更细公式与工程设计：[URT_STRATEGY_IMPLEMENTATION_DESIGN.md](./URT_STRATEGY_IMPLEMENTATION_DESIGN.md)  
回测买卖与观察期：[URT策略交易回测说明.md](./URT策略交易回测说明.md)

---

## 1. 一句话理解

找已经**站上中期均线**、近期**连续收阳**、且当天**明显放量**的股票，等右侧「趋势确认」再考虑入场。

主目标是「上升趋势右侧确认」，不是抄底，也不是左侧吸附（与 GMS 不同）。

---

## 2. 适用场景

| 适合 | 不太适合 |
|------|----------|
| 已走出底部、均线附近转强的票 | 跌破均线、阴跌缩量的票 |
| 想看「趋势 + 量能」是否共振 | 只想抄最低点 |
| A 股日线选股 / 自选股盯盘 / 日终推送 | 把港股混进 A 股 URT 推送池 |

默认覆盖沪深主板、创业板、科创板、中小板、北证等 **6 位码 A 股**（可按板块再筛）。名称含 ST 的不进候选池。

---

## 3. 选股在看什么（硬筛三关 + 得分）

出「正式买点」要两步都过：

1. **硬筛全部通过**（MA20、短连阳、量能；可选换手/量比；可选中期阳线/多头）  
2. **得分 ≥ 最低分**（默认 **70**）

### 第一关：站上 MA20

- 用收盘价算简单均线（默认 **20** 日）
- 要求：**收盘价 ≥ MA20**

业务理解：价格至少回到中期均线上方，才谈「上升趋势」。

### 第二关：连阳（两套规则，满足其一即可）

阳线判定：收盘价 **高于** 开盘价。

| 规则 | 默认要求 |
|------|----------|
| 规则 A | 近 **4** 个交易日里，阳线 ≥ **3** 根 |
| 规则 B | 近 **5** 个交易日里，阳线 ≥ **4** 根 |

业务理解：不是要求天天大阳，而是近期多数日子收阳，说明多头占优。

### 第三关：量能放大

- 量能倍数 = 当日成交量 ÷ 近 **20** 日均量（均量**不含当日**）
- 默认要求：量能倍数 ≥ **2.5**

业务理解：趋势确认最好伴随放量，避免无量假突破。

> **量能 ≠ 量比**：量比是「当日量 ÷ 前一日量」。默认**不参与**硬筛与加分；管理端可单独打开。

### 增强观察：中期阳线 & 均线多头（默认不硬筛）

列表与得分明细会展示：

| 项 | 默认含义 | 硬筛 |
|----|----------|------|
| 10 / 15 / 20 日阳线数 | 衡量中期阳线密度；硬筛开启时默认 ≥6 / ≥8 / ≥10 | 管理端开关 `use_yang_medium`，默认关 |
| 均线多头 | 默认 **MA5 > MA10 > MA20** | 管理端开关 `require_ma_bull`，默认关 |

二者默认只参与**轻度加分**（中期阳线最多约 6 分、多头约 4 分），**不改变**现有「短连阳 + 站上 MA20 + 放量」买点定义。开启硬筛后买点会更少、更偏强趋势。

### 得分门槛（硬筛之后）

硬筛过了还要看综合得分。默认满分大致来自：

| 分项 | 大约能拿多少 | 业务含义 |
|------|--------------|----------|
| 站上 MA20 | 固定 **10** | 均线条件成立 |
| 连阳强度 | 最高约 **40** | 阳线越密、越连贯，分越高（如 5 日全阳约 40，4 日 3 阳约 30） |
| 量能倍数 | 最高约 **34** | 刚达 2.5 倍约 25+；放得更多可再加 |
| 中期阳线 | 最高约 **6** | 按 10/15/20 相对阈值完成度 |
| 均线多头 | 最高约 **4** | MA5>MA10>MA20 则满分 |
| 换手 / 量比 | 各最多 **5** | 默认关闭；开启后才加 |

合计封顶 **100**。  
**正式买点**还要求得分 ≥ `min_score`（默认 **70**）。

可选：管理端打开「换手 / 量比 / 中期阳线硬筛 / 多头硬筛」后，对应项会进入硬筛。

## 4. 「正式买点」和「连阳补充收录」有啥区别

| | 正式买点（是否买点 = 是） | 连阳补充收录（是否买点 = 否） |
|--|--------------------------|------------------------------|
| 条件 | 硬筛全过 **且** 得分够 | 通常只满足连阳（4 日≥3 阳或 5 日≥4 阳），量能/均线/得分未必全过 |
| 选股页默认结果 | 全市场/板块扫描主要吐这类 | 一般不当作「可交易买点」列表主结果 |
| 自选股日终推送 Excel | **一律收录** | 自选里非买点、但连阳过关的也会写入，方便提前观察 |
| 排序（推送） | 买点优先，再按得分从高到低 | 排在买点之后 |

业务话术：

- 「是否买点 = 是」→ 策略认为当天达到交易候选标准  
- 「是否买点 = 否」但仍出现在推送表 → **观察池补充**，不是正式买点  

回测只按**正式买点**入场（信号日次日开盘），不会把「连阳补充」当成买入信号。

---

## 5. 支撑 / 阻力怎么看

系统会算筹码密度峰式的支撑、阻力（与 RPE / 个股关键价位同口径），写在预计算与明细里，供参考。

**不参与硬筛**：站上支撑、盈亏比等**不是** URT 买点的必要条件（这点和 RPE 不同）。

---

## 6. 买后怎么管（纪律写在配置里）

选股只负责找买点；**持仓纪律主要在回测「纪律出场」模式里生效**。会议约定大致是：

| 动作 | 默认口径（业务理解） |
|------|----------------------|
| 价格止损 | 浮亏约 **5%～10%** 区间，实际离场按配置上限（常按约 **10%**） |
| 时间止损 | 连续收跌约 **3** 日 → 离场 |
| 止盈 | 涨约 **25%～30%** 进入警惕区后，自高点回撤约 **5%** → 止盈 |

回测另有「命中率」模式：默认观察约 **20** 个交易日、目标涨幅约 **10%**，期内**不止损**，用来统计有没有摸到目标，和「纪律出场」是两套口径。细节见回测说明专文。

## 7. 边界与常见误解

| 点 | 说明 |
|----|------|
| 港股 | 有独立港股预计算能力，但 **A 股 URT 自选推送池不收港股**；5 位港股码不会被补成 6 位 A 股码混进来 |
| 北交所 | 代码前缀可筛（如 43/83/87/88/92）；不传板块 = 与其他 A 股一并扫描 |
| ST | 名称含 ST 的不进候选池 |
| 0 条结果 | 硬筛 + 最低分都严，某些交易日全市场很少是正常的 |
| 单股「明细」 | 可查看未过筛的逐步判定；不等于当天给出了正式买点 |
| 与 GMS | URT 不做左侧吸附；日线现算均线与量能，不依赖 GMS 那套预计算指标表 |

## 8. 页面与入口

- 选股页「上升趋势」Tab：策略选股 / 导出  
- 结果「历史」：`stock_urt_trace.html`  
- 结果「明细」：`stock_urt_score_detail.html`（逐步硬筛与得分）  
- 管理端：`/urt-management`（参数版本、预计算、回测）  
- 日终：预计算建议约 **16:45**，`urt_daily` 推送建议约 **17:30**（须晚于预计算）

## 9. 和业务沟通时可直接复用的话术

- 「URT 是右侧确认：站上均线 + 连阳 + 放量，再看得分够不够。」  
- 「推送表里『是否买点=否』是连阳观察补充，不是正式买点。」  
- 「港股不会进 A 股 URT 推送；别把 5 位码当成 A 股看。」  
- 「回测命中率和纪律出场是两套口径，对客户说明时不要混着讲。」
