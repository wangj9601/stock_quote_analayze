## 一、策略定义（Upward Right-side Trend）

本策略旨在针对中国 **A 股、港股** 市场的日线交易特性，通过监测中期均线站位、近期连续收阳结构与当日量能放大，识别**右侧趋势已确认**的短线交易机会，建立一套可量化的入场与退出决策体系。

本策略核心在于：**先做硬性条件过滤，再做百分制评分排序，并以结构位置与过热程度作为硬性否决闸门**。系统不追求左侧“均值吸附”式抄底，而是等待价格站上中期均线、连阳结构成立、资金放量确认后再给出正式买点。方法论目的在于构建“趋势确认 → 结构风控 → 纪律/结构出场”的闭环，并配合过热减仓提示与回测验证，实现对风险与收益的平衡管理。

与系统内 **GMS（均值引力与动量突变）** 的关系：

| 对比项 | GMS | URT |
|--------|-----|-----|
| 覆盖逻辑 | 左侧均值收敛 + 右侧动量溢出（双轨） | **仅右侧**趋势确认 |
| 评分形态 | 双模块阶梯分，取较高者排序 | 单轨百分制 + 硬筛/硬闸 |
| 数据主源 | 含独立指标表等 | 日 K 现算（A/港行情表） |
| 产品定位 | 均值引力与动量突变 | 上升趋势 |

## 二、投资理念与策略

- **趋势确认后再入场**：强调不抢左侧拐点，而在站上中期均线、连阳与放量同时成立时，认定趋势已由“酝酿”转为“确认”。
- **短线游击、控制持有周期**：默认以短线持有为假设，回测观察期缺省 **10 个交易日**；不长期持有单一标的。
- **止盈止损并重**：验证阶段以**结构出场**（支撑止损 / 阻力止盈）为主口径；另备纪律出场（固定止损 / 连跌 / 回撤）与命中率统计模式（仅用于目标触及率研究，不作实盘持有建议）。
- **化繁为简**：主逻辑回归日线 **价格与成交量**（均线、阴阳线、量能倍数、换手），辅以结构支撑/阻力与过热判定；不引入 GMS 式左侧轨或复杂双模块评分。

## 三、核心量化指标体系

策略基于日线 K 线现算指标（基准日为信号日，K 线序列以该日为最新）。核心指标定义如下：

| 符号 / 指标 | 定义 | 缺省窗口 / 阈值 |
|-------------|------|-----------------|
| MA20 | 收盘价简单移动平均 | 20 日；站上条件：收盘价 ≥ MA20 |
| 阳线 | 收盘价 > 开盘价 | — |
| 连阳规则 A | 近 N 日阳线数 ≥ M | N=4，M=3 |
| 连阳规则 B | 近 N 日阳线数 ≥ M | N=5，M=4 |
| 连阳硬筛 | A **或** B 任一通过 | — |
| 量能倍数 | 当日成交量 ÷ 近 N 日均量（**均量不含当日**） | N=20；硬筛阈值缺省 **3.0** |
| 中期阳线 | 近 10 / 15 / 20 日阳线数均达阈值 | 缺省 10≥6 / 15≥8 / 20≥10（须全部满足） |
| 均线多头 | MA5 > MA10 > MA20 | 缺省硬筛开启 |
| 换手率 | 当日换手率 | 硬筛缺省 ≥ **3%** |
| 结构支撑 / 阻力 | 与个股关键价位同口径（KDE / 共振等） | 信号日固化，持仓期默认不重算 |
| 结构盈亏比 RR | 上行空间 / 下行风险分母 | 偏低时提示，不单独否决买点 |
| 近窗涨幅 \(R_N\) | 相对近 N 日窗内最低价涨幅 | N=10；软提示 15%，硬闸 25% |
| MA20 乖离 | 收盘相对 MA20 偏离 | 软提示 15%，硬闸 20% |

频率：**日线、按交易日**。选股可指定基准日；若该日无行情则回退至表内最新交易日。

## 四、正式买点判定规则

### 4.1 正式买点定义

标的在指定交易日被判定为**正式买点（可交易候选）**，须**同时**满足：

```text
正式买点 = 硬筛全部通过
         AND 结构硬闸通过
         AND 过热硬闸通过
         AND 综合得分 ≥ 最低分（缺省 70）
```

仅正式买点可作为回测入场信号。日报中的「连阳补充」仅作观察，不构成入场条件。

### 4.2 默认硬筛条件

下列阈值为业务缺省口径，具体以管理端**生效参数版本**为准。

| 序号 | 条件 | 缺省要求 |
|------|------|----------|
| 1 | 站上均线 | 收盘价 ≥ MA20 |
| 2 | 连阳结构 | 近 4 日阳线数 ≥ 3，**或** 近 5 日阳线数 ≥ 4 |
| 3 | 量能放大 | 量能倍数 ≥ **3.0** |
| 4 | 中期阳线占比 | 近 10 / 15 / 20 日阳线数达到配置阈值（缺省开启，须全部满足） |
| 5 | 均线多头排列 | MA5 > MA10 > MA20（缺省开启） |
| 6 | 换手率 | 当日换手率 ≥ **3%**（缺省开启） |

### 4.3 结构硬闸（否决正式买点）

相对**最近**支撑 / 阻力判定（KDE 无效时不硬闸）：

| 情形 | 处理 |
|------|------|
| 破位支撑 | 否决正式买点 |
| 贴 / 超阻力 | 否决正式买点 |
| 上行空间不足 | 相对现价距最近阻力缺省 **&lt; 3%** → 否决 |
| 悬空离支撑 | 相对支撑过远（缺省约 **≥ 8%**）→ 否决 |
| 结构盈亏比 RR 偏低 | **仅提示**，不单独否决 |

### 4.4 过热硬闸与提示

| 类型 | 条件（缺省） | 处理 |
|------|--------------|------|
| 过热硬闸 | 近 10 日相对低点涨幅 ≥ **25%**，或相对 MA20 乖离 ≥ **20%** | **否决正式买点** |
| 过热提示 | 涨幅或乖离约达 **15%** 起 | 提示并扣分，影响排序，不单独构成硬闸 |

### 4.5 正式买点与连阳补充

| 对比项 | 正式买点 | 连阳补充（仅日报） |
|--------|----------|-------------------|
| 准入条件 | 硬筛 + 结构/过热硬闸 + 得分达标 | 未达正式买点，但满足连阳规则 |
| 是否买点 | 是 | 否 |
| 业务用途 | 可交易候选 | 观察池补充 |
| 回测入场 | 采用 | 不采用 |

### 4.6 判定流程（摘要）

```text
日线行情
  → 候选池过滤（剔 ST 等）
  → 硬筛（均线 / 连阳 / 量能 / 中期阳线 / 多头 / 换手）
  → 百分制得分
  → 结构硬闸（破位 / 贴阻力 / 上行不足 / 悬空）
  → 过热硬闸
  → 得分 ≥ min_score ?
        ├─ 是 → 正式买点（buy_signal = true）
        └─ 否 → 非买点（自选日报可作连阳补充观察）
```

说明：选股「全部 A 股 / 全部港股」默认**只返回正式买点**；自选 / 行业 / 概念 / 单股可返回含未过筛明细，是否买点仍以系统标志为准。

## 五、评分决策系统（满分 100）

为对通过硬筛的标的进行排序与阈值过滤，系统采用**单轨百分制**评分。得分达标仅为正式买点必要条件之一；**满分 ≠ 已贴近最优入场价位**，入场须结合结构位与买点标志审阅。

### 5.1 评分构成（缺省上限，约）

| 评估维度 | 逻辑指标 | 评分标准（满分约 100） | 说明 |
|----------|----------|------------------------|------|
| MA20 趋势 | 站上后乖离 + 近 5 日斜率 | 上限约 **10** | 未站上得 0；站上后按梯度给分 |
| 连阳天数 | 近窗阳线数 | 上限约 **20** | 连阳越充分分越高 |
| K 线实体质量 | 近窗实体比 + 突破波幅 | 上限约 **10** | 衡量阳线质量 |
| 量能倍数 | 当日量 / 近 20 日均量 | 上限约 **25** | 达硬筛阈值起分；约 **4.0** 倍附近拉满 |
| 中期阳线 | 10/15/20 日完成度 | 上限约 **5** | 相对阈值完成度等权 |
| 均线多头 / 空头 | MA 前缀链深度 | **+0～8 / −8** | 硬筛仍看 5/10/20；积分可看更长链 |
| 筹码位置与 RR | 贴近支撑 + 结构盈亏比 | 上限约 **15** | 贴近支撑约 0～8 + RR 约 0～7 |
| 换手率 | 相对近 20 日中位甜区 | **+8 / −8** | 过高或绝对极高等减分 |
| 量比（可选） | 当日量 / 前一日量 | 最多约 **5** | 默认不开启加分 |
| 过热扣分 | 近窗涨幅 / MA20 乖离 | 约 **−10～0** | 自软阈值起扣，逼近硬阈扣满 |

选股结果按**综合得分降序**排列。日报 Excel：先「是否买点」，再按得分（买点优先）。

### 5.2 执行标准（业务口径）

| 情形 | 口径 |
|------|------|
| 正式买点 | 硬筛 + 硬闸 + 得分 ≥ **70**（缺省） |
| 排序用途 | 得分用于候选排序与分桶分析，不单独替代硬闸 |
| 参数版本 | 权重与阈值可按管理端参数版本调整；改参后须预计算对齐 |

注：评分维度、权重与阈值需结合回测样本持续验证，后续可根据验证效果补充或调整（对齐 GMS 说明中的验证注记原则）。

## 六、风险管理与退出机制

### 6.1 买入规则（回测 / 交易纪律）

| 步骤 | 规则 |
|------|------|
| 信号日 | 当日判定为正式买点 |
| 入场日 | 信号日之后**下一交易日** |
| 入场价 | 该日**开盘价**（无效则跳过） |
| 观察期 | 缺省 **10** 个交易日 |
| 去重 | 同一标的在上一笔观察期结束前不再开新仓 |

### 6.2 目标涨幅判定（统计用）

| 配置 | 判定 |
|------|------|
| 上下限相等（缺省 **10%～10%**） | 观察期内最高价 ≥ 入场价 × (1 + 该值) → 计为命中 |
| 上下限不等（如 **5%～8%**） | 最大涨幅落在闭区间内才计为区间命中；冲破上限另计统计字段，不计入区间命中 |

### 6.3 三种出场模式

| 模式 | 目标 | 规则摘要 |
|------|------|----------|
| **命中率模式** | 统计目标触及率 | 观察期内**不止损**；满期以收盘价记参考出场。**不作实盘持有建议** |
| **纪律出场** | 可执行价格纪律 | 价格止损（缺省约 **−10%**）；连跌 **3** 日且浮亏 ≥ **4%**；浮盈达约 **8%～10%** 后自高点回撤 **5%** 止盈 |
| **结构出场**（当前验证重点） | 与选股结构位一致 | 止损：最近支撑下移约 **2%**；止盈：阻力（上行不足则改百分比跟踪）；可含分批、保本与峰值回撤保护；无有效结构时回退固定止损（约 **−8%**） |

策略建议优先验证**结构出场**的一致性；命中率模式仅用于对照“有没有摸到目标涨幅”。

### 6.4 持仓期保护（结构出场，摘要）

- 浮盈达约 **+6.5%** 后可武装保本 / 跟踪。  
- 阻力触及：默认可先平约 **50%**，余仓改移动止盈。  
- 同日优先级：先判保护 / 止损，再判阻力 / 百分比目标。

## 七、业务适用范围与作业节奏

### 7.1 适用范围

| 业务场景 | 适用范围 |
|----------|----------|
| 选股 | 全部 A 股、全部港股、用户自选、行业 / 概念板块、单股明细 |
| 日报推送 | 仅用户自选中的 **A 股**（正式买点 + 连阳补充） |
| 历史回测 | **仅 A 股** |
| 标的剔除 | 证券简称含「ST」的标的不进入候选池 |

### 7.2 A 股板块与候选过滤

- 选股支持主板 / 创业板 / 中小板 / 科创板 / 北证等代码段过滤（可多选并集；不选=不限）。  
- 港股不适用 A 股板块参数。  
- 单股明细解析以 **六位 A 股** 为主。

### 7.3 参数版本管理

1. 管理端维护多套策略参数版本；标记为默认 / 生效的版本，与前台日常选股及信号跟踪保持一致。  
2. 参数变更后，应对该版本执行信号预计算，以保证选股与缓存一致。  
3. 已生成的历史回测任务结果**不因**后续改参而自动重写。  
4. 回测若选用非生效版本或覆盖最低分等字段，系统标记为「已偏离生效配置」。

### 7.4 日终作业节奏（工作日）

| 作业 | 建议时点 | 说明 |
|------|----------|------|
| A 股信号预计算 | 约 **16:45** | 写入信号缓存，供选股加速与回测复用 |
| 港股信号预计算 | 约 **17:20** | 同上 |
| 自选股日报（urt_daily） | 建议约 **17:30** | 须晚于预计算；范围仅限自选 A 股 |

|-------------|------|
| 策略参数 | 新建与编辑参数版本；设置默认生效版本；保存后可触发信号预计算 |
| 回测管理 | 创建回测任务：区间日期、目标涨幅上下限、观察日数、股票池、出场模式、是否读取缓存、是否命中率对照等；任务列表展示完成时间 |
| 报告与分析 | 查阅历史回测报告、图表及分桶统计 |
| 操作记录 | 审计日志 |
| 信号预计算 | 按交易日、市场、参数版本补齐全市场信号缓存 |

全市场回测操作要求：应启用「优先读缓存」。关闭缓存时对全市场实时扫描耗时显著增加；首次无缓存时任务将自动补扫，耗时较长属预期行为。

### 9.3 数据流概要

```text
日线数据采集
    → 日终信号预计算
    → 信号缓存（urt_signal_trace）
         ├→ 用户选股 / 信号历史
         ├→ 回测（可读缓存）
         └→ 自选股日报推送 / 管理端报告导出
```

参数版本配置贯穿预计算、选股、回测及明细展示全流程。

## 十、验证结论与使用口径

### 10.1 已形成的验证结论

1. 以结构出场为主的全市场样本，在均盈亏、胜率、持有天数等指标上，整体优于早期纪律出场方案。  
2. 量能倍数低于 3.5 的样本占比较高且表现偏弱，宜优先评估提高量能硬筛阈值。  
3. 近支撑止损触发偏密，宜评估「止损相对入场价至少下移 3%～4%，否则回退固定止损」等规则。

### 10.2 汇报与使用口径

1. **命中率模式**仅用于统计观察期内是否触及目标涨幅，不构成实盘持有建议。  
2. **结构出场**与**纪律出场**更接近可执行交易路径，宜作为策略验证主口径。  
3. 全市场回测若信号量级异常偏低（如仅数十～三百笔而缓存声称已覆盖五千股），须核对参数版本、硬闸严格度及预计算是否与生效配置一致，不宜直接作为主结论。  
4. 目标涨幅已支持区间配置：缺省 10%～10%；配置为 5%～8% 时，表示最大涨幅须落在该区间内方计为区间命中。
