## 1. 概述

### 1.1 策略定位

本策略基于日线行情，筛选处于**右侧趋势确认**阶段的标的，作为短线交易候选。判定逻辑强调：价格已站上中期均线、近期收阳结构成立、当日成交量显著放大。

本策略**不属于**左侧抄底或均值回归类方法；与系统内 GMS 策略（左侧均值与右侧动量双轨）相互独立，URT 仅覆盖右侧趋势确认路径。

### 1.2 持有周期假设

默认以短线持有为假设，回测观察期缺省为 **10 个交易日**。实际持有与出场以回测任务所选模式及参数版本为准。

### 1.3 文档目的

本文说明策略定义、业务规则、已交付功能范围、前台与管理端操作入口，以及后续待优化功能与待跟踪事项，供管理层了解当前能力边界、使用方式与下一阶段排期重点。技术实现细节见文末相关文档清单。

## 2. 策略定义

### 2.1 正式买点（可交易候选）

标的在指定交易日被判定为正式买点，须**同时**满足下列条件：

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 硬筛全部通过 | 见第 2.2 节默认阈值 |
| 2 | 结构硬闸通过 | 破位、贴/超阻力、上行空间不足、悬空离支撑等情形予以否决 |
| 3 | 过热硬闸通过 | 短期涨幅过大或相对均线乖离过大予以否决 |
| 4 | 综合得分达标 | 得分 ≥ 最低分阈值（缺省 **70**） |

仅正式买点可作为回测入场信号；「连阳补充」仅用于日报观察，不构成入场条件。

### 2.2 默认硬筛条件

下列阈值为业务缺省口径，具体以管理端生效参数版本为准。

| 条件 | 缺省要求 |
|------|----------|
| 站上均线 | 收盘价 ≥ MA20 |
| 连阳结构 | 近 4 日阳线数 ≥ 3，**或** 近 5 日阳线数 ≥ 4 |
| 量能放大 | 当日成交量 ÷ 近 20 日均量 ≥ **3.0**（均量不含当日） |
| 中期阳线占比 | 近 10 / 15 / 20 日阳线数达到配置阈值（缺省开启） |
| 均线多头排列 | MA5 > MA10 > MA20（缺省开启） |
| 换手率 | 当日换手率 ≥ **3%**（缺省开启） |

### 2.3 评分与排序

| 项目 | 规则 |
|------|------|
| 评分体系 | 百分制，综合趋势、连阳、量能、结构位置与盈亏比、换手等因素，得分上限 100 |
| 买点判定 | 得分达标仅为必要条件之一；正式买点以系统 `buy_signal` 标志为准 |
| 结果排序 | 选股结果按综合得分降序排列 |

说明：高分并不等同于「已贴近最优入场价位」；入场建议须结合结构位与买点标志一并审阅。

### 2.4 结构与过热风控

| 类型 | 处理方式 |
|------|----------|
| 结构硬闸 | 相对最近支撑/阻力：破位、贴/超阻力、上行空间不足（缺省小于 3%）、离支撑过远等 → **否决正式买点** |
| 结构盈亏比（RR） | 偏低时予以提示，**不单独否决**买点 |
| 过热硬闸 | 近 10 日相对低点涨幅 ≥ 25%，或相对 MA20 乖离 ≥ 20% → **否决正式买点** |
| 过热提示 | 涨幅约达 15% 起提示并扣分，影响排序，不单独构成硬闸 |

### 2.5 回测交易规则

| 环节 | 规则 |
|------|------|
| 信号日 | 当日判定为正式买点 |
| 入场价 | 下一交易日开盘价 |
| 观察期 | 缺省 10 个交易日 |
| 目标涨幅 | 支持区间配置；缺省 **10%～10%**（最大涨幅不低于该值即计为命中）。若配置为 5%～8%，则最大涨幅须落在闭区间内方计为命中；冲破上限另计统计字段，不计入区间命中 |
| 出场模式 | （1）命中率模式：不计止损，用于目标触及统计；（2）纪律出场：固定止损 / 连跌 / 回撤；（3）结构出场：支撑止损 / 阻力止盈（当前验证重点） |

## 3. 业务规则

### 3.1 适用范围

| 业务场景 | 适用范围 |
|----------|----------|
| 选股 | 全部 A 股、全部港股、用户自选、行业/概念板块、单股明细 |
| 日报推送 | 仅用户自选中的 **A 股**（正式买点 + 连阳补充观察） |
| 历史回测 | **仅 A 股** |
| 标的剔除 | 证券简称含「ST」的标的不进入候选池 |

### 3.2 正式买点与连阳补充

| 对比项 | 正式买点 | 连阳补充（仅日报） |
|--------|----------|-------------------|
| 准入条件 | 硬筛 + 结构/过热硬闸 + 得分达标 | 未达正式买点，但满足连阳规则 |
| 是否买点 | 是 | 否 |
| 业务用途 | 可交易候选 | 观察池补充 |
| 回测入场 | 采用 | 不采用 |

### 3.3 参数版本管理

1. 管理端维护多套策略参数版本；标记为默认/生效的版本，与前台日常选股及信号跟踪保持一致。  
2. 参数变更后，应对该版本执行信号预计算，以保证选股与缓存一致。  
3. 已生成的历史回测任务结果**不因**后续改参而自动重写。  
4. 回测任务若选用非生效版本或覆盖最低分等字段，系统标记为「已偏离生效配置」。

### 3.4 日终作业节奏（工作日）

| 作业 | 建议时点 | 说明 |
|------|----------|------|
| A 股信号预计算 | 约 16:45 | 写入信号缓存表，供选股加速与回测复用 |
| 港股信号预计算 | 约 17:20 | 同上 |
| 自选股日报（urt_daily） | 建议约 17:30 | 须晚于预计算完成；范围仅限自选 A 股 |

## 5. 系统界面与操作入口

### 5.1 用户端

| 界面 | 入口 | 功能说明 |
|------|------|----------|
| 选股 · 上升趋势 | 选股页 → Tab「上升趋势」 | 选择范围（全市场 / 港股 / 自选 / 行业 / 概念 / 单股）、板块、参数版本并刷新筛选；可进入交易观察或正式交易 |
| 信号历史 | 选股结果或个股入口 → 信号追溯页 | 查看历史买点；支持强制重算；可发起单股回测 |
| 计算明细 | 得分明细页 | 查看得分构成、结构支撑/阻力、盈亏比、买点建议；可导出 PDF |
| 个股策略卡片 | 个股行情页 · URT 上升趋势 | 跳转信号历史或计算明细 |
| 邮件推送 | 推送配置 ·「自选股上升趋势策略信号列表」 | 日终 Excel 日报 |

操作要求：变更选股范围、板块、参数版本或相关筛选项后，须执行「刷新筛选」后方重新计算。

### 5.2 管理端

入口：管理后台 → **URT上升趋势策略**（路由 `/urt-management`）

| 页签 / 功能 | 说明 |
|-------------|------|
| 策略参数 | 新建与编辑参数版本；设置默认生效版本；保存后可触发信号预计算 |
| 回测管理 | 创建回测任务：区间日期、目标涨幅上下限、观察日数、股票池、出场模式、是否读取缓存、是否命中率对照等 |
| 报告与分析 | 查阅历史回测报告、图表及分桶统计 |
| 操作记录 | 审计日志 |
| 信号预计算 | 按交易日、市场、参数版本补齐全市场信号缓存 |

全市场回测操作要求：应启用「优先读缓存」。关闭缓存时对全市场实时扫描耗时显著增加；首次无缓存时任务将自动补扫，耗时较长属预期行为。

### 5.3 数据流概要

```text
日线数据采集
    → 日终信号预计算
    → 信号缓存（urt_signal_trace）
         ├→ 用户选股 / 信号历史
         ├→ 回测（可读缓存）
         └→ 自选股日报推送 / 管理端报告导出
```

参数版本配置贯穿预计算、选股、回测及明细展示全流程。

## 6. 验证结论与使用口径

### 6.1 已形成的验证结论

1. 以结构出场为主的全市场样本，在均盈亏、胜率、持有天数等指标上，整体优于早期纪律出场方案。  
2. 量能倍数低于 3.5 的样本占比较高且表现偏弱，宜优先评估提高量能硬筛阈值。  
3. 近支撑止损触发偏密，宜评估「止损相对入场价至少下移 3%～4%，否则回退固定止损」等规则。

### 6.2 汇报与使用口径

1. **命中率模式**仅用于统计观察期内是否触及目标涨幅，不构成实盘持有建议。  
2. **结构出场**与**纪律出场**更接近可执行交易路径，宜作为策略验证主口径。  
3. 全市场回测若仅得到数十条信号，通常表示缓存未覆盖全市场范围；应在生效参数版本下启用缓存并重跑，信号量级预期可达千级。  
4. 目标涨幅已支持区间配置：缺省 10%～10%；配置为 5%～8% 时，表示最大涨幅须落在该区间内方计为区间命中。

### 7.1 策略与回测规则（P1，建议优先）

| 序号 | 事项 | 状态 | 说明 |
|------|------|------|------|
| 1 | 提高量能硬筛阈值 | 待开发 | 当前缺省 3.0 倍；样本中 &lt;3.5 倍占比高、均盈偏低。建议先试硬筛 **3.5**，或以分层回测对照 |

## 8. 待跟踪事项

下列事项需在后续迭代中持续跟踪验证或闭环，不必然立即开发。

| 序号 | 跟踪项 | 责任侧重 | 跟踪要点 |
|------|--------|----------|----------|
| 1 | 结构出场主样本复验 | 策略 / 研发 | 以全市场、结构出场、观察期 10、生效参数版本 + 读缓存为基线；对照量能 3.5、止损最小距离、冷却规则等单变量改动 |
| 2 | 全市场缓存覆盖正确性 | 研发 / 运维 | 确认 `__URT_SCANNED__` 等占位不因股票池扫描冒充全市场已覆盖；全市场任务信号量级应至千级，而非数十条 |
| 3 | 参数版本与预计算一致性 | 运维 | 改参并设为生效后，须完成对应交易日预计算；避免前台选股与回测读到旧缓存 |
| 4 | 自选股结构出场小样本 | 策略 | 历史小样本曾出现「最大涨幅明显高于实际盈亏」；应用当前缺省观察期 10 与结构保护规则重跑验证 |
| 5 | 命中率模式使用边界 | 业务 / 管理 | 对外汇报与交易讨论中，明确命中率仅作统计对照，不以之为持有建议 |
| 6 | 产品缺口确认闭环 | 产品 | ETF、版本观察股池、港股回测/日报/单股等是否纳入，形成明确「做 / 不做」结论后更新本清单 |
| 7 | 回测报告归档口径 | 策略 | 关缓存或信号过少的任务不宜作为主结论样本；主结论任务须注明参数版本、出场模式、是否读缓存 |
| 8 | 与 GMS 能力边界 | 产品 / 研发 | 继续对齐选股—推送—回测能力面，但不引入左侧轨、MFR 或双模块评分体系 |

**建议下一轮最小验证包（结构出场）：**

1. 量能硬筛 3.5（或 ≥3.5 子样本）对照当前 3.0；  
2. 结构止损最小距离 3%～4% / 回退 −8%；  
3. 止损后冷却规则；  
4. 纪律出场新参仅作对照，不再作为主结论口径。
