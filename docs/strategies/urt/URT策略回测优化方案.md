## 2. 优化项与状态

| 优先级 | 项 | 状态 | 说明 |
|--------|----|------|------|
| P0 | 回撤武装 25%–30% → **8%–10%** | **已落地** | `risk.take_profit_alert_pct_*`；仍用峰值回撤 5% |
| P0 | 条件化连跌 3 日 | **已落地** | 连跌 3 日 **且浮亏 ≥4%** 才 `time_stop`（`time_stop_min_loss_pct`） |
| P0 | 默认观察期 20→**10** | **已落地** | 任务默认；`hit_rate` 对照仍可手填 20 |
| P1 | 结构出场全路径保本/回撤、阻力 5%+分批、pct 跟踪 | **已落地并验证** | `e4d3e04c`：均盈 0.94%、移动止盈占 47%；主结论继续用结构出场 |
| P1 | 量能硬筛/加权 | **下一轮必要** | 结构下 ≥5 倍 +2.19%，&lt;3.5 占 64% 仅 +0.61%。建议先试硬筛 3.5 或分层任务 |
| P1 | 结构止损过密（约 40%） | **下一轮必要** | 支撑过近易被洗；可要求止损相对入场至少下移 3%～4%，否则回退 −8% |
| P1 | 峰值回撤 4% 偏紧 | 待做 | 保护已触发但全样本回吐仍 ~11pp；可对已达 +10% 的余仓略放宽回撤 |
| P2 | 打分 | 部分 | 结构下高分更好（[90,100] +5%）；因子表仍因缺 `score_detail` 失效 |
| P2 | 止损后再进场冷却 | **必要（结构同样）** | 结构 2309 vs 命中率 2016，冷却按出场日导致同票回补 |
| P3 | 连跌叠加跌破 MA20 | 未做 | 当前用浮亏 4% 条件化，未接均线 |

**明确不做：** 不把持有期写进选股计分；不把 `hit_rate` 当实盘持有建议。

## 3. 本轮最小改动（纪律出场）

配置（`urt_config.json` / `config.py` 默认；**已保存的 DB 参数版本不会自动覆盖**，需在管理端改后保存或新建版本）：

| 键 | 原默认 | 新默认 |
|----|--------|--------|
| `risk.take_profit_alert_pct_min` | 25 | **8** |
| `risk.take_profit_alert_pct_max` | 30 | **10** |
| `risk.time_stop_min_loss_pct` | （无） | **4** |
| `risk.time_stop_down_days` | 3 | 3（不变） |
| `risk.trailing_drawdown_pct` | 5 | 5（不变） |

逻辑：`evaluate_exit_rules` — 连跌 streak 达标后须 `pnl_pct ≤ -time_stop_min_loss_pct`；回撤止盈自 `alert_min=8` 武装。

## 4. 建议下一轮回测

同一区间、全市场、**结构出场**、观察期 10（可关命中率对照）：

1. **量能：** 硬筛 `volume_multiple=3.5`（或只跑 ≥3.5 子样本）对照当前 3.0。
2. **结构止损：** 止损价相对入场下行不足 3%～4% 时改用 −8% 回退，看结构止损占比能否从 ~40% 下降、均盈是否升。
3. **冷却：** 结构止损后冷却至观察期末（或至少 5 日），看信号数是否回落到 ~2000、均盈是否升。
4. 纪律出场新参（8% 武装 + 连跌须亏 4%）仅作对照，不再当主结论。
