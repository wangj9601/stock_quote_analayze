## 1. 最新 A/B 样本（结构出场，2026-05-27～2026-08-12）

全市场 · 目标 10% · 观察 10 日 · min_score=70 · `use_trace=true` · 出场 `structure_exit`。

### 1.1 参数 A/B（出场 / 量能 / 得分）

| 方案 | 信号 | 命中率 | 胜率 | 均盈亏 | 备注 |
|------|------|--------|------|--------|------|
| **A0 基线（当前默认）** | 698 | 43.84% | **55.16%** | **1.33%** | 移动止盈 53.4% |
| A1 量能硬筛 ≥3.5 | 265 | 50.19% | 57.36% | 1.25% | 更准但均盈略降 |
| B1 峰值回撤 5% | 686 | 44.17% | 53.94% | 1.26% | 不如基线 |
| B2 峰值回撤 6% | 670 | 44.33% | 51.64% | 1.30% | 仍不如基线 |
| C1 min_score=75 | 630 | 43.17% | 54.44% | 1.17% | 不建议抬高 |

**结论：** 默认 4% 移动止盈、min_score=70、volume_multiple=3.0 **维持不变**；单独放宽 trail 或抬 min_score **无收益**。

### 1.2 因子 C 组（trace 后滤，同区间）

| 方案 | 信号 | 命中率 | 胜率 | 均盈亏 | vs 基线 |
|------|------|--------|------|--------|---------|
| D0 基线 | 698 | 43.84% | 55.16% | 1.33% | — |
| **D1 排除 ma_bull [4,7)** | **408** | **53.92%** | **68.38%** | **3.20%** | **+1.87pp** |
| D3 仅距支撑 ≤2% | 125 | 39.20% | 44.80% | 2.20% | +0.87pp |
| D4 排弱项(ma_mid+高得分) | 408 | 53.92% | 68.38% | 3.22% | ≈D1 |
| **D5 优质组合** | **41** | 48.78% | 56.10% | **4.95%** | +3.62pp（样本少） |
| D6 排除 RR≥2.5 | 531 | 48.96% | 60.08% | 1.71% | +0.38pp |

**结论：**

1. **P0 已落地**：实时硬闸 + trace 后滤排除 `f_ma_bull ∈ [4,7)` — 日常默认 **`standard`** 模式。  
2. **精选 `premium`**：均盈最高但约 **41 笔/2.5 月**，作可选开关，不作全量默认。  
3. 单独排除 score≥90 几乎无效（与 ma_bull 弱项高度重叠）。  
4. 因子分桶弱项：`ma_bull [4,7)`、`score [90,100]`、`dist_to_support >5%`；强项：`dist_to_support ≤2%`、`score [70,80)`。

## 2. 优化项与状态

| 优先级 | 项 | 状态 | 说明 |
|--------|----|------|------|
| **P0** | 排除 ma_bull 分 [4,7) | **已落地** | `signal_detector` 硬闸 + 选股/回测 `standard` 后滤；A/B +1.87pp |
| **P0** | 信号质量 standard/premium | **已落地** | 回测页 + 网站「上升趋势」Tab；API `signal_quality_mode` |
| P0 | 回撤武装 8%–10% | **已落地** | `risk.take_profit_alert_pct_*` |
| P0 | 条件化连跌 3 日 | **已落地** | 连跌且浮亏 ≥4% |
| P0 | 默认观察期 10 | **已落地** | 任务默认 |
| P1 | 结构出场全路径保护 | **已落地** | 移动止盈为主离场；**不宜**单独放宽 trail 至 5%～6% |
| P1 | 量能硬筛 3.5 作默认 | **不做** | A/B：命中率升、均盈降（1.33%→1.25%）；可作可选实验 |
| P1 | min_score 75 | **不做** | A/B 均盈 1.17%，弱于 70 |
| P1 | 结构止损过密（~40%） | **待做** | 支撑过近易被洗；止损距入场不足 3%～4% 时回退 −8% |
| P1 | 阻力止盈为 0 | **待查** | 结构出场样本中 `structure_target` 常为 0；查 `nearest_resistance` 是否偏高 |
| P2 | 距支撑 ≤2% 加权 | **待做** | D5 精选有效；可软加权排序，非全量硬筛 |
| P2 | 排除 RR≥2.5 | **可选** | D6 +0.38pp，作次级过滤 |
| P2 | 止损后再进场冷却 | **必要** | 结构出场信号数多于命中率对照，同票回补 |

**明确不做：** 不把持有期写进选股计分；不把 `hit_rate` 当实盘持有建议；默认不改为 volume_multiple=3.5。

## 3. 配置键（2026-08-27 新增）

写入 `urt_config.json` / `config.py` 默认；**已保存的 DB 参数版本需手动同步或新建版本**。

| 键 | 默认 | 说明 |
|----|------|------|
| `exclude_ma_bull_score_mid_enabled` | **true** | 是否启用弱项闸 |
| `exclude_ma_bull_score_lo` / `hi` | **4.0 / 7.0** | 左闭右开区间 |
| `premium_signal_near_support_max_pct` | **2.0** | 精选：距支撑上限（%） |
| `premium_signal_exclude_score_ge` | **90.0** | 精选：排除得分下限 |
| `premium_signal_exclude_hvz_near_max_pct` | **1.0** | 精选：排除贴身 HVZ 强压（距压力 ≤%） |

实现：`backend_core/strategies/urt/signal_filters.py`；回测 runner 支持 `config_overrides` / `signal_filter`。

强共振融合 A/B（`--group confluence`，同区间全市场结构出场）：**E3 ma_mid+HVZ≤1%** 均盈亏 **3.45%**（基线 3.20%）；void 过滤与区间带出场未写入默认。

## 4. 建议下一轮回测

同一区间、全市场、**结构出场**、观察期 10、`signal_quality_mode=standard`（已含 ma_bull 后滤）：

1. **结构止损缓冲**：止损价相对入场下行不足 3%～4% 时改用 −8% 回退，看结构止损占比与均盈。  
2. **冷却**：结构止损后延长冷却（≥5 日或至观察期末），看信号数与均盈。  
3. **阻力止盈**：排查 `structure_target=0` 是否配置/空间阈值过严。  
4. **距支撑加权**：在 standard 模式下对 `dist_to_support ≤2%` 加分，对照 D5 精选样本量。

复现 A/B：

```bash
python manual_scripts/urt_ab_backtest.py --group default --out test/_tmp_urt_ab_results.json
python manual_scripts/urt_ab_backtest.py --group factor --out test/_tmp_urt_ab_factor_results.json
python manual_scripts/urt_ab_backtest.py --group confluence --out test/_tmp_urt_ab_confluence_results.json
```
