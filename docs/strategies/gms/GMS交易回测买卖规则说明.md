# GMS 交易回测买卖规则说明

本文档说明管理后台 **GMS 回测** 中「买入 / 卖出（出场）」的业务规则、与选股信号的关系，以及创建任务时各参数的中文含义。实现代码主要位于：

- `backend_core/strategies/gms/signal_detector.py`（买点 / 策略卖点检测）
- `backend_core/strategies/gms/backtest_runner.py`（回测入场、出场模拟）
- `backend_core/strategies/gms/gms_config.json`（策略默认阈值）
- `backend_api/admin/gms_admin_routes.py`（回测任务参数定义）

买点阶梯评分的细项见：[GMS策略买点判定标准说明文档.md](./GMS策略买点判定标准说明文档.md)。

---

## 1. 回测类型

| 回测类型（参数名） | 中文名称 | 说明 |
|-------------------|----------|------|
| `signal_hit_rate` | 策略信号命中率 | **默认**。统计信号出现后，在观察期内最高价是否达到目标涨幅；不模拟完整开平仓与止损。 |
| `trade_simulation` | 交易回测 | 在观察期内按止损、止盈、移动止损、时间止损等规则模拟一笔完整交易，并计算单笔收益率。 |

两种类型的 **买入信号筛选规则相同**；差异仅在 **如何统计「卖出 / 出场」**。

---

## 2. 信号与总分（买入前提）

回测逐交易日扫描股票池，对每只股票计算 GMS 指标，再经 `GMSSignalDetector` 判定是否出现 **左侧** 或 **右侧** 买点。

### 2.1 综合总分

| 概念 | 说明 |
|------|------|
| 均值收敛态小计 | 左侧相关三维度得分之和，满分 100。 |
| 动量溢出态小计 | 右侧相关三维度得分之和，满分 100。 |
| **综合总分** | `max(均值收敛态小计, 动量溢出态小计)`，**不是两模块相加**。 |
| 信号强度 | 综合总分 ÷ 100，用于列表展示（如 0.75 表示 75%）。 |

### 2.2 左侧买点（均值收敛 / 吸筹）

默认阈值来自 `gms_config.json` → `left_buy`：

| 配置项 | 中文含义 | 默认值 |
|--------|----------|--------|
| `ratio_d20_abs_max` | 引力粘合：\|Δ/d₂₀\| 上限 | 1.5%（0.015） |
| `volume_ratio_max` | 地量：当日量相对 20 日均量的上限（m₂₀/m） | 0.8 |
| `min_accumulation_score` | 左侧额外要求：均值收敛态得分下限；0 表示不启用 | 0 |

**触发逻辑（满足其一即可）：**

1. **等级直通**：均值收敛态为 **S 级（≥85 分）** 或 **A 级（≥70 分）** → 直接判为左侧，跳过 F/Z、delta 等逐项检查。
2. **无等级时** 须同时满足：
   - 上涨天数 Z > 0，且 **下跌天数 F > 上涨天数 Z**
   - **宏观位移 Δ < 0**（周期末价低于周期起点）
   - \|Δ/d₂₀\| < 配置上限
   - 量比 m₂₀/m < 配置上限
   - 若 `min_accumulation_score > 0`，还须均值收敛态得分 ≥ 该值

### 2.3 右侧买点（动量溢出 / 突破）

默认阈值来自 `gms_config.json` → `right_buy`：

| 配置项 | 中文含义 | 默认值 |
|--------|----------|--------|
| `volume_ratio_min` | 放量：当日量相对 20 日均量的下限（m₂₀/m） | 1.5 |

**触发逻辑（满足其一即可）：**

1. **等级直通**：动量溢出态为 **「全速切入」（≥90 分）** 或 **「分批买入」（≥80 分）** → 直接判为右侧。
2. **无等级时** 须同时满足：
   - **收盘价在均线上方**（d₂₀ > d）
   - **宏观位移 Δ > 0**
   - 量比 m₂₀/m > 配置下限

### 2.4 左、右同时满足时的展示

引擎 **优先归类为左侧**：有左侧信号则 `buy_type = 左侧`，否则为 `右侧`。

### 2.5 策略「卖点」信号（选股展示用，回测出场不用）

配置见 `gms_config.json` → `exit`：

| 配置项 | 中文含义 | 默认值 |
|--------|----------|--------|
| `overbought_ratio` | 乖离过大阈值：Δ/d₂₀ 或 Δ/d 超过该比例则提示卖点 | 15%（0.15） |
| `use_ratio_d_for_exit` | 是否同时用 Δ/d（均线乖离）判断卖点 | false |
| `trend_break_days` | 趋势破坏：d₂₀ 连续跌破 d 的天数（设计项，单日检测未实现） | 3 |

**说明**：选股页、信号追溯中的 **sell_signal（卖点）** 仅作参考；**回测的出场规则见下文第 4 节**，不使用 `detect_sell`。

## 3. 回测「买入」规则（两种回测类型相同）

| 步骤 | 规则说明 |
|------|----------|
| 扫描范围 | 任务指定的 **开始日期～结束日期**、**市场**（A 股 / 港股 / ETF / 全部）、**股票池**（全市场 / 单股 / 自定义 / 自选股等）。 |
| 信号条件 | 当日须 **`left_buy_signal` 或 `right_buy_signal` 为真**，且 **综合总分 ≥ 最低总分（min_score）**。 |
| 入场价格 | **信号日之后的下一交易日开盘价**。 |
| 去重规则 | 同一标的在上一笔样本的 **观察期结束日** 之前，不再接受新的信号（避免观察窗口重叠）。 |

## 4. 回测「卖出 / 出场」规则

### 4.1 策略信号命中率（`signal_hit_rate`）

不模拟具体卖出日与止损，仅判断：

| 规则项 | 说明 |
|--------|------|
| 观察窗口 | 自入场日起共 **观察期交易日数（horizon_days）** 根 K 线。 |
| 命中条件 | 观察期内 **最高价 ≥ 入场价 × (1 + 目标涨幅)** 则记为命中。 |
| 出场 | 无固定卖出价；报表中的「是否命中目标」为是/否。 |

### 4.2 交易回测（`trade_simulation`）

在 **观察期（horizon_days）** 内的 K 线上，按交易日顺序模拟持仓，**同一交易日先判断止损，再判断止盈**。主要逻辑如下：

| 出场类型 | 中文说明 | 触发条件（概要） |
|----------|----------|------------------|
| 止损 | 价格触及移动止损线 | 当日最低价 ≤ 当前止损线（含初始止损、保本、锁盈、跟踪止损的综合结果） |
| 止盈 | 触及目标价且未启用分批 | 当日最高价 ≥ 入场价 × (1 + 目标涨幅)，且分批止盈比例为 0 |
| 时间止损 | 持仓过久且盈利不足 | 已持仓达到 **时间止损 K 线数**，且浮盈尚未达到 1R |
| 时间出场 | 观察期结束 | 观察期内未触发上述出场 → 以 **最后一根 K 线收盘价** 平仓 |

**移动止损与保护（按 R 倍数，R = 入场价 − 初始止损价）：**

| 机制 | 中文说明 | 默认参数 |
|------|----------|----------|
| 初始止损 | 入场下方止损价；若未配置止损比例则按入场价约 5% 兜底 | `stop_loss_pct` = 0 时实际约 5% |
| 保本 | 浮盈达到指定 R 后，止损线上移至成本价 | `breakeven_trigger_r` = 1 |
| 锁盈 | 浮盈达到更高 R 后，止损线上移至「成本 + 保留 R」 | `profit_lock_trigger_r` = 2，`profit_lock_r` = 0.5 |
| 跟踪止损 | 止损线随最高价上移，按最高价回撤一定比例 | `trail_pct` = 8% |
| 分批止盈 | 浮盈达到指定 R 后，部分仓位按目标价了结，其余按最终出场价 | `partial_take_profit_r` = 2，`partial_take_ratio` = 40% |

**费用与仓位：**

| 项 | 说明 |
|----|------|
| 手续费 | 按 **单边手续费（基点）** 在买入、卖出成交价上折算。 |
| 滑点 | 按 **单边滑点（基点）** 在买入、卖出成交价上折算。 |
| 仓位 | **单笔仓位比例**：该笔投入占组合权益的比例；净值按「单笔收益 × 仓位」复利，其余资金视为现金。 |

**实现说明**：任务中的 ATR 相关参数（ATR 周期、初始 ATR 止损倍数、ATR 移动止损倍数）在当前回测实现中 **未参与计算**，实际仅使用 **百分比止损 + 百分比跟踪止损**。

## 5. 回测任务参数一览（中文说明）

创建 GMS 回测任务时，管理端 API（`BacktestCreateBody`）各字段含义如下。

### 5.1 基础与股票池

| 参数名 | 中文名称 | 说明 | 默认值 |
|--------|----------|------|--------|
| `task_name` | 任务名称 | 自定义任务显示名；为空时系统自动生成 | 空 |
| `market` | 市场 | `cn` A 股 / `hk` 港股 / `etf` ETF / `all` 全部 | `all` |
| `start_date` | 开始日期 | 回测区间起始日，格式 YYYY-MM-DD | 必填 |
| `end_date` | 结束日期 | 回测区间结束日，格式 YYYY-MM-DD | 必填 |
| `stock_pool_mode` | 股票池模式 | `all` 全市场 / `single` 单股 / `custom` 自定义列表 / `watchlist` 指定用户自选 | `all` |
| `stock_code` | 单股代码 | `stock_pool_mode=single` 时填写，如 000001、00700 | 空 |
| `stock_pool` | 自定义股票池 | 代码列表 | 空 |
| `watchlist_user_id` | 自选用户 ID | `stock_pool_mode=watchlist` 时可选指定用户 | 空 |

### 5.2 信号筛选与观察期

| 参数名 | 中文名称 | 说明 | 默认值 |
|--------|----------|------|--------|
| `min_score` | 最低总分 | 仅统计综合总分 ≥ 该值的信号；须同时有左/右侧买点 | 0 |
| `target_pct` | 目标涨幅 | 小数，0.05 表示 5%；用于命中率判定及交易回测止盈价 | 0.05 |
| `horizon_days` | 观察期交易日数 | 入场后统计或模拟持仓的 K 线根数；亦为同一标的信号去重的观察窗口长度 | 20 |

### 5.3 回测类型

| 参数名 | 中文名称 | 说明 | 默认值 |
|--------|----------|------|--------|
| `backtest_type` | 回测类型 | `signal_hit_rate` 命中率 / `trade_simulation` 交易模拟 | `signal_hit_rate` |

### 5.4 交易回测专用（仅 `trade_simulation` 生效）

| 参数名 | 中文名称 | 说明 | 默认值 |
|--------|----------|------|--------|
| `stop_loss_pct` | 止损比例 | 相对入场价的下跌比例，如 0.08 表示 8%；**为 0 时系统按约 5% 设置初始止损** | 0 |
| `commission_bps` | 单边手续费（基点） | 1 bps = 0.01%，买卖各计一次 | 0 |
| `slippage_bps` | 单边滑点（基点） | 模拟成交价相对理论价的不利偏移 | 0 |
| `atr_period` | ATR 周期 | 预留参数，**当前实现未使用** | 14 |
| `init_stop_atr_k` | 初始止损 ATR 倍数 | 预留参数，**当前实现未使用** | 2.2 |
| `trail_stop_mode` | 移动止损模式 | `atr` 或 `percent`；**当前实现按 percent 逻辑** | `atr` |
| `trail_atr_k` | 跟踪止损 ATR 倍数 | 预留参数，**当前实现未使用** | 3.0 |
| `trail_pct` | 跟踪止损回撤比例 | 相对持仓期间最高价的回撤比例，如 0.08 表示 8% | 0.08 |
| `breakeven_trigger_r` | 保本触发 R 倍数 | 浮盈达到多少倍初始风险 R 后，止损抬至成本价 | 1.0 |
| `profit_lock_trigger_r` | 锁盈触发 R 倍数 | 浮盈达到该 R 后启用锁盈止损线 | 2.0 |
| `profit_lock_r` | 锁盈保留 R 倍数 | 锁盈后止损线设在「成本 + 该倍数 × R」 | 0.5 |
| `partial_take_profit_r` | 分批止盈触发 R 倍数 | 浮盈达到该 R 后标记分批止盈（与目标价配合） | 2.0 |
| `partial_take_ratio` | 分批止盈比例 | 在目标价了结的仓位比例，0～1；为 0 则触达目标价时全额止盈 | 0.4 |
| `time_stop_bars` | 时间止损 K 线数 | 持仓满该根数且浮盈 &lt; 1R 时，按当日收盘平仓 | 15 |
| `position_fraction` | 单笔仓位比例 | 每笔投入占组合权益的比例，(0, 1]；1 表示全仓计入该笔收益 | 1.0 |

## 6. 策略默认配置（`gms_config.json`）

回测与选股共用该文件（任务未单独覆盖策略配置时）。除上文左/右/卖点阈值外，评分相关默认值如下：

| 配置路径 | 中文含义 | 默认值 |
|----------|----------|--------|
| `observation_period` | 指标观察周期（交易日） | 20 |
| `scoring.accumulation_s_threshold` | 均值收敛态 S 级分数线 | 85 |
| `scoring.accumulation_a_threshold` | 均值收敛态 A 级分数线 | 70 |
| `scoring.momentum_full_threshold` | 动量溢出态「全速切入」分数线 | 90 |
| `scoring.momentum_batch_threshold` | 动量溢出态「分批买入」分数线 | 80 |
| `scoring.watch_threshold` | 重点关注分数（选股提示用） | 60 |
| `scoring.alert_threshold` | 动量突变预警分数 | 90 |
| `scoring.instant_deviation_stable_days` | 推力支撑「站稳」判定所需交易日数 | 3 |

各维度权重与阶梯分档见 [GMS策略买点判定标准说明文档.md](./GMS策略买点判定标准说明文档.md)。

## 7. 与选股、信号追溯的关系

| 模块 | 买点 | 卖点 / 出场 |
|------|------|-------------|
| 网站 GMS 选股 | 与回测相同检测器 | 展示 `sell_signal`（乖离过大），**不执行回测出场逻辑** |
| 信号追溯 | 历史每日左/右侧标记 | 同左 |
| GMS 回测 | 同左 + `min_score` + 观察期去重 | **命中率**：仅看是否触达目标涨幅；**交易回测**：第 4.2 节规则 |

## 8. 规则对照简表

| 特性 | 左侧买点 | 右侧买点 | 回测出场（交易模拟） |
|------|----------|----------|----------------------|
| 定位 | 均值吸附、地量蓄势 | 动量突破、放量攻击 | 风控 + 目标盈利 + 时间 |
| 核心条件 | \|Δ/d₂₀\| 小、量比 &lt; 0.8 等 | Δ&gt;0、价在均线上、量比 &gt; 1.5 | 止损线、目标涨幅、观察期收盘 |
| 最高等级 | S / A | 全速切入 / 分批买入 | — |
| 是否用于回测买入 | 是 | 是 | — |
| 是否用于回测卖出 | — | — | **否**（不用策略卖点） |
