## 1. 目标与边界

### 1.1 目标

在**个股周线**数据上复用与日线 GMS **同一套**打分、买卖信号、减分与结构位机制，产出可筛选、可追溯的周频信号。

### 1.2 第一期范围（做）

| 能力 | 说明 |
|------|------|
| 周频 mean_frequency 指标 | 由 `weekly_quotes` 按与日线相同的 MF 公式计算并落库 |
| 策略引擎 | 现有 `gms` 包扩展 `timeframe=weekly`，共享打分/信号代码 |
| 定时预计算 | 写入周线 trace 表 |
| 选股 API / UI | 现有 GMS 面板增加日线/周线切换 |
| 参数版本 | `gms_strategy_configs` 按 timeframe（或等价命名）隔离周线 canonical 默认 |

### 1.3 第一期不做

- 交易观察 / 正式交易闭环  
- 周线回测（API 与管理端 UI）  
- 港股 / ETF 周线 GMS  
- 板共振（board_resonance）参与周线打分或旁证

## 2. 数据基准

### 2.1 行情

- **唯一 K 线基准**：A 股 `weekly_quotes`（由日线按 `W-FRI` 聚合，`date` = 该周**周五**标签）。
- 不以日频 `mean_frequency_resonance_indicators` 抽样冒充周线指标。

### 2.2 周频指标（MF）

- 新建周频 MF 表（见设计文档），列语义与日频 MF 对齐。
- **公式窗口按「根数」与日线一致**：MA20 / MAVOL20 / 涨跌统计窗口 = **20 根周 K**（不是 4 周）。
- GMS 策略层使用的「类 MA60」等**窗口参数**另见 §4（日历量级覆盖），不改编 MF 核心的 20 根定义。

### 2.3 已收盘周（信号可用周）

设 `as_of` 为查询/预计算的业务日（`YYYY-MM-DD`），周 bar 标签日为周五 `F`（`W-FRI` 日历标签，**不必是交易日**）。

**交易日完备判定（Q20=A，覆盖周五休市）：**

\[
\mathrm{closed}(F, as\_of) \iff \nexists\ \text{交易日 } T\ \text{满足}\ as\_of < T \le F
\]

即：`as_of` 之后到标签周五 `F`（含）之间，A 股已无剩余交易日。

推论：

- 普通周：周四仍可能有周五交易 → 周四 EOD 未收盘；周五（或之后）收盘后已收盘。  
- **周五法定假**：本周最后交易日多为周四 → 周四 EOD 即已收盘（不必等到日历周五）。  
- 周中（如周三）即便库里已有该周五标签的未完成聚合 bar，也因仍存在 `T ∈ (as_of, F]` 而**不得**用作正式信号。

信号周取：满足 `closed(F, as_of)` 的**最大**周五标签 `F`（且该周在 `weekly_quotes` 中有有效 bar）。交易日集合以 A 股日行情/交易日历为准（实现见设计文档）。

## 3. 策略逻辑一致性

下列与日线 GMS **同一套规则**（仅输入序列为周 K / 周 MF，窗口类参数用周线默认）：

1. **左侧买（均值吸附）**：粘合 + 地量（及 S/A 等级短路等既有规则）  
2. **右侧买（动量引爆）**：放量 + 突破（及全速切入/分批买入等级等）  
3. **卖点**：乖离过大等既有退出规则  
4. **打分机制**：`tiered_dual_max` / `tiered_dual_penalty` 等注册机制  
5. **减分规则**：结构 RR、观察期振幅、收盘相对 MA60 等（板共振相关规则第一期不启用）  
6. **结构位**：成交量加权 KDE；lookback 使用周线默认根数  

比率类阈值（如 `\|Δ/d₂₀\|` 1.5%、量比 0.8 / 1.5、乖离 15% 等）**与日线相同**，不因周期缩放。

## 5. 预计算入库规则（日线 + 周线）

### 5.1 地板分（本次一并变更）

- 默认入库条件：`score_total >= 30`。  
- `score_total` 为 `None` 或无法解析为数字 → **不入库**。  
- 日线与周线共用同一解析逻辑（环境变量 `GMS_PRECOMPUTE_MIN_SCORE` > 配置 `scoring.precompute_min_score` / `precompute_min_score` > 代码默认 **30**）。  
- **不**因存在左/右买信号而豁免地板分。

### 5.2 重算与删除

对某一预计算作用域（日线：`date + market_type + config_id`；周线：对应周 trace 表同等键）：

- 本轮 `score_total >= 30` → upsert；  
- 本轮未达地板（含缺分）→ **删除**该 code 在该作用域下已有 trace 行（若存在）。  

保证 `trace_only` 选股不会读到「按现行规则本不该在库中」的行。

### 5.3 与选股展示分的关系

- 入库地板只约束**预计算写库**；选股接口自身的 `min_score` 过滤仍可独立配置。  
- 缺 trace 行时，是否允许现算回填遵循既有日线策略（周线第一期以预计算 + trace 为主路径，与日线 `trace_only` 用户站行为对齐）。

## 7. 产品与运维规则

### 7.1 UI

- 选股页现有 GMS 面板增加 **日线 / 周线** 切换；同一套筛选控件，请求带 `timeframe`。  
- 周线结果日期展示为信号周的周五标签（已收盘周）。

### 7.2 工作流顺序（CN）

```
cn_weekly → weekly_mf_cn → gms_signals_weekly_cn
```

- 周 GMS 预计算依赖：周 K 已更新、周 MF 已写完、且仅处理 §2.3 的已收盘周。

### 7.3 历史回填

- 提供可配置回填：默认 **近 5 年**周 MF + **近 52 个已收盘周** GMS 预计算。  
- 全历史全量 trace 非第一期默认。

### 7.4 回测与交易

- 第一期不提供周线回测与交易观察/正式交易。  
- 日线交易闭环行为不变（仅预计算入库地板按 §5 变更）。

## 8. 验收要点（业务）

1. 任意交易日查询周线 GMS，信号周均为已收盘周（含周五休市时周四即可确认）；周中不出现「当周未完成 bar」的正式预计算结果。  
2. 同一套买点/打分规则在周 MF + 周 K 上可跑通；比率阈值与日线文档一致。  
3. 预计算后库中无 `score_total < 30` 的新行；重算后未达标旧行被删除（日线、周线皆然）。  
4. 用户站可选日线/周线；周线读周 trace，不与日线 trace 串表。  
5. 板共振、回测、交易、HK/ETF 周线入口第一期不可用或明确禁用。
