# GMS 策略交易清单模版（精简版）

> **适用**：GMS 左侧（均值收敛）/ 右侧（动量溢出）单笔交易  
> **原则**：先写预案再下单；看错有规则，看对拿得住；以**收盘确认**为准（A 股 T+1）  
> **完整规则**：见 [GMS_逻辑证伪_交易系统白皮书](./GMS_逻辑证伪_交易系统白皮书.md)

## 八、一页速记卡（可剪下对照）

```
│  GMS 交易速记                                        │

│  止盈：乖离 >15%  →  分批减 30%～50%                 │
│  止损：结构位 与 入场×95% 取较紧者                   │
│  确认：盘中不算，以日/周/月收盘为准                  │

```
