# RPE 流动性过滤分层改造方案

> 状态：**已实施**（2026-07-27）  
> 范围：比价效应（RPE）入场流动性门控  
> 关联：`docs/strategies/rpe/RPE_比价效应_信号计算规则.md`、`backend_core/strategies/rpe/filters.py`、`listed_board.py`

---

## 1. 背景与问题

现行规则为全市场统一：

- 近 20 日均成交额 ≥ **500 万**
- 有换手数据时：近 20 日均换手 ≥ **0.5%**

问题：

1. **均额一刀切**：中大盘日均额常达数亿，相对 500 万几乎无过滤力（例：实际均额约 11.1 亿仍显示「≥500 万通过」）。
2. **板别差异未体现**：主板、中小板、创业板、科创板、北证的可成交性与定价习惯不同。
3. **换手 0.5% 偏松**：20 日均换手 0.5% 仍可能覆盖交投偏淡、冲击成本偏高的标的，对「可交易补涨」约束不足。

本期方案：**分层绝对均额 + 统一（可调）换手门槛**；不做「相对自身历史」「额÷流通市值」主门控。

---

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| 可交易优先 | 流动性回答「能否合理进出」，不是「相对自己是否缩量」 |
| 板别分层 | 与现有 A 股代码段分组对齐（VSB / `cn_listed_board_filter`） |
| 中小板独立 | `002` 与深市主板 `000/001`、创业板 `300` 分开设档 |
| 创业板独立 | `300` 与科创板 `688` 可同额或分列，配置键分开便于微调 |
| 兼容旧配置 | 无 `min_avg_amount_by_board` 时回退原 `min_avg_amount` |
| 可解释 | 明细展示分档、应用门槛、实际均额/换手 |

## 3. 分档与门槛（建议默认）

### 3.1 上市分档定义（按代码前缀）

与 `VSB_BOARD_PREFIX_GROUPS` 对齐：

| 配置键 | 名称 | 代码前缀 | 说明 |
|--------|------|----------|------|
| `MAIN` | 沪深主板 | 沪 `600/601/602/603/605`；深 `000/001` | **不含** `002`、`300`、`688` |
| `SZ_SME` | 中小板 | `002` | 历史中小板代码段，单独分档 |
| `CYB` | 创业板 | `300` | 独立分档 |
| `KCB` | 科创板 | `688` | 独立分档（可与创业板同默认额） |
| `BJ` | 北证 | `43/83/87/88/92` 等 | 北交所 |
| `DEFAULT` | 兜底 | 未命中上表的 A 股等 | 保守沿用原 500 万量级 |

解析顺序建议：先匹配更细前缀（`688`→`KCB`，`300`→`CYB`，`002`→`SZ_SME`，北证前缀→`BJ`），再主板，最后 `DEFAULT`。

### 3.2 日均成交额下限（近 20 日，单位：元）

| 分档 | 建议默认均额 | 相对原 500 万 | 理由（交易视角） |
|------|--------------|---------------|------------------|
| `MAIN` 主板 | **30,000,000（3000 万）** | ×6 | 抬高中大盘有效门槛，避免「必然通过」 |
| `SZ_SME` 中小板 | **20,000,000（2000 万）** | ×4 | 介于主板与成长板之间；池子偏中盘 |
| `CYB` 创业板 | **15,000,000（1500 万）** | ×3 | 波动大、票池深，底线低于主板 |
| `KCB` 科创板 | **15,000,000（1500 万）** | ×3 | 与创业板同级起步，配置独立可后调 |
| `BJ` 北证 | **5,000,000（500 万）** | ×1 | 体量小，保留可交易空间 |
| `DEFAULT` | **5,000,000（500 万）** | ×1 | 兜底与现状兼容 |

> 确认项：若希望创业板严于科创板（或相反），只需改配置数字，算法不变。

### 3.3 换手率：0.5% 是否偏低？

**结论：作为「可交易」门控，0.5% 略偏低，建议默认上调到 0.8%。**

| 档位 | 含义（近 20 日均换手） | 适用 |
|------|------------------------|------|
| 0.5% | 偏松，易放过交投偏淡票 | 仅作兼容/观察 |
| **0.8%（建议默认）** | 温和收紧，仍覆盖多数活跃补涨候选 | **推荐落地** |
| 1.0% | 更严，入场样本会明显减少 | 信号仍偏多时再调 |
| ≥1.5% | 偏短线活跃度，易误杀慢热补涨 | 不建议作 RPE 默认 |

理由简述：

1. 换手已含「相对股本」信息，是均额分层的自然补充。  
2. 0.5% × 20 日意味着整体换手偏淡，大单进出更容易推价。  
3. RPE 主逻辑是比价 Z + 结构，流动性只需去掉「明显难成交」；0.8% 比 1.0% 更不易误杀慢热补涨。  
4. **本期仍建议全市场统一换手**（不分板），降低复杂度；若日后主板过严/成长板过松，再做 `min_avg_turnover_by_board`。

**建议默认：`min_avg_turnover_rate = 0.8`。**  
若业务希望更保守，可确认改为 `1.0`。

无换手字段时：只判均额（保持现行为）。

## 4. 判定公式

```
board = resolve_listed_board_segment(code)   # MAIN / SZ_SME / CYB / KCB / BJ / DEFAULT
min_amt = min_avg_amount_by_board[board] or min_avg_amount or DEFAULT

liquidity_ok =
    (avg_amount_20d >= min_amt)
    AND (若窗口存在换手样本: avg_turnover_20d >= min_avg_turnover_rate)
```

入场公式其余部分不变：

> 入场 = (catch_up 或允许交易的 lead) AND 未趋势否决 AND 结构有效 AND 流动性通过

---

## 5. 配置结构（草案）

```json
"liquidity": {
  "lookback_days": 20,
  "min_avg_turnover_rate": 0.8,
  "min_avg_amount": 5000000,
  "min_avg_amount_by_board": {
    "MAIN": 30000000,
    "SZ_SME": 20000000,
    "CYB": 15000000,
    "KCB": 15000000,
    "BJ": 5000000,
    "DEFAULT": 5000000
  }
}
```

兼容：

- 仅有旧键 `min_avg_amount`、无 `by_board` → 全市场仍用原值（行为不变）。  
- 深合并默认配置后，缺省键从 `get_default_rpe_config()` 补齐。

## 9. 上线与观察

1. 默认配置生效后，对比改前：入场条数、主板占比、创业/中小占比。  
2. 若主板过严：仅下调 `MAIN`（如 3000 万→2000 万）。  
3. 若信号仍偏多：仅上调换手至 `1.0`，或略抬 `CYB`/`SZ_SME` 均额。  
4. 不建议同时大幅改均额与换手，便于归因。
