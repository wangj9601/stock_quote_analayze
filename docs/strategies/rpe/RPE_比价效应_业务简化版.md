# RPE 比价效应策略（业务简化版）

这版给业务同学看：找什么票、怎么算、名词啥意思、何时可买、买后怎么卖。

更细公式与分子分母：[RPE_比价效应_信号计算规则.md](./RPE_比价效应_信号计算规则.md)  
工程设计：[RPE_STRATEGY_IMPLEMENTATION_DESIGN.md](./RPE_STRATEGY_IMPLEMENTATION_DESIGN.md)

---

## 1. 一句话理解

在**同一板块**里，找相对板块明显**偏弱**、但仍站在**支撑之上**、上方还有空间的股票，等它向板块**补涨**。

主目标是「补涨捕捉」，不是追已经大幅领涨的票。

---

## 2. 计算流程（业务视角）

1. **定板块**：单股/自选用固定主板块（优先行业，没有再用概念）  
2. **算板块温度计 \(I\)**：成分股成交量加权均价（不是外部指数）  
3. **算比价 \(R\)**：个股收盘价 ÷ 板块基准（分子=股价，分母=板块基准）  
4. **算偏离 \(Z\)**：比价在近约 40 日里偏高还是偏低  
5. **看板块是否在跌**：近约 60 日板块基准斜率 &lt; 0 → 默认不做入场  
6. **看支撑/阻力与流动性**：站上支撑、盈亏比够、成交不能太稀  
7. **给出信号**：补涨 + 上述都过 → **可入场**；领涨默认只观察  

选股页点「明细」可看到与上表一致的逐步判定和参数取值。

## 3. 名词速查（分子 / 分母）

| 说法 | 白话 | 分子 | 分母 |
|------|------|------|------|
| **板块基准 \(I\)** | 板块「均价温度计」 | 各成分 价×量 之和 | 各成分成交量之和 |
| **比价 \(R\)** | 这只股相对板块贵还是便宜 | 个股收盘价 \(P\) | 同日板块基准 \(I\) |
| **Z** | 比价偏弱/偏强了多少（标准化） | 当日比价 − 近期均值 | 近期比价波动 |
| **盈亏比 RR** | 上方空间够不够 | 到阻力的距离 | 到支撑的距离（默认要 ≥1.5 倍） |
| **支撑 / 阻力** | 筹码密度峰（KDE） | — | 现价下/上方最近峰；上方没有就显示 `-` |
| **入场** | 策略认为「可以当交易候选」 | — | 补涨 + 未否决 + 结构 + 流动性 |
| **结构破位** | 该走的信号 | — | 收盘跌破支撑（不用固定 % 止损） |

## 4. 选股在看什么（四关）

### 第一关：板块基准

系统用板块成分股的**成交量加权均价**当温度计。  
自选/单股优先**行业**；没有行业则用**概念**。同一只股追溯全程固定一个主板块。

### 第二关：比价偏离（Z）

- **Z 很低（默认 ≤ -1.5）**：相对落后 → 潜在补涨  
- **Z 很高（默认 ≥ 2）**：相对领涨 → 默认只观察  
- **中间**：一般不作为主选股结果（单股明细仍能看到）

### 第三关：板块趋势否决

板块近一段整体往下走 → 默认**不做补涨入场**（仍可标出补涨类型供观察）。

### 第四关：结构 + 流动性

- 现价在最近支撑之上  
- 到阻力的上行空间 ≥ 下行空间的约 1.5 倍（无阻力时视为空间够）  
- 近 20 日**成交额（人民币）**按上市板别达标，且换手一般 ≥ 0.8%（主板门槛更高，北证较低）

都过了 → 「可入场」补涨信号。  
分层细则见 `docs/strategies/rpe/RPE_流动性过滤_分层改造方案.md`。

## 5. 信号怎么用

| 信号 | 业务含义 | 默认用法 |
|------|----------|----------|
| 补涨 + 入场 | 落后且过滤全过 | 观察 → 正式交易 |
| 补涨但未入场 | 落后但被趋势/结构/流动性挡住 | 只观察 |
| 领涨 | 明显强于板块 | 默认只观察 |

勾选「仅入场信号」结果变少是正常的。  
「优先读预计算」依赖日终任务是否已跑完。

---

## 6. 买后怎么管

**禁止用固定百分比止损当策略规则。**

- **结构破位**：收盘有效跌破最近支撑 → 应退出  
- 止盈可参考触及附近阻力；仓位人工定  

观察列表会用实时行情确认：现价是否仍在支撑上方。

---

## 7. 参数怎么调（业务视角）

| 想解决的问题 | 可调方向 |
|--------------|----------|
| 可入场太少 | 放宽补涨 Z、降低盈亏比、临时关趋势否决 |
| 信号太杂 | 收紧 Z、提高流动性/盈亏比 |
| 想做领涨 | 打开 `enable_lead_trade`（与补涨主逻辑不同） |

改参建议新建配置版本并预计算，避免和旧结果混用。
