# 个股推荐策略说明

> 文档对应实现：`backend_core/recommend/`、分析频道「策略推荐」Tab、管理端「策略推荐」  
> 口径声明：**规则合成参考，非投资建议**  
> 更新日期：2026-09-14（三期优化后）

---

## 1. 产品定位

个股推荐（前台名：**策略推荐**）把系统已有能力串成可执行清单：

```
大盘/板斜率(E_slope) → 场景 regime → 五策略买点(+CSB) → Min-Max 质量
→ 筹码峰 S_sr → 角色/主题 → 约束降级 → Top 截断 →（可选）尾盘 late_run
```

| 周期 | 名称 | 目标 | 典型产出 |
|------|------|------|----------|
| 日 | Daily Brief | 次日可跟进的买点清单 | 可执行 Top15（弱势≤5）+ 观察 Top25 |
| 周 | Weekly Watch | 主线板 + 角色观察池，约束次日日报 | 主线板 Top5 + 观察池 Top30（月主题加权） |
| 月 | Monthly Theme | 主题板 + 中军核心 / 龙头卫星 | 主题板 Top5 + 核心/卫星持仓框架 |

---

## 2. 周期分工与触发

| 周期 | 生成函数 | 默认触发 | 强制重跑 |
|------|----------|----------|----------|
| 日 | `generate_daily_brief` | 每个交易日日终 | 管理端重跑 |
| 日·尾盘 | 同上 `late_run=True` | 建议 14:40 左右 | 节点 `stock_recommend_brief_late` |
| 周 | `generate_weekly_watch` | 本周最后一个交易日 EOD | `force_weekly=True` |
| 月 | `generate_monthly_theme` | 自然月最后一个交易日 EOD | `force_monthly=True` |

工作流节点：

- `stock_recommend_brief`：日终主链路（日/周/月按日历）
- `stock_recommend_brief_late`：仅日报 `late_run=True`，**不替代**日终主链路

调度入口：`run_recommend_brief_job(late_run=..., horizons=...)`。

---

## 3. 数据输入

### 3.1 五策略买点（signal_trace）

| 策略 | 条件 | 质量分来源 |
|------|------|------------|
| CSB | `trade_date=asof` 且 `entry_signal=True` | `score` |
| URT | `date=asof` 且 `buy_signal=True` | `score` |
| GMS | `date=asof`、左买或右买 | `score_total` |
| SBBR | `trade_date=asof` 且 `entry_signal=True` | 无分 → 池内默认 50 |
| RPE | `trade_date=asof` 且 `entry_signal=True` | `z_score` → 映射后再 Min-Max |

缺 CSB 不阻断日报；VP/CSB 失败时降级继续出分。

### 3.2 行业、角色、行情

同花顺行业优先；板斜率 5/10/20/60/120；角色 leader/mid；指数默认沪深300（`RECOMMEND_MARKET_INDEX`）。

### 3.3 筹码峰（Volume Profile）

仅对合并后候选（默认 ≤80）计算 `P_sup` / `P_res` 与 `S_sr`，不全市场扫。  
有 VP 浮动买区/止损时，**不再因缺策略价位一律降级**。

---

## 4. 候选合并与场景

1. 按策略采集 → 当日池内 **Min-Max → quality_norm ∈ [0,100]**  
2. 按代码合并；质量可按 regime 加权  
3. **主策略**按 regime 优先级：
   - `range`：csb > urt > gms > sbbr > rpe  
   - `trend`：gms > urt > csb > sbbr > rpe  

场景划分（大盘 20 日斜率，阈值可配）：偏平/负 → `range`；明显为正 → `trend`。  
权重倾斜：**不删策略**，range 抬 CSB 压 GMS；trend 相反。

---

## 5. 环境判定与 E_slope

### 5.1 大盘立场

`bull` / `bear` / `neutral`（相对 MA20 + 近 5 日方向）。bear：buy→watch。

### 5.2 板弱否决

`sector_slope_5/10` 低于阈值 → board_weak；角色加分清零。

### 5.3 E_slope 乘数

- 指数近 20 日线性斜率 + 板 20 日斜率 → 各自映射为 E  
- 负斜率非对称映射到约 `[0.2, 0.4]`；非负接近 1.0  
- **E = min(E_market, E_board)**（偏防守）  
- `E < RECOMMEND_E_SLOPE_FLOOR`（默认 0.15）→ 强制 watch，角色不加分  

---

## 6. 立场与硬约束（日报）

| 约束 | 规则 | constraint_reasons |
|------|------|--------------------|
| 大盘偏空 | bear 且 buy → watch | `market_bear` |
| 板弱 | board_weak 且 buy → watch | `board_weak` |
| E 地板 | E < floor → watch | `e_slope_floor` |
| 防追高 | 涨停 / 短涨 / 远离买区 | `limit_up` 等 |
| 周观察池 | 池外 buy → watch | `out_of_weekly_pool` |
| 缺价位 | 无策略价位且无 VP 区 → watch | `missing_buy_or_stop_zone` |
| 尾盘长上影 | late_run | `late_upper_shadow` |
| 尾盘假突破 | late_run | `late_false_break` |
| 同板/主题上限 | 分散约束 | `per_board_cap` / `theme_board_cap` |

清单规模：

- 可执行 Top：**15**；弱势（`bear` 或 `E_market < 0.5`）压缩为 **5**（`RECOMMEND_DAILY_TOP_EXEC_DEFENSE`）
- 观察 Top：**25**

---

## 7. 推荐分（三期公式）

\[
S_{base} = 共振 + 质量 + 立场 + 角色 + 主题对齐 \\
S_{total} = \max(0,\ (0.7\cdot S_{base} + 0.3\cdot S_{sr})\cdot E_{slope})
\]

| 分项 | 计算 |
|------|------|
| 共振 | 命中策略数 × 10 |
| 质量 | `min(quality_norm, 100) × 0.3`（归一化后） |
| 立场 | 买入 +15 / 观察 +5 / 回避 +0 |
| 角色 | 龙头 +3 / 中军 +2；板弱或 E 地板时 0 |
| 主题对齐 | 落在当周主线或当月主题板时 +`THEME_ALIGN_BONUS`（默认 3） |
| S_sr | 现价相对筹码峰支撑/阻力贴合，0～100；缺 VP 为 0 |

`score_detail` 含：`s_base`、`s_sr`、`e_slope`、`theme_bonus`、`formula_version` 等。  
权重 `RECOMMEND_SCORE_W_BASE/SR` 可改；回滚可设 E≈1、无 SR、Top=15。

## 8. 周报 / 月报 / 传导

### 8.1 Weekly Watch

- 主线板：60 日斜率 Top5；观察池角色优先 Top30  
- 与月主题板交集：池内分 +4，并写入 `theme_align_monthly`  
- `summary.monthly_theme_overlap` 记录交集板

### 8.2 Monthly Theme

- 120 日主题板 Top5；中军核心 / 龙头卫星

### 8.3 日报传导

代码落在当周主线或当月主题板 → `theme_align` 加分，evidence 留痕；周池外降级逻辑保留。

---

## 9. 尾盘 late_run

1. 加载/重算当日 daily 候选与评分  
2. 用当日 OHLC：上影占比超阈值 → 降 watch；收盘跌回买区上沿 → 假突破降级  
3. upsert 同一 `asof_date`，`late_run=True`，`publish_window` 标注尾盘确认  
4. KPI：`late_degraded`

管理端重跑可打开 late_run 开关；生产建议独立挂 `stock_recommend_brief_late`。

---

## 10. 落库

表：`stock_recommend_brief`；唯一键 `(horizon, asof_date)`。  
字段含 `late_run`、`summary_json`（regime/config/counts）、`kpi_json`（defense_mode、regime_counts、late_degraded 等）。

---

## 11. 前台与管理端

- 前台：场景、发布窗、推荐分明细（E斜率 / S_base / S_sr）  
- 管理端：regime、是否尾盘确认、重跑 late_run 提示  
- 导出列：场景、E斜率、S_base、S_sr、P_sup/P_res 等

权限码不变（仍在 recommend 下）。

## 12. 可配置环境变量（增量）

| 变量 | 默认 | 含义 |
|------|------|------|
| `RECOMMEND_E_SLOPE_NEG_MIN/MAX` | 0.2 / 0.4 | 负斜率 E 映射区间 |
| `RECOMMEND_E_SLOPE_FLOOR` | 0.15 | 强制 watch 地板 |
| `RECOMMEND_E_SLOPE_DEFENSE_THRESHOLD` | 0.5 | 弱势压缩 Top 阈值 |
| `RECOMMEND_DAILY_TOP_EXEC_DEFENSE` | 5 | 弱势可执行上限 |
| `RECOMMEND_SCORE_W_BASE/SR` | 0.7 / 0.3 | 公式权重 |
| `RECOMMEND_THEME_ALIGN_BONUS` | 3 | 主题对齐加成 |
| `RECOMMEND_SR_BAND_PCT` 等 | — | VP 浮动买区带宽 |
| `RECOMMEND_LATE_UPPER_SHADOW_RATIO` 等 | — | 尾盘过滤阈值 |
| `RECOMMEND_VP_CANDIDATE_CAP` | 80 | VP 候选上限 |

其余变量见代码 `brief_config_snapshot()` / `config.py`。

## 13. KPI 与运维

- 集中度 HHI、角色分布  
- `defense_mode` / `daily_top_exec_effective`：弱势出手次数与上限  
- `late_degraded`：尾盘降级数  
- `regime` / `regime_counts`：场景分布  
- 触达买区率：管理端「触达买区 KPI」

运维注意：

1. 日报依赖 CSB/URT/GMS/SBBR/RPE 预计算到目标 asof  
2. VP 仅候选计算，耗时与候选规模相关  
3. late 窗口建议 14:30–14:50，需当日 OHLC 可用  
4. 回滚：E=1、Top=15、W_SR=0、关闭 late 节点

## 15. 使用注意

1. 策略 trace 未跑到 asof 时对应源为空，不会凭空造信号。  
2. SBBR 无统一质量分时用默认 50 再归一化。  
3. 读接口 enrich 不强制重算 VP。  
4. 先单测再管理端历史 asof 重跑对比纸面 KPI，再挂 late 到生产。
