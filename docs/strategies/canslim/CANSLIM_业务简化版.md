# CAN SLIM 选股（业务简化版 · 第一期）

面向投研与业务同学：我们在找什么、第一期做了哪些字母、和奥尼尔原文有何差异。

---

## 1. 一句话

**CAN SLIM** 是成长股「基本面加速 + 价格强势 + 大盘允许开仓」的合取框架。  
本系统第一期落地 **C / A / N / S / L**，**M** 做简单大盘开关，**I（机构）暂不过滤**。

---

## 2. 七个字母（第一期口径）

| 字母 | 含义 | 第一期规则（默认可配置） |
|------|------|------------------------|
| **C** | 当季盈利 | 最新单季 EPS（或利润）同比 ≥ **25%** |
| **A** | 年度成长 | 近 **3** 个年报 EPS 同比均 ≥ 25%（不足时可用 CAGR 兜底）且 ROE ≥ **17%** |
| **N** | 新高 / 新形态 | 前复权收盘 ≥ 52 周高的 **85%**，**或** CUPB 为 forming/confirmed |
| **S** | 供给需求 | 流通股本 ≤ **20 亿股**；阳线日成交量 ≥ MAVOL20 |
| **L** | 领涨 | IBD 风格 **RS Rating ≥ 80** |
| **I** | 机构 | 第一期**不参与**过滤 |
| **M** | 大盘 | 沪深300 收盘 > MA50，且 MA50 高于 10 日前；不满足则整批空结果（可关） |

---

## 3. 和美股 IBD 原文的差异（重要）

- 流通盘：美股常提 2000～2500 万股；A 股默认放宽到 **20 亿股** 上限。
- 财务：读库表 `stock_fina_indicator`（采集：**Tushare 优先，不可用时 AkShare 回退**），不是盘中外网。
- 「新产品 / 新管理层」不做 NLP；N 只看新高与杯柄。
- M 不做 IBD「跟进日/派发日」，只用均线趋势；指数日线**优先 AkShare**，失败可回退 Tushare。
- I 完全置后。

---

## 4. 怎么用

1. 选股页打开 **CAN SLIM** Tab。  
2. 确认已采集：`fina_indicator_cn`、`index_daily_cn`、日终 `rs_rating_cn`、股本与 CUPB 预计算（可选）。  
3. 可选：关闭「启用大盘过滤」、调整 RS 门槛、填基准日。  
4. 点 **刷新筛选**。结果按 RS 降序；悬停 C/A/N/S/L 列可看原因。

API：`GET /api/screening/canslim?market_filter=true&rs_min=80&asof=YYYY-MM-DD`
