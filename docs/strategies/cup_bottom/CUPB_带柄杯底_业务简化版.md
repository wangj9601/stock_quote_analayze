# CUPB 带柄杯底策略（业务简化版）

这版文档给业务与投研同学看，尽量不用公式，重点回答：

1. 我们在找什么样的图形  
2. 什么时候算「结构成立」「可以跟踪突破」  
3. A/B/C 等级分别代表什么  
4. 和管理端、个股分析形态工具的关系  

---

## 1. 一句话理解

**带柄杯底**是上涨趋势中途的「洗盘整理」：股价先回落形成 U 形杯身，再在杯口附近小幅回调形成杯柄，最后**放量突破杯口**后继续上攻。

不是抄底最低点，而是等「整理完成 + 突破确认」。

---

## 2. 图上要看到什么

可以把它想象成一只**带把手的咖啡杯**：

| 部位 | 图上长什么样 | 我们在看什么 |
|------|--------------|--------------|
| **左沿（杯口左肩）** | 上涨后的高点 | 形态起点，要有前期涨幅 |
| **杯底** | U 形最低点 | 缓慢探底，最好缩量 |
| **右沿（杯口右肩）** | 反弹回左沿附近 | 说明抛压减轻，多头收回失地 |
| **杯柄** | 右沿后的小幅回落 | 洗盘换手，**不能跌回杯底** |
| **突破** | 放量冲破杯口 | 确认日，策略进入「已确认」 |

**警惕信号（不算标准杯柄）**

- 杯底之后价格又创新低 → 说明整理失败，应看更深的杯底  
- 杯柄跌进杯子下半区 → 多头失守  
- 杯柄向上翘（买盘太急）→ 容易假突破  
- 突破当天没量 → 可能是假突破

## 3. 系统怎么给结果

### 3.1 状态

| 状态 | 业务含义 |
|------|----------|
| **forming（形成中）** | 杯+柄结构已识别，还没突破杯口 |
| **confirmed（已确认）** | 已收盘突破杯口（可选要求放量） |
| **invalidated（已失效）** | 跌破柄低或破杯底，结构破坏 |

### 3.2 等级 A / B / C

| 等级 | 含义 | 怎么用 |
|------|------|--------|
| **A** | 结构标准 + 量价配合好（四项里至少三项达标） | 优先纳入观察/选股池 |
| **B** | 结构合格，量价一般 | 可跟踪，等突破放量再重视 |
| **C** | **延长型大基底**（杯很深、时间很长，或量价偏弱） | 仍可突破，但更像「复杂筑底」而非教科书茶杯 |
| **X** | 失效 | 仅作历史参考，不参与选股 |

默认扫描 **全部等级**；若只要质量更高的，可在配置里设 `scan.grade_filter: "A"`。

### 3.3 量价四条（系统后台检查）

1. **杯底缩量**：底部交投清淡  
2. **右侧回升放量**：从杯底往右沿涨时有资金进场  
3. **柄部缩量**：柄回调时卖压枯竭  
4. **突破放量**：突破日成交量明显放大（相对近 50 日均量）  

前端结果里「量价」列显示 0～4 分。

## 4. 管理端怎么用

菜单：**形态策略 → 杯底形态（CUPB）**

1. 选股票池（个股 / 板块 / 全市场）  
2. 点 **试算** 看当日命中列表（含左沿、杯底、右沿、柄低、确认日、等级）  
3. 满意后 **写入预计算**，供日后「利旧」快速查询  
4. **强制计算** 会忽略旧缓存，参数改版后务必重算  

价格口径：管理端默认 **不复权** 日线。

---

## 5. 个股分析里的「带柄茶杯」

分析页 → 技术工具 → 形态识别 → 勾选 **杯底/带柄茶杯**。

- 默认 **前复权** K 线做识别（与图表一致）  
- 算法与管理端相同，关键日期应对齐  
- 展示价位可与不复权管理端对齐（便于对照）  
- 确认日 = 形成日（`formed_at`）

## 6. 案例：002412 汉森制药

这是典型的 **C 级延长基底**，不是教科书里的浅 U 形杯：

| 阶段 | 时间 | 发生了什么 |
|------|------|------------|
| 左沿 | 2026-02 初 | 冲高后见顶 |
| 第一次探底 | 2026-03-23 | 跌到约 6 元，但后面又跌了 |
| 假反弹 | 2026-04 | 弹到 7 元一带，像杯柄，但未能维持 |
| **真杯底** | **2026-06-29** | **最低约 5.32，缩量磨底** |
| 右沿 | 2026-07-24 | 放量弹回 8 元一带 |
| 柄部 | 2026-07 底 | 小幅回踩到 6.5 元附近 |
| 突破确认 | 2026-08-20 前后 | 突破杯口，后续大涨 |

**业务教训**

- 不要看到第一次探底就当成杯底  
- 真突破前的最后一次探底 + 右侧放量更重要  
- 深杯、长整理标 **C 级** 仍可有交易价值，但止损要盯紧柄低和真杯底

## 7. 和双底（DBLB）的区别

| 对比 | 双底 DBLB | 带柄杯底 CUPB |
|------|-----------|---------------|
| 图形 | W 形，两个近似低点 | U 形 + 右沿上方小柄 |
| 确认 | 突破颈线 | 突破杯口（左/右沿较高者） |
| 趋势要求 | 无硬性前期涨幅 | 默认要求左沿前有 ≥30% 涨幅 |
| 适用场景 | 反转、筑底 | 上涨趋势中的中继整理 |

同一只股票可能同时出现双底、头肩、杯柄等多个形态，以**等级更高、状态已确认**的结构为主参考。

## 8. 常见问题

**Q：为什么同一只股票管理端和前端价位略有不同？**  
A：管理端用不复权，前端默认前复权。日期应一致；价位差异来自复权，前端可对齐展示不复权参考价。

**Q：强制重算后结果变了？**  
A：算法升级后会重锚杯底、加破底失效规则，属预期行为。请用「强制计算」刷新缓存。

**Q：为什么全市场扫描很慢？**  
A：全市场 + 160 日回看计算量大，建议用板块或限额，或依赖预计算入库结果。
