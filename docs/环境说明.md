## 2. 本地开发环境

### 2.1 应用端口（当前 `.env`）

```text
FRONTEND_PORT=8000
ADMIN_PORT=8001
BACKEND_PORT=5000
ENVIRONMENT=development
DEBUG=true
```

### 2.2 数据库（当前本机 `.env`）

| 项 | 值 |
|----|-----|
| 类型 | PostgreSQL |
| 主机 | `localhost` |
| 端口 | **5446** |
| 用户 | `postgres` |
| 密码 | `qidianspacetime` |
| 库名 | `stock_analysis` |

连接串（分项等价）：

```text
postgresql+psycopg2://postgres:qidianspacetime@localhost:5446/stock_analysis
```

`psql` 示例：

```bash
psql -h localhost -p 5446 -U postgres -d stock_analysis
```

### 2.3 局域网开发备选（`.env.example`）

若连团队内网库，示例为：

| 项 | 值 |
|----|-----|
| 主机 | `192.168.31.237` |
| 端口 | `5446` |
| 用户 | `postgres` |
| 密码 | `qidianspacetime` |
| 库名 | `stock_analysis` |

```text
postgresql+psycopg2://postgres:qidianspacetime@192.168.31.237:5446/stock_analysis
```

### 2.4 历史/备选本机连接（`.env` 注释）

曾出现过的备选串（端口 **8432**，密码含特殊字符 `$`）：

```text
postgresql+psycopg2://postgres:qidianspacetime$91@localhost:8432/stock_analysis
```

仅在本机实际监听 8432 时使用；当前默认开发库为 **5446**。

### 2.5 本地启动顺序（简要）

1. PostgreSQL（5446）
2. 后端 API：`python` 启动 backend_api（5000）
3. 用户前端：`python start_frontend.py`（8000）
4. 管理端：admin 开发服或静态服（8001）
5. 采集调度（按需）：`python start_backend_core.py` / `backend_core.data_collectors.main`

## 3. 生产环境

### 3.1 对外与反代

| 项 | 说明 |
|----|------|
| 域名 | `https://www.icemaplecity.com` |
| Nginx | HTTP **80** → HTTPS **443** |
| 用户站 | 反代本机 `127.0.0.1:8000` |
| 管理端 | 反代本机 `127.0.0.1:8001`（路径 `/admin/`） |
| API | 反代本机 `127.0.0.1:5000`（路径 `/api/`） |
| 安全组 | 对外仅 **SSH、80、443**；勿开放 5000/8000/8001/5432 |

### 3.2 应用端口（生产机本机）

与本地一致（由 Nginx 对外暴露）：

```text
FRONTEND_PORT=8000
ADMIN_PORT=8001
BACKEND_PORT=5000
ENVIRONMENT=production
```

CentOS 新生产部署目录约定（见 `docs/prod/centos-migration-runbook.md`）：

| 路径 | 用途 |
|------|------|
| `/opt/stock_quote/current` | 当前发布代码 |
| `/opt/stock_quote/shared/.env` | **生产环境变量（含库密码）** |
| `/opt/stock_quote/shared/reports` | 推送报告等 |
| `/opt/stock_quote/shared/ssl/` | HTTPS 证书 |

### 3.3 生产数据库

| 项 | 典型值 / 说明 |
|----|----------------|
| 类型 | PostgreSQL 12+ |
| 库名 | `stock_analysis` |
| 用户 | `postgres`（或现场专用账号） |
| 主机 | 多为 `127.0.0.1`（与 API 同机）或内网 DB 主机 |
| 端口 | 常见 **5432**；旧 Windows 生产笔记常见 **8432** |
| 密码 | **仅保存在生产机 `.env`，不以仓库为准** |

生产推荐写法（`scripts/deploy/linux/.env.centos.example`）：

```text
ENVIRONMENT=production
DATABASE_URL=postgresql+psycopg2://postgres:<生产密码>@127.0.0.1:5432/stock_analysis
# 或分项：
# DB_HOST=127.0.0.1
# DB_PORT=5432
# DB_USER=postgres
# DB_PASSWORD=<生产密码>
# DB_NAME=stock_analysis
```

查看生产口令（需登录生产机）：

```bash
# CentOS 示例
sudo grep -E '^(DATABASE_URL|DB_HOST|DB_PORT|DB_USER|DB_PASSWORD|DB_NAME)=' \
  /opt/stock_quote/shared/.env
```

备份示例：

```bash
pg_dump -h 127.0.0.1 -p 5432 -U postgres -Fc -f stock_analysis_YYYYMMDD.dump stock_analysis
```

（若现场端口为 8432，把 `-p` 改成 8432。）
