# 均值频率共振量化交易指标计算设计文档

## 概述

均值频率共振量化交易指标基于"量价频幅度共振策略(PVFARS)"理论,通过价格、频率、成交量、幅度等维度的共振分析,识别市场的高效率上涨状态。

## 理论基础

### 三维共振理论

"高效率上涨"被定义为市场在以下三个维度达成向上共振:

1. **价格维度**: 方向与强度的确认
2. **频率维度**: 微观一致性与共识判定  
3. **成交量维度**: 动力与进出效率验证

## 指标参数定义

### 基础参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 观察窗口 | `window` | 默认20个交易日 |
| 当前收盘价 | `d20` 或 `Close_t` | 当前交易日的收盘价 |
| 起始收盘价 | `d1` 或 `Close_{t-19}` | 窗口起始日的收盘价 |
| 移动平均价格 | `d` 或 `MA20` | 20日移动平均收盘价 |
| 当前成交量 | `m20` 或 `Vol_t` | 当前交易日的成交量 |
| 移动平均成交量 | `m` 或 `MAVOL20` | 20日移动平均成交量 |

## 指标计算规则

### 1. 宏观位移 Delta (Δ)

**定义**: 衡量观察周期内价格的整体位移

**计算公式**:
```
Δ = d20 - d1 = Close_t - Close_{t-19}
```

**计算步骤**:
1. 获取当前交易日收盘价 `Close_t`
2. 获取20天前(窗口起始)的收盘价 `Close_{t-19}`
3. 计算差值: `Δ = Close_t - Close_{t-19}`

**经济意义**:
- **Δ > 0**: 市场处于盈利的正向区间,整体上涨
- **Δ < 0**: 市场处于亏损区间,整体下跌
- **Δ = 0**: 市场横盘整理

**代码实现**:
```python
df['delta'] = df['close'] - df['close'].shift(window - 1)
```

---

### 1.1 幅度（Amplitude）

**定义**: 宏观位移的数值大小（绝对值）

**计算公式**:
```
幅度 = |Δ| = |d₂₀ - d₁|
```

**经济意义**:
- 衡量20天观察期内价格变化的**绝对幅度**
- 与方向无关，只关注变化的大小
- 用于判断价格波动的剧烈程度

**代码实现**:
```python
amplitude = abs(macro_displacement)  # |Δ|
```

---

### 1.2 幅度比例（Amplitude Ratios）

**定义**: 宏观位移相对于首尾价格的比率

**计算公式**:
```
ratio_d20 = Δ / d₂₀ = (d₂₀ - d₁) / d₂₀
ratio_d1 = Δ / d₁ = (d₂₀ - d₁) / d₁
```

**计算步骤**:
1. 计算宏观位移: `Δ = d₂₀ - d₁`
2. 计算相对于第20天价格的比率: `ratio_d20 = Δ / d₂₀`
3. 计算相对于第1天价格的比率: `ratio_d1 = Δ / d₁`

**经济意义**:
- **ratio_d20**: 衡量20天涨幅相对于当前价格的比率
- **ratio_d1**: 衡量20天涨幅相对于起始价格的比率
- 用于判断整体趋势的强度（相对于价格水平）

**注意事项**:
- 当 d₂₀ = 0 或 d₁ = 0 时，对应比例无法计算（应设为 None 或跳过）

**代码实现**:
```python
if d20 != 0:
    ratio_d20 = macro_displacement / d20
else:
    ratio_d20 = None

if d1 != 0:
    ratio_d1 = macro_displacement / d1
else:
    ratio_d1 = None
```

---

### 1.3 横盘判断（Sideways Market Detection）

**定义**: 判断市场是否处于横盘整理状态

**判断条件**:
```
① Δ = 0 或 |Δ| < ε → 横盘
② Δ₂₀ / d 极小数域内 → 横盘（相对幅度过小）
```

其中 `ε` 为横盘判定阈值（例如 `1e-6` 或可配置的 `amplitude_flat_threshold`）

**经济意义**:
- **Δ = 0**: 20天首尾价格相同，绝对横盘
- **|Δ| < ε**: 价格变化极小，近似横盘
- **Δ₂₀ / d 极小数域内**: 相对幅度过小，即便满足量价条件，演化逻辑仍属于"平"的范畴

**应用场景**:
- 入场时机：横盘时建议等待波幅放大
- 信号过滤：横盘状态下的信号质量较低
- 风险控制：横盘时更保守的策略

**代码实现**:
```python
amplitude_flat_threshold = 1e-6  # 可配置阈值

# 方法1：基于绝对幅度
is_sideways_abs = abs(macro_displacement) < amplitude_flat_threshold

# 方法2：基于相对幅度
amplitude_coefficient = macro_displacement / avg_price_20d
is_sideways_rel = abs(amplitude_coefficient) < threshold  # threshold 可配置

# 综合判断
is_sideways = is_sideways_abs or is_sideways_rel
```

### 2. 即时偏离度 (d20 - d)

**定义**: 衡量当前价格相对于均值的偏离程度

**计算公式**:
```
即时偏离度 = d20 - d = Close_t - MA20
```

**计算步骤**:
1. 计算20日移动平均价格: `MA20 = mean(Close_{t-19}, ..., Close_t)`
2. 获取当前收盘价 `Close_t`
3. 计算偏离度: `即时偏离度 = Close_t - MA20`

**经济意义**:
- **d20 > d**: 当前价格高于均值,处于强势阶段
- **d20 < d**: 当前价格低于均值,处于弱势阶段
- **d20 = d**: 当前价格等于均值,处于均衡状态

**判定条件**:
- 强势确认: `d20 > d`,表明个体已脱离低位震荡区域

**代码实现**:
df['ma20'] = df['close'].rolling(window=window).mean()
df['instant_deviation'] = df['close'] - df['ma20']
```

---

### 3. 乖离率 (Bias)

**定义**: 衡量当前价格偏离均线的幅度

**计算公式**:
```
Bias = (Pt - d) / d = (Close_t - MA20) / MA20
```

**计算步骤**:
1. 获取即时偏离度 `(Close_t - MA20)`
2. 除以均线值 `MA20`

**经济意义**:
- **Bias > 0**: 正乖离，股价在均线上方
- **Bias < 0**: 负乖离，股价在均线下方
- **数值大小**: 反映偏离的程度，过大可能导致回调(超买)，过小可能反弹(超卖)

**代码实现**:
```python
df['bias'] = (df['close'] - df['ma20']) / df['ma20']
```

---

### 3.5 日价格变化 (Daily Price Change)

**定义**: 衡量相邻交易日之间的价格变化

**计算公式**:
```
Δᵢ = dᵢ₊₁ - dᵢ = Close_{i+1} - Close_i
```

**计算步骤**:
1. 对每个交易日 i，计算与前一日的价格差: `Δᵢ = Close_i - Close_{i-1}`
2. 在20日窗口内，得到19个日变化值（因为需要19次比较）

**经济意义**:
- **Δᵢ > 0**: 第i天价格上涨
- **Δᵢ < 0**: 第i天价格下跌
- **Δᵢ = 0**: 第i天价格持平（横盘日）

**与Z/F的关系**:
- Z（上涨天数）= count(Δᵢ > 0) for i in [1, 19]
- F（下跌天数）= count(Δᵢ < 0) for i in [1, 19]
- 横盘日（Δᵢ = 0）既不计入Z也不计入F

**代码实现**:
```python
df['daily_change'] = df['close'].diff(1)  # Δᵢ = dᵢ - dᵢ₋₁
df['is_rising'] = (df['daily_change'] > 0).astype(int)
df['is_falling'] = (df['daily_change'] < 0).astype(int)
```

### 4. 上涨天数 (Z)

**定义**: 统计观察周期内价格上涨的交易日数量

**计算公式**:
```
Z = Σ I(Close_i > Close_{i-1})  for i in [t-19, t]
```

其中 `I()` 为指示函数,条件满足时为1,否则为0

**计算步骤**:
1. 对每个交易日,判断是否上涨: `is_rising_i = 1 if Close_i > Close_{i-1} else 0`
2. 在20日窗口内求和: `Z = Σ is_rising_i`

**经济意义**:
- **Z值越大**: 上涨天数越多,趋势越稳定
- **Z > F**: 上涨频率优势,确保趋势由持续买盘推动
- **Z < F**: 下跌频率占优,趋势不稳定

**代码实现**:
```python
df['is_rising'] = (df['close'] > df['close'].shift(1)).astype(int)
df['z'] = df['is_rising'].rolling(window=window).sum()
```

---

### 4. 下跌天数 (F)

**定义**: 统计观察周期内价格下跌的交易日数量

**计算公式**:
```
F = Σ I(Close_i < Close_{i-1})  for i in [t-19, t]
```

**计算步骤**:
1. 对每个交易日,判断是否下跌: `is_falling_i = 1 if Close_i < Close_{i-1} else 0`
2. 在20日窗口内求和: `F = Σ is_falling_i`

**经济意义**:
- **F值越大**: 下跌天数越多,趋势不稳定
- **F < Z**: 下跌天数少于上涨天数,趋势向上
- **F > Z**: 下跌天数多于上涨天数,趋势向下

**注意事项**:
- 横盘日(Close_i = Close_{i-1})既不计入Z也不计入F
- 理论上: `Z + F ≤ window - 1` (最多19个比较)

**代码实现**:
```python
df['is_falling'] = (df['close'] < df['close'].shift(1)).astype(int)
df['f'] = df['is_falling'].rolling(window=window).sum()
```

---

### 5. 进出效率指标 (m20 - m)

**定义**: 衡量当前成交量相对于平均成交量的活跃程度

**计算公式**:
```
进出效率 = m20 - m = Vol_t - MAVOL20
```

**计算步骤**:
1. 计算20日移动平均成交量: `MAVOL20 = mean(Vol_{t-19}, ..., Vol_t)`
2. 获取当前成交量 `Vol_t`
3. 计算效率指标: `进出效率 = Vol_t - MAVOL20`

**经济意义**:
- **m20 > m**: 当前成交量放大,资金活跃,换手率提升
- **m20 < m**: 当前成交量萎缩,资金观望,换手率下降
- **m20 = m**: 成交量处于平均水平

**量价共振逻辑**:
- **高效率上涨**: 价格上涨 + 成交量放大 (`m20 > m`)
- **低成色上涨**: 价格上涨 + 成交量萎缩 (`m20 < m`),稳定性差

**代码实现**:
```python
df['mavol20'] = df['volume'].rolling(window=window).mean()
df['efficiency'] = df['volume'] - df['mavol20']
```

## 综合判定规则

### 高效率上涨的量化条件

当以下三个维度的条件**同时满足**时,确认市场进入高效率演化轨道:

1. **价格维度**:
   - 宏观位移: `Δ > 0`
   - 即时强度: `d20 > d`

2. **频率维度**:
   - 上涨频率优势: `Z > F`

3. **成交量维度**:
   - 进出效率: `m20 > m`

### 入场操作建议

**理想入场点**:
- 价格向上穿越MA20: `d20 > d`
- 同时成交量突破MAVOL20: `m20 > m`

**幅度校验**:
- 计算相对位移系数: `Δ / d`
- 若系数过小,说明价格偏离均值幅度不足,需等待波幅放大

### 重点关注条件（风险预警）

**定义**: 识别可能进入下跌趋势或需要特别关注的股票

**判断条件**:
```
F > Z 且 d₂₀ < d₁
```

**经济意义**:
- **F > Z**: 下跌天数多于上涨天数，表明下跌频率占优
- **d₂₀ < d₁**: 当前价格低于起始价格，表明整体下跌
- **同时满足**: 说明股票可能进入下跌趋势，需要重点关注

**应用场景**:
- 风险预警：识别可能进入下跌轨道的股票
- 卖出信号：可作为卖出或减仓的参考条件
- 趋势反转：与买入信号（Z > F 且 d₂₀ > d₁）形成对比

**代码实现**:
```python
def check_attention_condition(falling_days, rising_days, d20, d1):
    """
    检查是否需要重点关注
    
    Returns:
        bool: True表示需要重点关注
    """
    return falling_days > rising_days and d20 < d1
```

## 计算示例

### 示例数据

假设某股票20个交易日的收盘价和成交量如下:

| 日期 | 收盘价 | 成交量 |
|------|--------|--------|
| Day 1 | 10.0 | 1000 |
| Day 2 | 10.2 | 1100 |
| ... | ... | ... |
| Day 19 | 11.5 | 1300 |
| Day 20 | 12.0 | 1500 |

### 计算过程

1. **MA20**: `(10.0 + 10.2 + ... + 11.5 + 12.0) / 20 = 11.0`
2. **MAVOL20**: `(1000 + 1100 + ... + 1300 + 1500) / 20 = 1200`
3. **Δ**: `12.0 - 10.0 = 2.0`
4. **即时偏离度**: `12.0 - 11.0 = 1.0`
5. **进出效率**: `1500 - 1200 = 300`
6. **Z**: 假设20天内有15天上涨,则 `Z = 15`
7. **F**: 假设20天内有4天下跌,则 `F = 4`

### 判定结果

- ✅ `Δ = 2.0 > 0` (宏观位移为正)
- ✅ `d20 = 12.0 > d = 11.0` (即时强度为正)
- ✅ `Z = 15 > F = 4` (上涨频率优势)
- ✅ `m20 = 1500 > m = 1200` (进出效率为正)

**结论**: 该股票满足高效率上涨的所有条件,可考虑入场

1. **数据质量**: 确保收盘价和成交量数据完整无缺失
2. **窗口期**: 至少需要20个交易日的历史数据才能计算
