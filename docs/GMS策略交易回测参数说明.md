## 2. 回测类型说明

| 回测类型 | 参数名 | 说明 |
|----------|--------|------|
| 策略信号命中率回测 | `signal_hit_rate` | 只判断观察期内最高价是否达到目标涨幅，**不模拟**完整开平仓、止损、手续费 |
| **交易回测** | `trade_simulation` | 按止损、止盈、移动止损、时间止损等规则模拟完整一笔交易，计算单笔收益率与组合净值 |

**本文档以下章节均针对「交易回测」。**

## 3. 核心概念：R（风险单位）

### 3.1 定义

开仓后，系统先根据 **止损比例** 计算 **初始止损价**，再定义：

```
R = 入场价 − 初始止损价
```

**R** 表示每股（每手）愿意承担的风险金额，是后续「保本触发(R)」「锁盈触发(R)」等参数的计量基准。

### 3.2 计算示例

| 项目 | 数值 |
|------|------|
| 入场价 | 10.00 元 |
| 止损比例 | 10% |
| 初始止损价 | 9.00 元 |
| **R** | **1.00 元** |

### 3.3 R 倍数与价格对应关系

| R 倍数 | 含义 | 上例中对应最高价（约） |
|--------|------|------------------------|
| 1R | 浮盈 = 1 倍初始风险 | 11.00 元 |
| 2R | 浮盈 = 2 倍初始风险 | 12.00 元 |
| 0.4R | 浮盈 = 0.4 倍初始风险 | 10.40 元 |

> **为何用 R 而不是固定百分比？**  
> 不同标的、不同止损宽度下，「赚了 5%」所代表的风险回报并不相同。用 R 统一衡量，可使保本、锁盈、分批止盈等规则与 **该笔交易的实际风险** 挂钩。

### 3.4 特殊情况

- 若 **止损比例填 0**，系统按约 **5%** 设置初始止损（兜底逻辑）。
- 若计算出的初始止损价 ≥ 入场价，系统会将初始止损调整为入场价的 99%。

## 4. 买入与出场总览

### 4.1 买入规则（交易回测）

| 步骤 | 规则 |
|------|------|
| 信号条件 | 当日出现 **左侧** 或 **右侧** 买点，且 **综合总分 ≥ 最低总分** |
| 入场价格 | **信号日下一交易日开盘价** |
| 去重 | 同一标的在上一笔观察期结束前不重复开仓 |
| 费用 | 买入价按 **滑点 + 手续费（单边 bps）** 折算为实际成交价 |

### 4.2 出场优先级（同一交易日内）

每个持仓交易日按以下顺序判断（先触发先执行）：

1. **止损**：当日最低价 ≤ 当前有效止损线  
2. **止盈**：当日最高价 ≥ 目标价，且 **分批止盈比例 = 0**（全额止盈）  
3. **时间止损**：持仓满 **时间止损 K 线数**，且浮盈仍 **< 1R** → 按当日收盘价平仓  
4. **时间出场**：观察期内未触发上述条件 → 以 **最后一根 K 线收盘价** 平仓  

> 同一天若同时满足止损与止盈条件，按 **止损优先** 处理。

### 4.3 有效止损线的构成

每个交易日，系统取下列止损线的 **最大值** 作为当日有效止损线：

1. **初始止损价**（由止损% 决定）  
2. **保本止损**（浮盈 ≥ 保本触发 R 后，止损线 ≥ 入场价）  
3. **锁盈止损**（浮盈 ≥ 锁盈触发 R 后，止损线 ≥ 入场价 + 锁盈保留 × R）  
4. **跟踪止损**（最高价 × (1 − 移动止损%)）

| 界面名称 | 参数名 | 说明 | 默认值 |
|----------|--------|------|--------|

## 6. 交易回测专用参数（详细说明）

以下参数 **仅在回测类型 = 交易回测** 时生效。

### 6.1 风险与成本类

#### 止损（%）

| 项目 | 内容 |
|------|------|
| 参数名 | `stop_loss_pct` |
| 含义 | 相对入场价的 **初始止损** 下跌比例 |
| 示例 | 10% → 入场 10 元，初始止损约 9 元 |
| 为 0 时 | 系统按约 **5%** 兜底 |
| 调参提示 | 越大 → 单笔容忍回撤越大，R 变大，后续 1R/2R 触发价位更远 |

#### 手续费（bps）

| 项目 | 内容 |
|------|------|
| 参数名 | `commission_bps` |
| 含义 | **单边** 手续费，1 bps = 0.01% |
| 示例 | 3 bps = 0.03%，买入、卖出各计一次 |
| 调参提示 | 用于贴近实盘佣金，避免回测收益偏高 |

#### 滑点（bps）

| 项目 | 内容 |
|------|------|
| 参数名 | `slippage_bps` |
| 含义 | **单边** 成交不利偏移（价差、冲击成本） |
| 示例 | 5 bps = 0.05%，买入价略高、卖出价略低 |
| 调参提示 | 流动性差、波动大的标的可适当调高 |

#### 单笔仓位（%）

| 项目 | 内容 |
|------|------|
| 参数名 | `position_fraction` |
| 含义 | 每笔投入占 **组合权益** 的比例，(0, 1] |
| 示例 | 50% → 半仓；其余资金视为现金、无收益 |
| 净值计算 | 按「单笔收益率 × 仓位比例」复利 |
| 调参提示 | 切换策略预设 **不会** 自动修改此参数 |

---

### 6.2 移动止损与利润保护（R 体系）

#### 移动止损（%）

| 项目 | 内容 |
|------|------|
| 参数名 | `trail_pct` |
| 含义 | 从持仓期 **最高价** 回撤多少比例触发止损 |
| 公式 | 跟踪止损线 = 最高价 × (1 − 移动止损%) |
| 示例 | 10%：最高 13 元 → 跟踪线 11.7 元 |
| 调参提示 | 越小越紧、越容易保住利润；越大越能给趋势「奔跑」空间 |

#### 保本触发（R）

| 项目 | 内容 |
|------|------|
| 参数名 | `breakeven_trigger_r` |
| 含义 | 浮盈达到多少倍 **R** 后，止损线抬至 **成本价（入场价）** |
| 示例 | 1.0：赚够 1R 后原则上不再亏损本金（仍受滑点/手续费影响） |
| 调参提示 | 越小越早保本，越大越允许回撤 |

#### 锁盈触发（R）

| 项目 | 内容 |
|------|------|
| 参数名 | `profit_lock_trigger_r` |
| 含义 | 浮盈达到该 R 倍数后，进入 **锁盈阶段** |
| 示例 | 2.0：最高价相对入场盈利达到 2R 时启用锁盈止损 |
| 调参提示 | 通常应 **大于** 保本触发 R |

#### 锁盈保留（R）

| 项目 | 内容 |
|------|------|
| 参数名 | `profit_lock_r` |
| 含义 | 锁盈后，止损线设在「入场价 + 该值 × R」 |
| 示例 | 0.4：锁盈后至少保留 0.4R 的利润垫 |
| 调参提示 | 越大保护越强，但也可能更早被洗出

---

### 6.3 止盈与时间类

#### 分批止盈触发（R）

| 项目 | 内容 |
|------|------|
| 参数名 | `partial_take_profit_r` |
| 含义 | 浮盈达到该 R 倍数后，**允许** 在目标价分批减仓 |
| 说明 | 仅当 **分批止盈比例 > 0** 时才实际执行分批；比例为 0 时等同关闭 |
| 预设惯例 | 稳健/平衡/进取预设常设为 **999**，实质关闭分批 |

#### 分批止盈比例

| 项目 | 内容 |
|------|------|
| 参数名 | `partial_take_ratio` |
| 含义 | 触发分批后，在 **目标涨幅价** 卖出的仓位比例，0～1 |
| 示例 | 0.4 = 卖 40%，剩余仓位继续受移动止损管理 |
| 为 0 时 | 触达目标价则 **全额止盈**（若未先止损） |

#### 时间止损 K 线数

| 项目 | 内容 |
|------|------|
| 参数名 | `time_stop_bars` |
| 含义 | 持仓满该 **交易日根数**，且浮盈仍 **< 1R** 时，按 **收盘价** 平仓 |
| 出场原因 | 记为「时间止损」 |
| 调参提示 | 用于清理长期横盘、迟迟不盈利的单子；数值越大越耐心 |

#### 目标涨幅（与止盈联动）

| 项目 | 内容 |
|------|------|
| 参数名 | `target_pct` |
| 含义 | 止盈目标价 = 入场价 × (1 + 目标涨幅) |
| 示例 | 5% → 入场 10 元，目标价 10.5 元 |

---

### 6.4 隐藏参数（界面未暴露）

界面提示：「已隐藏 ATR 高级参数，系统自动使用默认值。」

| 参数名 | 说明 | 当前实现 |
|--------|------|----------|

## 7. 策略预设对照表

管理端提供三种一键预设（切换预设 **不修改**「最低总分」与「单笔仓位」）：

| 参数 | 稳健型 | 平衡型（推荐） | 进取型 |
|------|--------|----------------|--------|
| 止损 (%) | 5 | 6 | 7 |
| 手续费 (bps) | 3 | 3 | 3 |
| 滑点 (bps) | 5 | 5 | 5 |
| 移动止损 (%) | 8 | 8 | 10 |
| 保本触发 (R) | 1.1 | 1.3 | 1.6 |
| 锁盈触发 (R) | 2.2 | 2.5 | 3.2 |
| 锁盈保留 (R) | 0.6 | 0.5 | 0.4 |
| 分批止盈触发 (R) | 999（关闭） | 999（关闭） | 999（关闭） |
| 分批止盈比例 | 0 | 0 | 0 |
| 时间止损 K 线数 | 10 | 12 | 16 |

**选用建议**：

- 首次回测建议用 **平衡型**，观察胜率、平均 R、时间止损占比后再微调。  
- **稳健型**：更早保本、更紧跟踪、更短时间止损。  
- **进取型**：更宽止损、更晚保本/锁盈、更长持仓耐心。

## 8. 参数协同示例

### 8.1 数值_walkthrough

**假设参数**：入场 10 元，止损 10%，保本 1R，锁盈 2R，锁盈保留 0.4R，移动止损 10%

| 步骤 | 计算 |
|------|------|
| 初始止损 | 9.00 元 |
| R | 1.00 元 |
| 保本触发价（约） | 最高价 ≥ 11.00 元 → 止损 ≥ 10.00 元 |
| 锁盈触发价（约） | 最高价 ≥ 12.00 元 → 止损 ≥ 10.40 元 |
| 跟踪止损示例 | 最高 13.00 元 → 跟踪线 11.70 元 |
| 有效止损 | 上述各项的 **最大值** |

### 8.2 流程简图

```
信号日次日开盘买入
    ↓
设置初始止损（止损%）
    ↓
逐日更新最高价 → 计算当前浮盈 R 倍数
    ↓
更新止损线：保本 / 锁盈 / 跟踪止损 → 取 max 为有效止损
    ↓
当日最低价 ≤ 有效止损？ → 是：止损出场
    ↓ 否
触达目标价且未分批？ → 是：止盈出场
    ↓ 否
满时间止损K线且浮盈<1R？ → 是：时间止损（收盘）
    ↓ 否
观察期结束 → 时间出场（最后收盘价）
```

## 10. 常见问题（FAQ）

**Q1：为什么很多单子是「时间止损」出场？**  
A：说明在 `time_stop_bars` 根 K 线内，价格未达到 1R 盈利，系统按规则收盘平仓。可适当增大时间止损 K 线数或降低最低总分/调整买点池。

**Q2：分批止盈比例填 0，触发 R 还有意义吗？**  
A：无实际分批效果；触达目标价时仍按 **全额止盈** 逻辑处理。

**Q3：移动止损和止损(%) 有什么区别？**  
A：**止损%** 决定开仓时的 **初始** 风险底线；**移动止损%** 在持仓过程中随 **最高价** 上移，用于保护已有浮盈。

**Q4：R 和「目标涨幅」有什么关系？**  
A：R 用于 **止损保护与锁盈**；目标涨幅用于 **止盈目标价**。二者独立，可分别调节。

## 11. 案例：科创板 GMS 观察股池回测复盘（2026-05～06）

### 11.1 样本来源

- 导出文件：`GMS回测_562500_688001…688008澜起科技.xlsx`
- 实际成交 6 笔均为 **科创板（688xxx）**，来自 **GMS 观察股池** 扫描信号
- 共同参数（基线）：止损 10%、移动止损 10%、保本 1R、锁盈 2R/0.4R、时间止损 20、半仓 50%、最低总分 70

### 11.2 结果摘要

| 指标 | 数值 |
|------|------|
| 胜率 | 0%（6 笔全亏） |
| 平均单笔收益 | -4.87% |
| 出场原因 | 6 笔均为「止损」 |
| 平均持仓 | 约 3.2 根 K 线 |
| 观察期命中率 | 83%（5/6 触达目标涨幅） |
| 观察期平均最大涨幅 | +41.7% |
| 持仓期平均 MFE | 仅 +5.7% |

### 11.3 核心矛盾

**信号在较长观察窗内多数正确，但交易模拟在 2～4 天内被止损洗出。**

典型现象：

- 688689：观察期最大涨幅 **+101%**，持仓 MFE 仅 +7.3%，4 天止损离场  
- 688663：MFE 约 +10% 后在成本附近保本出场（R 倍数 = 0），错过后续涨幅  
- 688788：右侧 80 分，MFE = 0，满额 -1R 止损（入场时机偏弱）

结论：**优先优化出场规则与分批止盈**，其次提高分数门槛；不宜先调仓位。
