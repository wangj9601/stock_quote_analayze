# 逻辑证伪应对系统 · 股票交易执行清单

> **系统目标**：不是每次看对，而是看错时有规则、亏得可控、看对时拿得住。  
> 来源：《逻辑证伪应对系统》— 把预测转化为预案，把情绪转化为规则。

---

## 一、交易前总原则（RULES BEFORE TRADE）

| # | 原则 | 自检 |
|---|------|------|
| □ | 把「预测」转化为「预案」，不凭感觉下单 | |
| □ | 把「情绪」转化为「规则」，盘中波动不替代确认 | |
| □ | 逻辑证伪 ≠ 固定比例止损，而是「买入理由被推翻就退出」 | |
| □ | A 股 T+1：以**收盘确认**为准，盘中假突破/假跌破不算数 | |

| **周期条件** | 例：月线趋势向上；周线回调至支撑位；日线放量确认 | □ |

| **环境条件** | 例：板块资金仍在流入；大盘无系统性风险 | □ |

## 三、分层应对规则（持仓期间）

> 不要把所有波动都当成卖出信号。

| 层级 | 触发情形 | 应对动作 |
|------|----------|----------|
| **轻微异常** | 日线走弱，但周线结构尚未破坏 | 减仓观察，不急于清仓 |
| **关键位失守** | 收盘跌破预设支撑，原交易逻辑被证伪 | **执行止损**，按预案退出 |
| **逻辑完全反向** | 周期 + 结构 + 板块**同时转弱** | **清仓停手**，禁止补仓摊平 |

---

## 四、收盘确认规则（减少噪音）

| 级别 | 确认时点 | 看什么 | 决策含义 |
|------|----------|--------|----------|
| **D 日线** | 当日收盘 | 是否收回/守住关键位 | 避免被盘中假跌破带偏 |
| **W 周线** | 周五收盘 | 是否守住支撑 | 决定波段逻辑是否延续 |
| **M 月线** | 月末收盘 | 是否维持趋势结构 | 判断长期生态是否改变 |

## 五、单笔交易快速执行清单（一页版）

### 【买入前】

- [ ] 买入理由写成**具体可检验条件**，不是一句感觉
- [ ] 每条买入理由都有**对应的证伪条件**
- [ ] 已预设**退出位**和**确认周期**（日/周/月）
- [ ] 已设计**看对时的加仓/止盈/持有规则**
- [ ] 已明确**最大可接受亏损**

### 【买入时】

- [ ] 股票代码/名称：________　买入价：________　仓位：________
- [ ] 买入日期：________　计划持有周期：________

### 【持仓中 · 每日/每周检查】

- [ ] 是否出现**轻微异常**？→ 减仓观察
- [ ] 是否**关键位失守**（收盘确认）？→ 执行止损
- [ ] 是否**逻辑完全反向**？→ 清仓停手，禁止摊平

### 【收盘后复盘】

- [ ] 今日/本周收盘是否触发证伪条件？
- [ ] 是否严格执行预案？（严格执行 / 偏差较大）
- [ ] 是否有情绪化操作？（无 / 轻微 / 严重）
- [ ] 交易结果总结：_______________________________________________

## 七、与 PPT 框架对照

| PPT 章节 | 清单对应部分 |
|----------|-------------|
| 核心定义 | 一、总原则 |

---

**一句话总结**：逻辑越具体，越容易知道什么时候错了；看错时有规则，比每次看对更重要。
