# 多指标综合交易策略设计文档

## 1. 项目概述

### 1.1 项目背景
随着股票市场的发展和投资者对技术分析需求的增加，单一技术指标往往无法全面反映市场状态。本项目旨在设计一个基于多个技术指标（MACD、KDJ、RSI、BOLL、PVFRS）的综合交易策略，通过多维度分析提高交易信号的准确性和可靠性。

### 1.2 项目目标
- 实现基于MACD、KDJ、RSI、BOLL、PVFRS五个核心指标的综合交易策略
- 提供完整的回测框架，验证策略有效性
- 实现风险控制机制，保护投资资金
- 提供灵活的参数配置，适应不同市场环境

## 2. 技术指标详解

### 2.1 MACD（移动平均收敛发散指标）
- **计算方法**：
  - 快速EMA(12)：12日指数移动平均线
  - 慢速EMA(26)：26日指数移动平均线
  - DIF = 快速EMA - 慢速EMA
  - DEA(9) = DIF的9日指数移动平均
  - MACD柱 = (DIF - DEA) × 2

- **信号规则**：
  - 金叉：DIF上穿DEA，且MACD柱由负转正
  - 死叉：DIF下穿DEA，且MACD柱由正转负

### 2.2 KDJ（随机指标）
- **计算方法**：
  - RSV = (收盘价 - N日内最低价) / (N日内最高价 - N日内最低价) × 100
  - K = 2/3 × 前一日K值 + 1/3 × 当日RSV
  - D = 2/3 × 前一日D值 + 1/3 × 当日K值
  - J = 3 × 当日K值 - 2 × 当日D值

- **信号规则**：
  - 超卖区金叉：J < 20 且 K上穿D
  - 超买区死叉：J > 80 且 K下穿D

### 2.3 RSI（相对强弱指标）
- **计算方法**：
  - RSI = 100 - [100 ÷ (1 + RS)]
  - RS = N日内上涨幅度平均值 ÷ N日内下跌幅度平均值

- **信号规则**：
  - 超卖反弹：RSI从<30回升至>30
  - 超买回落：RSI从>70回落至<70

### 2.4 BOLL（布林带）
- **计算方法**：
  - 中轨(MA20)：20日简单移动平均
  - 标准差：20日收盘价的标准差
  - 上轨：中轨 + 2 × 标准差
  - 下轨：中轨 - 2 × 标准差

- **信号规则**：
  - 下轨反弹：价格触及下轨后回升
  - 上轨回调：价格触及上轨后回落

### 2.5 PVFRS（均值频率共振指标）
- **计算方法**：
  - 乖离率(Bias)：(当前价格 - 均值) / 均值
  - 宏观位移Delta：d20 - d1（20日与1日差值）
  - 其他相关指标的计算

- **信号规则**：
  - 乖离过大反弹：Bias < -0.05
  - 乖离过大回调：Bias > 0.05

## 3. 策略设计

### 3.1 买入信号规则
满足以下条件中的至少3个才能形成买入信号：
1. MACD出现金叉信号
2. KDJ出现金叉信号
3. RSI出现超卖反弹信号
4. BOLL出现下轨反弹信号
5. PVFRS出现积极共振信号

### 3.2 卖出信号规则
满足以下条件中的至少3个才能形成卖出信号：
1. MACD出现死叉信号
2. KDJ出现死叉信号
3. RSI出现超买回落信号
4. BOLL出现上轨回调信号
5. PVFRS出现负面共振信号

### 3.3 风险控制机制
- **仓位管理**：每次交易风险不超过总资金的2%
- **止损机制**：单笔交易亏损超过5%时强制平仓
- **资金管理**：最大使用90%资金进行交易

## 6. 回测系统设计

### 6.1 回测流程
1. 加载历史数据
2. 生成交易信号
3. 执行交易模拟
4. 计算绩效指标
5. 生成报告和图表

### 6.2 绩效指标
- **总收益率**：(最终资金 - 初始资金) / 初始资金
- **胜率**：盈利交易数 / 总交易数
- **夏普比率**：(年化收益率 - 无风险利率) / 年化波动率
- **最大回撤**：净值回撤的最大值
- **盈利因子**：总盈利 / 总亏损

### 6.3 数据源支持
- 支持从数据库加载A股/港股历史数据
- 支持CSV文件导入
- 支持示例数据生成

## 7. 使用说明

### 7.1 命令行参数
```bash
python strategy_runner.py [options]

Options:
  --mode {backtest,live,paper}    运行模式 (默认: backtest)
  --symbol TEXT                   股票代码 (默认: 000001)
  --start-date TEXT               开始日期 (默认: 2023-01-01)
  --end-date TEXT                 结束日期 (默认: 2023-12-31)
  --capital FLOAT                 初始资金 (默认: 100000)
  --risk-per-trade FLOAT          每次交易风险比例 (默认: 0.02)
  --market-type {CN,HK}           市场类型 (默认: CN)
  --plot                          是否绘制回测结果图表
  --export-results TEXT           导出结果到指定JSON文件路径
```

### 7.2 示例命令
```bash
# 默认回测
python strategy_runner.py

# 指定股票回测
python strategy_runner.py --symbol 000001 --start-date 2023-01-01 --end-date 2023-12-31

# 生成图表并导出结果
python strategy_runner.py --plot --export-results results.json
```
