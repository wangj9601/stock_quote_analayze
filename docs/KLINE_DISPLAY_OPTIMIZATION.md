# K线图初始显示范围优化说明

## 问题描述

用户反馈个股详情页面中，K线显示太密集，从2008年至今的所有数据都显示在屏幕上，导致K线过于密集，难以查看。

**问题截图分析**:
- 时间范围：2008-09-17 至 2025-09-24（约17年）
- 显示了所有历史数据，导致K线密集

## 根本原因

代码中存在两处设置 dataZoom 的逻辑：

1. **第一处**（正确的设置）：在数据加载后，设置显示最近250根K线（约一年）
   - A股: `stock.js` 第 3735-3746 行
   - 港股: `stock_hk.js` 第 2951-2963 行

2. **第二处**（错误的覆盖）：在数据量优化逻辑中，当数据量 > 200 时，覆盖了第一处的设置
   - A股: `stock.js` 第 4017-4034 行 - 设置 `start = 50`（显示后50%的数据）
   - 港股: `stock_hk.js` 第 3113-3123 行 - 设置 `start = 50`（显示后50%的数据）

由于第二处逻辑在第一处之后执行，导致初始缩放设置被覆盖，显示了约50%的历史数据（约8-9年），而不是预期的一年。

## 解决方案

### 修改文件
1. **A股**: `frontend/js/stock.js`
2. **港股**: `frontend/js/stock_hk.js`

### 修改内容

删除了当数据量 > 200 时覆盖 dataZoom 设置的代码块，确保初始显示范围保持为最近250根K线（约一年）。

**A股修改**（`stock.js` 第 4015-4034 行）:
```javascript
// 修改前
} else {
    // 数据量充足时，保持原有的显示方式，但使用更宽的默认宽度
    option.dataZoom[0].start = 50;  // ❌ 覆盖了之前的设置
    option.dataZoom[0].end = 100;
    // ... 其他设置
}

// 修改后
}
// 注意：当数据量 > 200 时，使用前面已经设置好的缩放范围（显示最近250根K线）
// 不再覆盖 dataZoom 设置，保持初始显示最近一年的数据
```

**港股修改**（`stock_hk.js` 第 3074-3123 行）:
```javascript
// 修改前
} else {
    // 数据量充足时，保持原有的显示方式，但使用更宽的默认宽度
    option.dataZoom[0].start = 50;  // ❌ 覆盖了之前的设置
    option.dataZoom[0].end = 100;
    // ... 其他设置
}

// 修改后
}
// 注意：当数据量 > 200 时，使用前面已经设置好的缩放范围（显示最近250根K线）
// 不再覆盖 dataZoom 设置，保持初始显示最近一年的数据
```

## 效果说明

### 修改前
- 初始显示：约50%的历史数据（8-9年）
- K线密集，难以查看细节

### 修改后
- 初始显示：最近250根K线（约一年）
- K线清晰，便于查看
- 用户可以通过缩放工具查看更多历史数据

## 不同数据量的显示策略

修改后的显示策略如下：

| 数据量 | 初始显示范围 | 说明 |
|--------|------------|------|
| ≤ 30根 | 全部显示 | 数据很少，显示全部 |
| 31-80根 | 全部显示 | 数据较少，显示全部 |
| 81-200根 | 显示最近100根 | 中等数据量 |
| > 200根 | 显示最近250根 | **约一年数据，避免密集** |

## 用户体验改进

1. ✅ **初始视图清晰**: 打开股票详情页时，K线不再密集
2. ✅ **聚焦近期数据**: 默认显示最近一年的数据，符合大多数用户的查看习惯
3. ✅ **保留历史数据**: 用户仍可通过拖动或缩放查看更早的历史数据
4. ✅ **一致性**: A股和港股使用相同的显示策略

1. 打开任意股票详情页（A股或港股）

3. 预期结果：
   - 显示最近约一年的数据（约250根K线）
