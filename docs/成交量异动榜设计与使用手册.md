# 成交量异动榜 设计与使用手册

本文档说明「行情页成交量异动榜」功能的设计、实现要点，以及**指标补丁程序**（MAVOL、MA、GMS 均值频率共振）的设计与使用方法。

---

## 一、功能概述

在**前端 → 行情 → 涨跌排行**区域增加「成交量异动榜」入口，用于按**量比**对当日股票进行排行（放量榜 / 缩量榜），支持 A 股与港股切换、日期选择、分页与导出。

### 1.1 异动定义

- **量比(20)** = 当日成交量 ÷ MAVOL20（20 日成交量均线）
- **放量榜**：按量比(20) 从高到低排序，放量居前
- **缩量榜**：按量比(20) 从低到高排序，缩量居前
- 仅展示**当日有均量指标**的股票（行情表与 `mavol_indicators` 能按 code、date 关联上的记录）

---

## 二、数据来源与表结构

### 2.1 数据来源

| 市场 | 日行情表 | 均量指标表 | 关联条件 |
|------|----------|------------|----------|
| A 股 | `historical_quotes` | `mavol_indicators`（market_type='CN'） | code、date（统一为 YYYY-MM-DD） |
| 港股 | `historical_quotes_hk` | `mavol_indicators`（market_type='HK'） | code、date |

- `historical_quotes.date` 为 Date 类型，`historical_quotes_hk.date` 为 String；JOIN 时按同一日期格式（如 'YYYY-MM-DD'）匹配。
- 若某日某股票在行情表有数据但 `mavol_indicators` 无对应 code/date，则无法计算量比，**不进入榜单**（建议仅展示量比可算的股票）。

### 2.2 列表字段

| 字段名 | 说明 | 数据来源 |
|--------|------|----------|
| 排名 | 按量比排序后的序号 | 计算 |
| 股票代码 | code | 行情表 |
| 股票名称 | name | 行情表 |
| 日期 | 交易日期 | 行情表 |
| 当日成交量 | volume | 行情表（单位：手；展示按手：万手/亿手，÷10000/÷1e8） |
| 成交额 | amount | 行情表 |
| MAVOL5 | 5 日均量 | mavol_indicators |
| MAVOL10 | 10 日均量 | mavol_indicators |
| MAVOL20 | 20 日均量 | mavol_indicators |
| 量比(5) | volume / mavol5 | 计算 |
| 量比(20) | volume / mavol20 | 计算 |
| 涨跌幅(%) | change_percent | 行情表 |
| 收盘价 | close | 行情表 |
| 换手率(%) | turnover_rate | 行情表 |
| 操作 | 跳转详情/历史页、自选 | 前端 |

导出 CSV/Excel 时**不含「操作」列**，其余与上表一致；股票代码列建议加 `\u2060` 前缀，避免 Excel 吞前导零。

## 三、后端设计

### 3.1 接口

- **路径**：`GET /api/stock/volume_aberration_list`
- **位置**：`backend_api/stock/stock_manage.py`

### 3.2 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| market | string | 是 | 市场：`cn`（A 股）/ `hk`（港股） |
| date | string | 否 | 交易日期 YYYY-MM-DD；不传则取该市场行情表最新交易日 |
| order | string | 否 | 排序：`desc` 放量榜（默认）/ `asc` 缩量榜 |
| page | int | 否 | 页码，默认 1 |
| page_size | int | 否 | 每页条数，默认 20，最大 500 |

### 3.3 返回格式

```json
{
  "success": true,
  "data": [
    {
      "rank": 1,
      "code": "000001",
      "name": "平安银行",
      "date": "2026-03-06",
      "volume": 12345678,
      "amount": 1.23e9,
      "mavol5": 10000000,
      "mavol10": 9500000,
      "mavol20": 9000000,
      "ratio_5": 1.23,
      "ratio_20": 1.37,
      "change_percent": 2.5,
      "close": 12.34,
      "turnover_rate": 5.6
    }
  ],
  "total": 5000,
  "date": "2026-03-06",
  "page": 1,
  "page_size": 20
}
```

### 3.4 逻辑要点

- A 股：`historical_quotes` INNER JOIN `mavol_indicators`（market_type='CN'），条件 `m.mavol20 IS NOT NULL AND m.mavol20 > 0`，按量比(20) 排序后分页。
- 港股：`historical_quotes_hk` INNER JOIN `mavol_indicators`（market_type='HK'），同上。
- 量比(5)、量比(20) 在对应 mavol 为 0 或空时不除，返回 null；前端可显示「--」。

### 3.5 计算逻辑与 SQL（现网口径）

以下为当前后端实际执行口径（保持现逻辑）：

1. 入参校验：`market in {cn,hk}`，`order in {desc,asc}`。  
2. 交易日确定：  
   - A 股：若未传 `date`，取 `historical_quotes.date` 最大值；  
   - 港股：若未传 `date`，取 `historical_quotes_hk.date` 最大值。  
3. 查询当日行情与均量：行情表 INNER JOIN `mavol_indicators`（按 `code + date + market_type`）。  
4. 强过滤：仅保留 `m.mavol20 IS NOT NULL AND m.mavol20 > 0` 的记录（即仅展示可算量比(20)的股票）。  
5. 逐行计算：  
   - `ratio_5 = volume / mavol5`（`mavol5 > 0` 才计算）；  
   - `ratio_20 = volume / mavol20`（`mavol20 > 0` 才计算）；  
   - 两者保留 4 位小数。  
6. 排序与排名：  
   - `desc`：按 `ratio_20` 降序（放量榜）；  
   - `asc`：按 `ratio_20` 升序（缩量榜）；  
   - 空值放末尾（当前因强过滤基本不会出现）；  
   - 结果按排序顺序生成 `rank=1..N`。  
7. 分页：先算全量结果，再按 `page/page_size` 切片。

#### A 股 SQL

```sql
SELECT h.code, h.name, h.date, h.volume, h.amount, h.change_percent, h.close, h.turnover_rate,
       m.mavol5 AS mavol5, m.mavol10 AS mavol10, m.mavol20 AS mavol20
FROM historical_quotes h
INNER JOIN mavol_indicators m ON h.code = m.code AND m.market_type = 'CN'
   AND m.date = :trade_date
WHERE h.date = :h_date
  AND m.mavol20 IS NOT NULL AND m.mavol20 > 0
```

#### 港股 SQL

```sql
SELECT h.code, h.name, h.date, h.volume, h.amount, h.change_percent, h.close, h.turnover_rate,
       m.mavol5 AS mavol5, m.mavol10 AS mavol10, m.mavol20 AS mavol20
FROM historical_quotes_hk h
INNER JOIN mavol_indicators m ON h.code = m.code AND m.market_type = 'HK'
   AND m.date = :trade_date
WHERE h.date = :trade_date
  AND m.mavol20 IS NOT NULL AND m.mavol20 > 0
```

#### 排序实现（服务层）

```python
result.sort(key=lambda x: (
    x["ratio_20"] is None,
    -(x["ratio_20"] or 0) if order == "desc" else (x["ratio_20"] or 0)
))
```

#### 说明（为什么“当日行情条数”大于“榜单条数”）

- 榜单并非直接展示当日全部行情，而是仅展示能计算 `量比(20)` 的股票。  
- 若当日某股票 `mavol20` 为空（常见于历史样本不足 20 日或指标未补齐），会被上述 SQL 过滤掉。

## 四、前端设计

### 4.1 入口与布局

- **入口**：行情页 → 涨跌排行 → 与「涨幅榜」「跌幅榜」「成交量榜」「换手率榜」并列，增加按钮「**成交量异动榜**」。
- **选中后**：
  - 显示**市场**：A股 / 港股
  - **日期**：可选（留空为最新交易日）
  - **排序**：放量榜 / 缩量榜
  - **查询**、**导出 CSV**、**导出 Excel**
  - **异动说明**：单独一行信息框，说明量比(20)=当日成交量÷MAVOL20、放量榜/缩量榜含义、仅展示有均量指标的股票。

### 4.2 表格与分页

- 表头与「二、列表字段」一致，最后一列为「操作」（如 +自选、历史）。
- 分页复用涨跌排行组件，翻页时请求 `volume_aberration_list` 对应 `page`。

### 4.3 导出

- **CSV**：当前页数据，表头与列表一致（不含操作），股票代码列加 `\u2060` 前缀，UTF-8 BOM，文件名含日期。
- **Excel**：当前页数据，同上规则，使用 SheetJS（xlsx），`XLSX.writeFile` 下载 .xlsx。

### 4.4 涉及文件

- `frontend/markets.html`：成交量异动榜按钮、工具栏、异动说明区域、表格容器
- `frontend/js/markets.js`：`loadVolumeAberrationData`、`renderVolumeAberrationTable`、`exportVolumeAberrationCsv`、`exportVolumeAberrationExcel`、分页与切换逻辑
- `frontend/css/markets.css`：`.volume-aberration-hint-wrap`、`.volume-aberration-hint-inner` 等样式

## 五、MAVOL 补丁程序（设计与使用）

成交量异动榜依赖 `mavol_indicators` 表有数据。若该表为空或缺失某日/某市场数据，需先运行**补丁程序**全量或按需计算 MAVOL 指标。

### 5.1 补丁设计

- **脚本路径**：`manual_scripts/mavol_indicators_backfill.py`
- **作用**：对 A 股、港股全部股票，用历史行情表（`historical_quotes` / `historical_quotes_hk`）的 **volume** 列，计算 MAVOL5/10/20/30/60/120/200，写入 `mavol_indicators`。
- **已存在**：(code, date, market_type) 已存在时**跳过**，不重复计算（默认先查再插；可选 `--no-skip` 直接插入，重复由数据库 `ON CONFLICT DO UPDATE` 覆盖）。
- **依赖**：`backend_api.database.SessionLocal`、`backend_core.utils.mavol_calculator.MAVOLCalculator`。
- **计算规则**：按股票、按日期升序取 volume，滚动窗口计算各周期均量（与 `MAVOLCalculator.calculate_mavol_for_dataframe` 一致）。

### 5.2 使用说明

**运行环境**：在项目根目录执行，确保已配置 `backend_api.database` 所用数据库（与主应用一致）。

**命令示例**：

```bash
# 全量：A 股 + 港股，已存在记录跳过


# 仅 A 股
python manual_scripts/mavol_indicators_backfill.py --market CN

# 仅港股
python manual_scripts/mavol_indicators_backfill.py --market HK

# 指定日期范围
python manual_scripts/mavol_indicators_backfill.py --market ALL --start-date 2025-01-01 --end-date 2026-03-01
python manual_scripts/mavol_indicators_backfill.py --market HK --start-date 2026-03-17 --end-date 2026-03-20
python manual_scripts/mavol_indicators_backfill.py --market CN --start-date 2025-01-01 --end-date 2026-03-01


# 只跑一只股票（自动判断 A 股/港股）
python manual_scripts/mavol_indicators_backfill.py --code 000001

# 测试：只处理前 5 只
python manual_scripts/mavol_indicators_backfill.py --market ALL --test 5

# 不跳过已存在，直接插入（重复由 DB 忽略，可加速全量重跑）
python manual_scripts/mavol_indicators_backfill.py --market ALL --no-skip
```

**参数说明**：

| 参数 | 说明 |
|------|------|
| `--market` | ALL（默认）/ CN / HK |
| `--start-date` | 开始日期 YYYY-MM-DD（可选） |
| `--end-date` | 结束日期 YYYY-MM-DD（可选） |
| `--code` | 仅处理该股票代码（可选） |
| `--no-skip` | 不逐条检查是否已存在，直接插入 |
| `--test N` | 仅处理前 N 只股票（测试用） |

**日志**：若存在 `logs/` 目录，会写入 `logs/mavol_backfill.log`，同时输出到控制台。

**数据库**：插入使用 `ON CONFLICT (code, date, market_type) DO UPDATE`（PostgreSQL）。若使用 MySQL，需自行改为 `ON DUPLICATE KEY UPDATE` 或等价写法。

## 六、MA 补丁程序（设计与使用）

用于全量计算 A 股与港股全部股票的 **MA 移动平均线指标**（`ma_indicators` 表），供技术分析、选股等使用。已计算的记录跳过，不重复计算。

### 6.1 补丁设计

- **脚本路径**：`manual_scripts/ma_indicators_backfill.py`
- **作用**：对 A 股、港股全部股票，用历史行情表（`historical_quotes` / `historical_quotes_hk`）的 **close**（收盘价）列，计算 MA5/10/20/30/60/120/200，写入 `ma_indicators`。
- **已存在**：(code, date, market_type) 已存在时**跳过**，不重复计算（默认先查再插；可选 `--no-skip` 直接插入，重复由数据库 `ON CONFLICT DO NOTHING` 忽略）。
- **依赖**：`backend_api.database.SessionLocal`、`backend_core.utils.ma_calculator.MACalculator`。
- **计算规则**：按股票、按日期升序取 close，滚动窗口计算各周期均线（与 `MACalculator.calculate_ma_for_dataframe` 一致，周期 5/10/20/30/60/120/200）。

### 6.2 使用说明

**运行环境**：在项目根目录执行，确保已配置 `backend_api.database` 所用数据库。

## 七、GMS 策略（均值频率共振）补丁程序（设计与使用）

用于全量计算 A 股与港股全部股票的 **GMS 均值频率共振指标**（`mean_frequency_resonance_indicators` 表），供 GMS 选股策略、信号追溯等使用。已存在的记录跳过，不重复计算。

### 7.1 补丁设计

- **脚本路径**：`manual_scripts/gms_mean_frequency_backfill.py`
- **作用**：对 A 股、港股全部股票，用历史行情表（`historical_quotes` / `historical_quotes_hk`）的 **close、volume** 列，按 20 日窗口计算均值频率共振指标，写入 `mean_frequency_resonance_indicators`。
- **已存在**：(code, date, market_type) 已存在时**跳过**，不重复计算（默认先查再插；可选 `--no-skip` 直接插入，重复由数据库 `ON CONFLICT DO NOTHING` 忽略）。
- **依赖**：`backend_api.database.SessionLocal`、`backend_core.utils.mean_frequency_calculator.MeanFrequencyResonanceCalculator`。
- **计算规则**：窗口 20 日；指标包括：宏观位移 Delta、幅度 ratio_d20/ratio_d1、即时偏离度、上涨/下跌天数 Z/F、进出效率、MA20、MAVOL20、乖离率 bias、d1/d20 及对应日期等（与 `MeanFrequencyResonanceCalculator.calculate` 一致）。

### 7.2 写入字段

与表结构一致，主要包括：`macro_displacement_delta`、`amplitude`、`ratio_d20`、`ratio_d1`、`instant_deviation`、`rising_days_z`、`falling_days_f`、`efficiency_m20_minus_m`、`ma20_d`、`mavol20_m`、`bias`、`d1`、`d1_date`、`d20`、`d20_date`、`created_at`。

### 7.3 使用说明

## 八、常见问题

1. **MAVOL、量比列全部为「--」**  
   - 该交易日在 `mavol_indicators` 中无数据或未跑补丁。  
   - 解决：对对应市场/日期运行 `mavol_indicators_backfill.py`，再刷新页面。

2. **异动说明排版**  
   - 异动说明为独立一行信息框，位于筛选区与表格之间，避免与按钮挤在一行。

3. **导出后 Excel 中股票代码前导零丢失**  
   - 导出时已对股票代码列加 `\u2060` 前缀，若仍异常可检查前端导出逻辑是否对该列统一加了前缀。

## 九、运维排查 SQL 模板

以下 SQL 可直接用于排查“为什么榜单条数少于当日行情条数”。

### 9.1 港股（示例日期：`2026-03-19`）

```sql
-- 1) 当日港股历史行情总数
SELECT COUNT(1) AS hk_hist_total
FROM historical_quotes_hk
WHERE date = '2026-03-19';

-- 2) 满足榜单条件的条数（JOIN + mavol20有效）
SELECT COUNT(1) AS hk_board_total
FROM historical_quotes_hk h
INNER JOIN mavol_indicators m
  ON h.code = m.code
 AND m.market_type = 'HK'
 AND m.date = '2026-03-19'
WHERE h.date = '2026-03-19'
  AND m.mavol20 IS NOT NULL
  AND m.mavol20 > 0;

-- 3) 当日港股中，mavol20为空的条数（主要过滤来源）
SELECT COUNT(1) AS hk_mavol20_null
FROM historical_quotes_hk h
INNER JOIN mavol_indicators m
  ON h.code = m.code
 AND m.market_type = 'HK'
 AND m.date = '2026-03-19'
WHERE h.date = '2026-03-19'
  AND m.mavol20 IS NULL;
```

### 9.2 A 股（示例日期：`2026-03-19`）

```sql
-- 1) 当日A股历史行情总数
SELECT COUNT(1) AS cn_hist_total
FROM historical_quotes
WHERE date = '2026-03-19';

-- 2) 满足榜单条件的条数（JOIN + mavol20有效）
SELECT COUNT(1) AS cn_board_total
FROM historical_quotes h
INNER JOIN mavol_indicators m
  ON h.code = m.code
 AND m.market_type = 'CN'
 AND m.date = '2026-03-19'
WHERE h.date = '2026-03-19'
  AND m.mavol20 IS NOT NULL
  AND m.mavol20 > 0;

-- 3) 当日A股中，mavol20为空的条数（主要过滤来源）
SELECT COUNT(1) AS cn_mavol20_null
FROM historical_quotes h
INNER JOIN mavol_indicators m
  ON h.code = m.code
 AND m.market_type = 'CN'
 AND m.date = '2026-03-19'
WHERE h.date = '2026-03-19'
  AND m.mavol20 IS NULL;
```
