## 核心功能验证

### 错误分类逻辑

ErrorHandler 实现了4种错误分类：

1. **用户输入错误** (USER_INPUT_ERROR)
   - 关键词: invalid email, invalid format, validation error
   - 异常类型: ValueError, ValidationError
   - 处理策略: 不重试，警告级别日志

2. **数据错误** (DATA_ERROR)
   - 关键词: no data, data not found, missing data, empty watchlist
   - 处理策略: 不重试，警告级别日志

3. **服务不可用错误** (SERVICE_UNAVAILABLE)
   - 关键词: connection, timeout, network, unavailable, smtp
   - 异常类型: ConnectionError, TimeoutError, SMTPException
   - 处理策略: 应该重试，错误级别日志

4. **系统错误** (SYSTEM_ERROR)
   - 默认分类
   - 处理策略: 根据具体情况决定是否重试

### 重试策略

实现了指数退避策略：
- 第1次重试: 1分钟后
- 第2次重试: 5分钟后
- 第3次重试: 15分钟后
- 后续重试: 保持15分钟间隔

### 日志记录

根据错误类型使用不同的日志级别：
- 用户输入错误、数据错误: WARNING
- 服务不可用、系统错误: ERROR
