### 12.2 创建启动脚本 ✅

#### 1. start_scheduler.py - 调度器启动脚本

**功能**:
- 启动推送调度器
- 在配置的时间点自动触发推送任务
- 支持守护进程模式运行

**命令行参数**:
- `--config-file`: 指定配置文件路径
- `--push-times`: 指定推送时间点 (逗号分隔)
- `--log-level`: 日志级别 (DEBUG/INFO/WARNING/ERROR)
- `--daemon`: 以守护进程模式运行
- `--pid-file`: PID文件路径

**特性**:
- 完整的日志记录 (文件+控制台)
- 信号处理 (SIGINT, SIGTERM)
- PID文件管理
- 优雅的启动和停止
- 自动初始化所有服务组件

**使用示例**:
```bash
# 前台运行
python start_scheduler.py

# 指定推送时间
python start_scheduler.py --push-times "09:30,15:30,21:00"

# 后台运行
python start_scheduler.py --daemon --pid-file scheduler.pid

# 调试模式
python start_scheduler.py --log-level DEBUG
```

#### 2. init_db.py - 数据库初始化脚本

**功能**:
- 创建数据库表
- 运行数据库迁移脚本
- 验证表结构
- 显示数据库状态

**命令行参数**:
- `--migration-dir`: 迁移脚本目录
- `--dry-run`: 模拟模式，不实际执行
- `--force`: 强制执行迁移
- `--rollback`: 回滚最后一次迁移
- `--status`: 显示数据库状态
- `--verify`: 验证表结构

**特性**:
- 自动创建所有必需的表
- 支持增量迁移
- 表结构验证
- 详细的日志输出
- 模拟模式预览操作

**使用示例**:
```bash
# 查看将要执行的操作
python init_db.py --dry-run

# 执行数据库迁移
python init_db.py

# 验证表结构
python init_db.py --verify

# 查看数据库状态
python init_db.py --status
```

#### 3. generate_test_data.py - 测试数据生成脚本

**功能**:
- 生成测试用户
- 生成推送配置
- 生成自选股数据
- 生成历史推送记录
- 清除测试数据

**命令行参数**:
- `--users`: 生成的测试用户数量
- `--stocks`: 每个用户的自选股数量
- `--clean`: 清除现有测试数据
- `--seed`: 随机种子
- `--no-records`: 不生成推送记录

**特性**:
- 生成真实的测试数据
- 支持自定义数据量
- 可重复的随机数据 (通过seed)
- 自动生成多样化的配置
- 数据摘要显示

**使用示例**:
```bash
# 生成5个测试用户，每个10只自选股
python generate_test_data.py --users 5 --stocks 10

# 清除测试数据
python generate_test_data.py --clean

# 生成数据但不生成推送记录
python generate_test_data.py --users 3 --no-records
```
