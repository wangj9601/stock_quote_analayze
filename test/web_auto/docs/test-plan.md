# 管理端自动化测试方案及用例

针对本项目管理端（Vue 3 + Element Plus）和已有的 `test/web_auto` 框架，特制定此自动化测试方案。

## 1. 自动化框架扩展建议

基于现有 `test/web_auto` 逻辑，建议进行以下扩展：

*   **增强 POM (Page Object Model)**：针对 PVFRS 管理、数据采集等复杂页面，建立独立的 Page 类，封装 Element Plus 特定组件（如 `el-dialog`, `el-table`, `el-tabs`）的操作逻辑。
*   **状态同步检查**：由于后端任务多为异步执行，需在 Playwright 中实现 `polling` (轮询) 机制，实时验证任务状态从 `pending` 变为 `running` 或 `completed`。
*   **视觉对比 (Visual Regression)**：针对 ECharts 渲染的分析报告，引入 `expect(page).toHaveScreenshot()` 进行基准图对比。

## 4. 验证计划

1.  **运行本地 Dev 环境**: 确保 `admin` 端和后端 API 同时运行。
2.  **执行测试集**: 运行 `npm run test:all`。
3.  **分析结果**: 检查 `playwright-report` 中的截图和追踪信息 (Trace)。
