# 价格幅度指标与乖离率对比说明

## 一、结论

**价格幅度指标与乖离率（Bias）的计算方式不一致**，它们是**不同的指标**，衡量的是价格的不同维度。

---

## 二、定义对比

### 2.1 图片中的价格幅度指标


| 指标       | 公式           | 说明               |
| -------- | ------------ | ---------------- |
| **宏观位移** | Δ = d₂₀ - d₁ | 20天首尾价格差（绝对差值）   |
| **幅度**   | 幅度 = Δ的数值大小  | 宏观位移的绝对值或相对值     |
| **比例1**  | Δ/d₂₀        | 宏观位移相对于第20天价格的比率 |
| **比例2**  | Δ/d₁         | 宏观位移相对于第1天价格的比率  |


**代码位置**：

- [analyzers.py](backend_core/strategies/pvfrs/analyzers.py) 第 54-83 行：`calculate_macro_displacement` 计算 Δ = d₂₀ - d₁
- 当前**未实现** Δ/d₂₀、Δ/d₁ 这两个比例

---

### 2.2 PVFRS 中的乖离率（Bias）


| 指标      | 公式                             | 说明                 |
| ------- | ------------------------------ | ------------------ |
| **乖离率** | Bias = (d₂₀ - d) / d           | 当前价格相对于20日均价的偏离百分比 |
| 其中      | d = (d₁ + d₂ + ... + d₂₀) / 20 | 20日平均价格            |


**代码位置**：

- [analyzers.py](backend_core/strategies/pvfrs/analyzers.py) 第 289-311 行：`calculate_bias` 计算 Bias = (当前价格 - 20日均价) / 20日均价

---

## 三、关键区别

### 3.1 分子不同


| 项目       | 幅度指标         | 乖离率             |
| -------- | ------------ | --------------- |
| **分子**   | Δ = d₂₀ - d₁ | d₂₀ - d         |
| **含义**   | 20天首尾价格差     | 当前价格与20日均价的差    |
| **时间跨度** | 20天整体变化      | 当前时刻相对于20天均值的偏离 |


**示例**：

- 假设 d₁ = 10.0，d₂₀ = 12.0，d = 11.0
- 幅度指标分子：Δ = 12.0 - 10.0 = **2.0**
- 乖离率分子：d₂₀ - d = 12.0 - 11.0 = **1.0**

---

### 3.2 分母不同


| 项目     | 幅度指标                   | 乖离率          |
| ------ | ---------------------- | ------------ |
| **分母** | d₂₀ 或 d₁               | d（20日平均价格）   |
| **含义** | 首尾价格                   | 20天平均价格      |
| **数值** | d₂₀ = 12.0 或 d₁ = 10.0 | d = 11.0（假设） |


**示例**（续上）：

- 幅度指标比例：Δ/d₂₀ = 2.0 / 12.0 = **16.67%**，或 Δ/d₁ = 2.0 / 10.0 = **20%**
- 乖离率：Bias = 1.0 / 11.0 = **9.09%**

---

### 3.3 经济含义不同


| 指标                   | 衡量内容              | 应用场景                  |
| -------------------- | ----------------- | --------------------- |
| **幅度指标（Δ/d₂₀、Δ/d₁）** | 20天整体涨幅相对于首尾价格的比率 | 判断20天整体趋势强度、是否横盘（Δ=0） |
| **乖离率（Bias）**        | 当前价格相对于20日均价的偏离程度 | 判断超买/超卖、买入/卖出时机       |


---

## 四、数值关系

虽然两者不同，但在某些情况下存在关联：

### 4.1 当价格线性上涨时

假设价格从 d₁ 线性上涨到 d₂₀：

- d = (d₁ + d₂₀) / 2（近似）
- Δ = d₂₀ - d₁
- Bias = (d₂₀ - d) / d ≈ (d₂₀ - (d₁ + d₂₀)/2) / d = (d₂₀ - d₁) / (2d) = Δ / (2d)

此时：**Bias ≈ Δ / (2d)**，但分母仍是 d（均价），不是 d₂₀ 或 d₁。

### 4.2 当 Δ = 0（横盘）时

- 幅度指标：Δ = 0 → 横盘（图片中的判断）
- 乖离率：Bias = (d₂₀ - d) / d，如果 d₂₀ ≈ d，则 Bias ≈ 0，但**不一定等于0**

**关键**：Δ = 0 时，d₂₀ = d₁，但 d（20日均价）可能不等于 d₁ 或 d₂₀（因为中间价格波动），所以 Bias 不一定为 0。

## 六、总结

1. **不一致**：价格幅度指标（Δ/d₂₀、Δ/d₁）与乖离率（Bias）是**不同的指标**。
2. **幅度指标**：衡量20天整体涨幅相对于首尾价格的比率，用于判断整体趋势和横盘。
3. **乖离率**：衡量当前价格相对于20日均价的偏离，用于判断超买/超卖和买卖时机。
4. **互补关系**：两者可以**互补使用**：

- 幅度指标：判断整体趋势（是否横盘、整体涨幅）
- 乖离率：判断当前偏离（是否超买/超卖）

如果需要在 PVFRS 中补充图片中的幅度指标（Δ/d₂₀、Δ/d₁），可以参考之前创建的《幅度计算及指标与图片对齐》计划进行实现。
