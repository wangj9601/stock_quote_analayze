# 行情页「成交量异动榜」设计与实现计划

## 一、数据来源与异动定义

- **A 股**：`historical_quotes`（日行情） + `mavol_indicators`（market_type='CN'），按 `code`、`date` 关联。
- **港股**：`historical_quotes_hk`（日行情） + `mavol_indicators`（market_type='HK'），按 `code`、`date` 关联。
- **异动**：取「当日成交量 / MAVOL20」作为量比，按量比降序排行（放量居前）；可选支持按量比升序（缩量）或同时提供两种榜单。

## 二、列表字段设计（建议）


| 字段名     | 说明               | 数据来源             |
| ------- | ---------------- | ---------------- |
| 排名      | 按量比排序后的序号        | 计算               |
| 股票代码    | code             | 行情表              |
| 股票名称    | name             | 行情表              |
| 日期      | 交易日期             | 行情表              |
| 当日成交量   | volume           | 行情表              |
| 成交额     | amount           | 行情表              |
| MAVOL5  | 5 日均量            | mavol_indicators |
| MAVOL10 | 10 日均量           | mavol_indicators |
| MAVOL20 | 20 日均量           | mavol_indicators |
| 量比(5)   | volume / mavol5  | 计算               |
| 量比(20)  | volume / mavol20 | 计算               |
| 涨跌幅(%)  | change_percent   | 行情表              |
| 收盘价     | close            | 行情表              |
| 换手率(%)  | turnover_rate    | 行情表              |
| 操作      | 跳转详情/历史页         | 前端               |


导出 CSV/Excel 时可不含「操作」列，其余字段与上表一致。

## 三、后端接口

**新建接口**（建议放在 [backend_api/stock/stock_manage.py](backend_api/stock/stock_manage.py) 或 [backend_api/quotes_routes.py](backend_api/quotes_routes.py)）：

- **GET /api/stock/volume_aberration_list**
  - 参数：`market`（cn / hk，必填）、`date`（可选，默认取该市场行情表最新交易日）、`order`（desc 放量 / asc 缩量，默认 desc）、`page`、`page_size`。
  - 逻辑：
    - `market=cn`：从 `historical_quotes` 取指定 date 的所有记录，JOIN `mavol_indicators`（code, date, market_type='CN'），计算量比(5)、量比(20)，按量比排序后分页返回上述字段。
    - `market=hk`：从 `historical_quotes_hk` 取指定 date 的所有记录，JOIN `mavol_indicators`（code, date, market_type='HK'），同样计算量比并排序分页。
  - 返回：`{ success, data: [...], total, date }`，其中 `date` 为实际使用的交易日期。

**注意**：`historical_quotes.date` 为 Date 类型，`historical_quotes_hk.date` 为 String；JOIN 时需统一为同格式（如均转为 'YYYY-MM-DD'）。

## 四、前端改动

**页面结构**（[frontend/markets.html](frontend/markets.html)）：

- 在「涨跌排行」面板内，在现有四个按钮（涨幅榜、跌幅榜、成交量榜、换手率榜）旁增加 **「成交量异动榜」** 按钮（或单独一个 tab 与「涨跌排行」并列，按你现有 UI 风格二选一）。
- 当选中「成交量异动榜」时：
  - 显示 **市场切换**：A股 / 港股（与现有涨跌排行的市场筛选一致或复用）。
  - 可选：**日期选择**（默认“最新交易日”）和 **排序**：放量榜 / 缩量榜。
  - 表格列与「二、列表字段设计」一致；最后一列为「操作」（如跳转 `stock.html?code=xxx`、`stock_history.html?code=xxx`）。
  - 表格上方或下方提供 **导出 CSV**、**导出 Excel** 按钮。

**逻辑**（[frontend/js/markets.js](frontend/js/markets.js)）：

- 新增 `currentRankingType === 'volume_aberration'` 时的分支：
  - 调用 `GET /api/stock/volume_aberration_list`，传入 `market`、`date`、`order`、`page`、`page_size`。
  - 渲染表格与分页（可复用现有 `renderRankingTable` 的表格结构，列不同则单独写 `renderVolumeAberrationTable`）。
- **导出 CSV**：用当前列表数据组二维数组，表头为上述字段（不含操作），股票代码列加 `\u2060` 前缀防 Excel 吞前导零，触发下载 `.csv`（与 [frontend/js/screening.js](frontend/js/screening.js) 中 GMS 导出方式类似）。
- **导出 Excel**：使用页面已引用的 SheetJS（若无则像 screening 一样引入），将当前列表数据写入 sheet，表头 + 数据行，股票代码列同样加 `\u2060`，调用 `XLSX.writeFile` 下载 `.xlsx`。

**样式**（[frontend/css/markets.css](frontend/css/markets.css)）：为「成交量异动榜」表格与按钮增加或复用现有排行表格样式，保证与涨跌排行视觉一致。

## 五、实现顺序建议

1. 后端：实现 `volume_aberration_list` 接口（A股 + 港股，分页，量比计算与排序）。
2. 前端：涨跌排行区增加「成交量异动榜」入口与市场/日期/排序 UI，请求新接口并渲染表格与分页。
3. 前端：导出 CSV、导出 Excel（字段与列表一致，不含操作列）。

## 六、数据与边界

- 若某日某只股票在行情表有数据但 `mavol_indicators` 无对应 code/date，则量比为 NULL，排序时可排最后或过滤掉（建议过滤，保证量比均有值）。
- 量比(5)、量比(20) 在 mavol 为 0 时不做除，返回 null 或前端显示「--」。
