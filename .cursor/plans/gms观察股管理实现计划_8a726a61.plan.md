## 数据模型与数据库设计
- 新增策略版本主表（建议）：`gms_strategy_versions`
  - 核心字段：`id`、`strategy_code`、`version_name`、`version_no`、`description`、`is_active`、`created_by`、`created_at`、`updated_at`。
  - 约束：`(strategy_code, version_no)` 唯一。
- 新增策略版本观察股关系表：`gms_strategy_version_stocks`
  - 核心字段：`id`、`version_id`、`market`(`A`/`HK`)、`stock_code`、`stock_name`、`sort_order`、`status`、`remark`、`created_at`、`updated_at`。
  - 约束：`(version_id, market, stock_code)` 唯一。
  - 索引：`version_id`、`market`、`stock_code`、`(version_id, status)`。
- 数据库脚本位置：[`E:/wangxw/股票分析软件/编码/stock_quote_analayze/database/migrations/`](E:/wangxw/股票分析软件/编码/stock_quote_analayze/database/migrations/)
  - 新建 SQL 脚本包含：建表、索引、唯一约束、外键、初始化示例（可选）、回滚语句（可选）。
  - 所有表/字段/索引均补充中文注释（`COMMENT`）。

## 后端 API 设计（管理端）
- 在 `/api/admin/gms` 下新增“策略版本观察股管理”接口分组：
  - 版本管理：列表、详情、新增、修改、删除、启用/停用。
  - 观察股管理：分页列表、新增、编辑、删除、批量导入、批量删除。
- 批量导入支持：
  - `json/csv/xlsx` 三选一（实现时先落地一种主格式，另两种按统一解析器扩展）。
  - 去重规则：基于 `(version_id, market, stock_code)` 幂等导入。
  - 返回导入统计：成功数、跳过数、失败数、失败原因。
- A/H 股代码与存在性校验：
  - A 股去 `stock_basic_info` 校验；港股去 `stock_basic_info_hk` 校验。
  - 不存在代码按失败明细返回。
