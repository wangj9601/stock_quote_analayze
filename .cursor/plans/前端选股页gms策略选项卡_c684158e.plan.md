# 前端选股页 GMS 策略选项卡实现计划

## 一、参考结构：PVFARS 选项卡

PVFARS 选项卡由以下部分组成（[screening.html](frontend/screening.html) 第 600-735 行）：

1. **策略说明卡片**：`strategy-info-card`，策略条件列表
2. **数据来源**：`strategy-params-card`，单选：全部A股 / 全部港股 / 我的自选
3. **策略参数**：`strategy-params-card`，可编辑参数（观察周期、Δ/d₂₀ 上限等）+ 保存按钮
4. **筛选操作**：刷新筛选、导出CSV、筛选时间
5. **加载/错误区域**：`loadingIndicator`、`errorMessage`
6. **结果表格**：`resultsTable`，含得分明细展开行

## 二、GMS 选项卡页面设计

### 2.1 策略说明（依据 [均值引力动量策略说明.md](.cursor/specs/均值引力动量策略说明.md)）

- **股票范围**：全部A股或港股（排除ST）
- **时间范围**：最近 20 个交易日
- **选股条件**：
  1. **左侧买点（均值吸附）**：F>Z 且 d₂₀<d₁；Δ/d₂₀<1.5%；地量洗盘 m₂₀<0.8m
  2. **右侧买点（动量引爆）**：d₂₀>d 且 Δ>0；m₂₀>1.5m；Δ/d₁ 突破 0 轴
  3. **评分**：蓄势 30 + 平衡 40 + 动量 30；总分>60 重头关注，>90 动量突变预警
  4. **退出**：趋势破坏（d₂₀ 跌破 d 三日）或乖离过大（Δ/d₂₀>15%）

### 2.2 数据来源

与 PVFARS 相同：全部A股、全部港股、我的自选（单选）

### 2.3 策略参数（可配置，参考文档）


| 参数        | 说明            | 默认   |
| --------- | ------------- | ---- |
| 观察周期      | 20 天          | 20   |
| 左侧买点      | Δ/d₂₀         | 上限   |
| 左侧买点 量比上限 | 地量 m₂₀/m < 此值 | 0.8  |
| 右侧买点 量比下限 | 放量 m₂₀/m > 此值 | 1.5  |
| 重头关注分数    | 总分 > 此值       | 60   |
| 动量突变预警分数  | 总分 > 此值       | 90   |
| 乖离过大阈值    | Δ/d₂₀ > 此值退出  | 0.15 |


### 2.4 结果表格列设计


| 列     | 说明         |
| ----- | ---------- |
| 股票代码  |            |
| 股票名称  |            |
| 总分    | 蓄势+平衡+动量   |
| 买点类型  | 左侧/右侧/—    |
| 当前价格  |            |
| Δ/d₂₀ | 偏离率        |
| Δ/d₁  | 突变率        |
| F/Z   | 数方比        |
| 当前涨跌幅 |            |
| 操作    | 历史、详情、得分明细 |


得分明细展开：蓄势得分、平衡得分、动量得分、各项条件满足情况。

## 三、修改文件清单

### 3.2 [frontend/js/screening.js](frontend/js/screening.js)

1. **switchStrategy**：`strategy === 'gms'` 时加载 GMS 参数（类似 `loadPvfrsParams`）
2. **bindEvents**：
  - 刷新按钮 `refreshBtn-gms` 绑定 `loadScreeningResults('gms')`
  - 数据来源 radio `gmsScope` 变更时刷新
  - 保存参数 `gmsParamsSaveBtn` 绑定 `saveGmsParams`
  - 得分明细展开按钮事件委托（在 `resultsContainer-gms` 上）
3. **loadScreeningResults**：`strategy === 'gms'` 时
  - suffix = `gms`
  - URL = `/api/screening/gms-strategy?scope=${scope}`（需后端提供）
4. **renderResults**：`strategy === 'gms'` 时渲染 GMS 表格行及得分明细展开
5. **exportCSV**：`strategy === 'gms'` 时导出 GMS 列
6. **loadGmsParams** / **saveGmsParams**：从/到 `localStorage` 或后端 API（若存在）

## 四、后端 API 依赖

GMS 选项卡需调用选股接口，建议新增：

- **GET** `/api/screening/gms-strategy?scope=cn|hk|watchlist`
- 响应格式与 PVFRS 一致：`{ success, data, total, search_date }`
- `data` 每项包含：`symbol`/`code`、`name`、`score_total`、`buy_type`（left/right）、`current_price`、`ratio_d20`、`ratio_d1`、`fz_ratio`、`current_change_percent`、`score_detail` 等

若 GMS 后端未完成，可先用占位接口返回 `{ success: true, data: [] }`，前端展示“暂无数据”或“接口开发中”。
