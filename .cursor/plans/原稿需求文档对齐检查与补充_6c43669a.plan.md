## 一、原稿关键内容梳理

### 第一张图片（原稿）的关键定义：

1. **基础变量定义**：
  - `dᵢ`: 价格（第i天）
    - `mᵢ`: 成交量（第i天）
    - `d = ∑(i=1 to 20) dᵢ / 20`：20日平均价格
    - `m = ∑(i=1 to 20) mᵢ / 20`：20日平均成交量
2. **趋势判断**：
  - `d₂₀ - d < 0` → 跌
    - `d₂₀ - d > 0` → 涨
3. **横盘判断**：
  - `Δ₂₀ / d` 极小数域内 → 横盘

### 第二张图片的关键定义：

1. **日价格变化**：
  - `Δᵢ = dᵢ₊₁ - dᵢ`（日价格变化）
2. **频率统计**：
  - `F = count(Δᵢ < 0)`：下跌天数总数
    - `Z = count(Δᵢ > 0)`：上涨天数总数
3. **重点关注条件**：
  - `F > Z 且 d₂₀ < d₁` → 则位及重关关注（值得重点关注）
4. **幅度计算**：
  - `Δ = d₂₀ - d₁`（20天价格位移）
    - **幅度 = Δ的数值大小**（|Δ|）
    - `Δ/d₂₀`、`Δ/d₁`（两个比例）
5. **横盘判断**：
  - `① Δ = 0 → 横盘`

### 3.5 日价格变化 (Daily Price Change)

**定义**: 衡量相邻交易日之间的价格变化

**计算公式**:
```

Δᵢ = dᵢ₊₁ - dᵢ = Close_{i+1} - Close_i

```

**计算步骤**:
1. 对每个交易日 i，计算与前一日的价格差: `Δᵢ = Close_i - Close_{i-1}`
2. 在20日窗口内，得到19个日变化值（因为需要19次比较）

**经济意义**:
- **Δᵢ > 0**: 第i天价格上涨
- **Δᵢ < 0**: 第i天价格下跌
- **Δᵢ = 0**: 第i天价格持平（横盘日）

**与Z/F的关系**:
- Z（上涨天数）= count(Δᵢ > 0) for i in [1, 19]
- F（下跌天数）= count(Δᵢ < 0) for i in [1, 19]
- 横盘日（Δᵢ = 0）既不计入Z也不计入F

**代码实现**:
```python
df['daily_change'] = df['close'].diff(1)  # Δᵢ = dᵢ - dᵢ₋₁
df['is_rising'] = (df['daily_change'] > 0).astype(int)
df['is_falling'] = (df['daily_change'] < 0).astype(int)
```

### 1.2 幅度比例（Amplitude Ratios）

**定义**: 宏观位移相对于首尾价格的比率

**计算公式**:

```
ratio_d20 = Δ / d₂₀ = (d₂₀ - d₁) / d₂₀
ratio_d1 = Δ / d₁ = (d₂₀ - d₁) / d₁
```

**计算步骤**:

1. 计算宏观位移: `Δ = d₂₀ - d₁`
2. 计算相对于第20天价格的比率: `ratio_d20 = Δ / d₂₀`
3. 计算相对于第1天价格的比率: `ratio_d1 = Δ / d₁`

**经济意义**:

- **ratio_d20**: 衡量20天涨幅相对于当前价格的比率
- **ratio_d1**: 衡量20天涨幅相对于起始价格的比率
- 用于判断整体趋势的强度（相对于价格水平）

**注意事项**:

- 当 d₂₀ = 0 或 d₁ = 0 时，对应比例无法计算（应设为 None 或跳过）

**代码实现**:

```python
if d20 != 0:
    ratio_d20 = macro_displacement / d20
else:
    ratio_d20 = None

if d1 != 0:
    ratio_d1 = macro_displacement / d1
else:
    ratio_d1 = None
```

### 1.3 横盘判断（Sideways Market Detection）

**定义**: 判断市场是否处于横盘整理状态

**判断条件**:

```
① Δ = 0 或 |Δ| < ε → 横盘
② Δ₂₀ / d 极小数域内 → 横盘（相对幅度过小）
```

其中 `ε` 为横盘判定阈值（例如 `1e-6` 或可配置的 `amplitude_flat_threshold`）

**经济意义**:

- **Δ = 0**: 20天首尾价格相同，绝对横盘
- **|Δ| < ε**: 价格变化极小，近似横盘
- **Δ₂₀ / d 极小数域内**: 相对幅度过小，即便满足量价条件，演化逻辑仍属于"平"的范畴

**应用场景**:

- 入场时机：横盘时建议等待波幅放大
- 信号过滤：横盘状态下的信号质量较低
- 风险控制：横盘时更保守的策略

**代码实现**:

```python
amplitude_flat_threshold = 1e-6  # 可配置阈值

# 方法1：基于绝对幅度
is_sideways_abs = abs(macro_displacement) < amplitude_flat_threshold

# 方法2：基于相对幅度
amplitude_coefficient = macro_displacement / avg_price_20d
is_sideways_rel = abs(amplitude_coefficient) < threshold  # threshold 可配置

# 综合判断
is_sideways = is_sideways_abs or is_sideways_rel
```
