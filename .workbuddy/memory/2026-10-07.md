## 引入 Alembic 管理数据库迁移

- **背景**：原迁移方式为 84 个手写 `migrations/*.py` + `scripts/run_recent_migrations.py`（按文件 mtime 排序执行），无版本账本、无回滚、顺序不可靠。`alembic==1.13.1` 早已在根 `requirements.txt` 中但从未配置。
- **新增文件**：
  - `alembic.ini`（根，**必须纯 ASCII** —— alembic 1.13.x 用系统 locale 编码读该文件，zh-CN Windows 下为 GBK，中文注释会 `UnicodeDecodeError`）
  - `alembic/env.py`、`alembic/script.py.mako`、`alembic/README.md`
  - `alembic/versions/0001_baseline.py`（no-op 基线）
  - `alembic/schema_snapshot_0001.json`（基线时刻 171 张表的结构快照，归档参考）
  - `scripts/db_migrate.py`（封装：status/check/upgrade/downgrade/stamp/revision/history/sql）
  - `docs/database/Alembic_guide.md`（主文档）、`migrations/README.md`（冻结说明）
- **改动的既有文件**：`backend_api/requirements.txt`（启用 alembic）、`backend_api/requirements-minimal.txt`（注释说明 alembic 刻意不入最小依赖）、`scripts/run_recent_migrations.py` 与 `.ps1`（加弃用提示）、`docs/README.md`（加 database/ 索引）。
- **三个必须牢记的坑（关键结论）**：
  1. **两套 ORM Base 且不能传 metadata 列表**：`backend_api.models.Base`(125 表) 与 `backend_core.database.db.Base`(9 表) 有 4 张同名表（`watchlist`/`historical_quotes`/`ma_indicators`/`macd_indicators`）。Alembic 的 `AutogenContext.table_key_to_table` 遇跨 metadata 同名表直接抛 `ValueError`。解决：`MetaData.to_metadata()` 合并为**单一** MetaData，api 侧优先 → 130 表。
  2. **库里 44 张表无 ORM 声明**（当年手写 SQL 建的）：autogenerate 会生成 `drop_table`，执行即不可逆丢数据。解决：`env.py:include_object()` 默认「只增不减」（跳过 `reflected and compare_to is None` 的对象），用 `ALEMBIC_ALLOW_DROP=1` 才放开。实测 upgrade 段 `drop_table`/`drop_column` 计数为 0。
  3. **ORM metadata 与真实库有系统性偏差**：`String()` vs `TEXT`、`Integer` vs `BIGINT`、`JSON` vs `JSONB` → 353 处 `alter_column` 属**伪漂移**；另有 164 `create_index`、14 `create_foreign_key`、6 `create_unique_constraint`、3 `create_table`。**结论：本项目必须手写 revision，autogenerate 只当线索，不可原样提交。**
- **验证（全部通过）**：`stamp 0001_baseline` 对既有库生效（171→172 张，仅多 `alembic_version`）；端到端 `upgrade`→建表→版本 `0002_smoke`，`downgrade -1`→撤销→回 `0001_baseline`，库复原；`db_migrate.py status` 口令脱敏为 `postgres:***@…`；离线 `sql` 子命令正常。
- **其他记忆点**：`backend_api/models` 是**包**（与 `models.py` 同名），`Base` 由包内 importlib 动态载入 `models.py`；`backend_api/database.py` 在模块级 `print` 含明文口令的连接串，脚本里需吞 stdout。
