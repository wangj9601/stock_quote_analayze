## 代码梳理：URT 推送任务生成链路（只读分析，未改代码）
- 两段式：① 配置行 `user_push_configs`（report_type=urt_daily + push_times + channels）由管理端 push_routes admin create → ConfigService.create_config 生成；② 调度 job 由独立进程 `start_scheduler.py` → `PushScheduler` 每 5 分钟 `_refresh_push_jobs_from_config()` 按 `get_all_distinct_push_times()` 差集对齐，job_id=`push_job_HHMM`，Cron 默认 mon-fri（ENABLE_WEEKEND_PUSH 控）
- 执行链：`_execute_push_job` → `PushService.execute_scheduled_push(push_time)` → 休市跳过(trading_calendar_utils.is_market_session_closed CN) + 去重(user,push_date,push_time,report_type) → `push_to_user` → `ReportService.generate_user_report` → `_generate_urt_report_for_user` → `URTFrontendInterface.screen(scope=watchlist, force_realtime=True, skip_screening_filters=True)` → `URTStrategyEngine.screen_universe` → `evaluate_buy_signal`
- 注意：推送报告走 force_realtime，**不读** `urt_signal_trace` 预计算；预计算是另一条线（data_collectors/main.py 注册，A股 16:45 / 港股 17:20，默认仅 is_default/precompute_enabled 版本）
- 三条任务入口差异：定时（走去重+休市跳过）、管理端 `/api/admin/push/configs/{id}/trigger`（push_time=`MHH:MM:SS`、不走去重）、外部自动化脚本 `.workbuddy/tmp/push_urt_daily.py`（force=True 直调 push_to_user）
